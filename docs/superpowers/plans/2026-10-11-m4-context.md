# claude-plus Milestone 4 (Context View) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pane gains a Context view (hotkey `2`) that shows Claude Code's own context breakdown by category with rows that open into their items, the largest items the setup loads into every request, what has not been used in 14 days, the largest tool results and a read-only count of what is configured on disk, and that estimates the composition from the transcript while no breakdown exists.

**Architecture:** The mod asks `$.session.usage({ breakdown: 'full' })` after main-thread turns at a capped cadence, draws it at once and forwards it as a `session.usage` event; the daemon keeps the latest one per session in a new `live_breakdowns` table (schema v12).
Two new daemon units do the rest: `config_scan` finds the CLAUDE.md chain, memory, skills, agents, output styles, MCP servers and plugins on disk without writing anything, and `context_model` parses breakdowns, calibrates chars per token, composes history from transcript attachments and ranks items and dead weight.
A new route `GET /context?session=<id>` serves the result as `ContextReport` v1; the snapshot is unchanged, and the mod keeps every `$` call and atom in `hooks/register.tsx` with the Context screen as a pure function in `hooks/context.ts`.

**Tech Stack:** Rust (edition 2024, MSRV 1.88), no new crates (`walkdir`, `serde_json` and `rusqlite` are already dependencies); Claude Code 2.1.296 function hooks (TypeScript, JSX with `h`), `claude plugin validate` and `claude plugin test`, TypeScript 6.0.3 through `npx` for type-checking only.
Node and npx are installed at `/opt/homebrew/bin`; there is no global `tsc`, and `npx --offline -p typescript@6.0.3 tsc` runs from the npx cache.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 3 "The pane" view 2 and "Look and feel", 4 "Units" `config_scan` and `context_model`, "Data sources" `$.session.usage({ breakdown: 'full' })`, "Transcript facts verified on real data" on `attachment` records, "Storage schema" `live_breakdowns`, 5 "Context composition", 7 "Error handling and safety", 8 "Testing", 9 milestone 4: "Context view: live breakdown, history composition, config scan").

## Decisions

The spec is silent on these points, so this plan decides them.

1. The report gets its own route, `GET /context?session=<id>`, instead of a field in the snapshot.
   The scan and the composition are heavier than the snapshot and only matter while the Context view is shown, so the 3 s snapshot poll stays as cheap as in M3.
   The route is new, so `API_VERSION` stays 1 and nothing existing changes shape.
2. Schema v12 adds `live_breakdowns(session_id PRIMARY KEY, ts_ms, received_ms, json)` with an index on `ts_ms`, the spec's table with the timestamps every event row already carries.
   A `session.usage` event is written there and not into `events`, so a long session keeps one row however often it sends one; an older breakdown never replaces a newer one, and the table is not derived, so a reindex keeps it.
3. The mod forwards an explicit camelCase copy of Claude Code's `SessionContextBreakdown` (`model`, `totalTokens`, `maxTokens`, `rawMaxTokens`, `percentage`, `autocompactSource`, `autoCompactThreshold`, `isAutoCompactEnabled`, `categories`, `memoryFiles`, `mcpTools`, `agents`, `skills`, `slashCommands`, `apiUsage`) plus `contextTokens` and `contextWindow`, and leaves out `gridRows`, which only draws `/context`'s grid.
4. `breakdown: 'full'` costs Claude Code one token-count request per tool and memory file, so the mod asks for it only when it is due: after a main-thread `turn.complete` or `session.compact`, and when the Context view opens without one.
   A due request waits until 60 s have passed since the last one while the Context view is shown, and 10 minutes otherwise; subagent turns never make one due.
   The call is `.catch(() => null)`, so a failure leaves the last breakdown in place.
5. The window shown is `max(rawMaxTokens, maxTokens)` and a category with `isDeferred` counts as `deferred`, matching how `/context` reads.
6. The mod polls `/context` every 10 s, only while the Context view is shown, and at once after it forwarded a new breakdown or the view opened.
   The breakdown the mod collected itself is drawn as soon as it arrives; the stored one wins only when it is newer, and a report or breakdown of another session is ignored, so `/clear` starts empty.
7. The scan reads, and never writes: `~/.claude/CLAUDE.md` and `~/.claude/rules/**/*.md` (depth 4); for the project and each ancestor up to `/`, `CLAUDE.md`, `.claude/CLAUDE.md`, `CLAUDE.local.md` and `.claude/rules/**/*.md`; nested `CLAUDE.md` and `CLAUDE.local.md` below the project (depth 6, at most 20,000 entries, skipping dot directories, `node_modules`, `target`, `vendor`, `dist`, `build` and `__pycache__`); every `~/.claude/projects/*/memory` directory; `settings.json` of the user, the project and `settings.local.json` (later wins); `plugins/installed_plugins.json`; skills, agents and output styles of the user, the project and enabled plugins; MCP servers from `~/.claude.json` (user and this project's entry), the project's `.mcp.json` and enabled plugins' `.mcp.json` and `plugin.json`.
   A file is counted once by its canonical path; a file over 4 MiB is measured by its size and not read.
   With `CLAUDE_CONFIG_DIR` set, `.claude.json` is read from that directory, else from the home directory (`Paths.claude_json`).
8. Each source has a loading class: `always` (CLAUDE.md files, the active output style, enabled plugins, the first 200 lines of the current project's `MEMORY.md`), `listing` (a skill or agent costs its listing line `- name: description` until used), `on_demand` (nested CLAUDE.md files, other memory files, skills with `disable-model-invocation: true`), `off` (disabled plugins, inactive output styles, project MCP servers in `disabledMcpjsonServers`) or `unknown` (an MCP server, whose size only a breakdown can tell).
   A project memory directory is found by the project path with every character other than a letter or digit replaced by `-`.
9. The scan is cached for 30 s per (claude dir, `.claude.json`, project) and the cache holds 16 projects, so the 10 s poll does not walk the disk each time.
10. Characters per token default to 3.5 for prose (Anthropic's own rule of thumb), 3.0 for code and tool results, and 2.5 for JSON schemas.
    The spec's calibration "for the same session" is done on the same text instead: memory files (by path), skills and agents (by name) that appear both in one of the latest 10 breakdowns of any session and in the scan, with at least 25 tokens, one pair per item, latest breakdown first.
    With at least 3 pairs the median ratio over 3.5 gives one factor, clamped to between 0.5 and 2, that scales all three kinds; transcripts keep only `{"$chars": n}` of attachment content, so no finer per-session pairing exists.
11. History composition follows the spec: attachments up to the first main-thread request are estimated, the first user message is estimated from the first prompt record, and the fixed part is the first request's `input + cache_read + cache_write` minus that message.
    What the attachments do not explain becomes a `system` share (system prompt and tool definitions); estimates are scaled down only when they exceed the fixed part, never up.
    Attachment kinds map to parts: `instructions` and `nested_memory` to memory; `skill_listing` and `invoked_skills` to skills; `mcp_instructions_delta` to MCP as prose and `deferred_tools_delta`, `deferred_tools_record` as schema; `agent_listing_delta` to agents; `file`, `edited_text_file`, `selected_lines_in_ide`, `compact_file_reference` to files as code; `hook_additional_context` to hooks; `environment`, `date`, `model`, `session_context`, `total_tokens_reminder`, `silent_turn_reminder`, `task_status`, `auto_mode` to reminders; everything else (for example `prompt_snapshot`, `queued_command`, `hook_success`) is bookkeeping and ignored.
    A compaction resets what was injected, and the history keeps at most 60 points, always including every compaction, for the M5 growth curve.
12. Items are exact when a breakdown exists (memory files named from the scan when the path matches, skills, MCP servers with their loaded tool tokens and tool count, agents) and estimated from the scan otherwise; the active output style is always an estimate.
    `items` lists every item with tokens, at most 100, largest first; the view shows the first 6 under "Largest items" and all of a kind under its category row.
13. Dead weight is data only (insights wait for M6): a skill (from `attributionSkill`) or an MCP server (from its tools' `mcp__<server>__<tool>` uses) with tokens and no use in 14 days across all sessions.
    Agents and memory files have no use count, because transcripts do not attribute requests to them.
14. Not scanned in v1: slash commands, hooks, managed-policy CLAUDE.md files and `@` imports inside CLAUDE.md files.
15. The view reads top to bottom: the headline (`Context · <model>` and used over window), a bar, the auto-compact line; "By category" (or "Estimated from the transcript" with `~` values); "Largest items"; "Not used in 14 days" with what it costs a turn; "Largest tool results" (the 3 largest of the session at the code ratio); "Configured" (counts with `on demand` and `off`).
    The spec's "rows expand with Enter" is a category row marked `▸` (Memory files, Skills, MCP tools, Custom agents, matched by Claude Code's category names) that is a Button: Tab reaches it, Enter or a click opens it to `▾` with up to 8 items and a `+ N more` line, and its open state lives in the M3 `expanded` atom as `open-<item kind>`.
    A `?` on "By category", "Estimated from the transcript", "Largest items" and "Configured" explains the numbers, as in M3.
16. Categories keep Claude Code's own colors when the color is one of the 23 `ThemeKey`s and use `text` otherwise; the estimated parts use fixed keys (system `promptBorder`, memory `autoAccept`, skills `suggestion`, MCP `permission`, agents `remember`, files `ide`, hooks `planMode`, reminders `subtle`, messages `text`).
17. Both views share one pane body, `views/pane.tsx` (the M3 `views/live.tsx` renamed), with the tabs `1: Live` and `2: Context` one column apart; the Live screen model stays in `state.ts` and the Context one lives in `context.ts`.
18. The `local` atom's shape becomes `local-2` because `Local` gains `breakdown`, and the new `context` atom is shaped `context-1`, so state kept from an older module reads as absent instead of malformed.
19. The validator's note `gating hook without .catch: session.compact` predates M4 and stays: a failing observer hook fails open, which is right for a mod that only watches.

## Review Focus

1. `~/.claude` must come out of a scan exactly as it went in, even when it is read-only or holds unreadable, malformed or huge files (Task 2 tests `a_read_only_claude_dir_is_scanned_and_left_untouched`, `unreadable_or_malformed_config_is_skipped` and `oversized_files_count_their_bytes_without_being_read`).
2. A full breakdown costs Claude Code one request per tool and memory file: the mod must not ask for one on every turn, nor for a subagent's turn (Task 10 test `the Live view asks for a breakdown once per ten minutes of turns, the Context view once a minute`).
3. `/clear` keeps the process under a new session id without `session.start`: the Context view must drop the old report and breakdown (Task 10 test `a new session after /clear drops the previous context report`, Task 9 test `the newest of the local and the stored breakdown wins, and another session is ignored`).
4. With the daemon down or not installed, the Context view must still draw Claude Code's own breakdown and say how to fix the daemon (Task 10 test `the Context view keeps the breakdown from Claude Code while the daemon is down`, Task 9 test `keeps the live breakdown from Claude Code alone while the daemon is missing`).
5. A breakdown that arrives late, or in a shape a newer Claude Code sends, must neither replace a newer one nor break the report (Task 1 test `the_newest_breakdown_of_a_session_replaces_older_ones`, Task 4 test `anything_but_a_breakdown_reads_as_none_and_missing_lists_as_empty`, Task 6 test `a_breakdown_the_daemon_cannot_read_is_left_out`).

use anyhow::Result;
use rusqlite::{OptionalExtension, params};

use super::{EventRow, Store, Writer};

#[derive(Debug, Clone, PartialEq)]
pub struct StoredBreakdown {
    pub session_id: String,
    pub ts_ms: i64,
    pub received_ms: i64,
    pub json: String,
}

impl Writer<'_> {
    pub fn live_breakdown(&mut self, row: &EventRow) -> Result<bool> {
        let changed = self
            .tx
            .prepare_cached(
                "INSERT INTO live_breakdowns (session_id, ts_ms, received_ms, json) VALUES (?1, ?2, ?3, ?4)
                 ON CONFLICT(session_id) DO UPDATE SET
                     ts_ms = excluded.ts_ms, received_ms = excluded.received_ms, json = excluded.json
                 WHERE excluded.ts_ms >= live_breakdowns.ts_ms",
            )?
            .execute(params![row.session_id, row.ts_ms, row.received_ms, row.json])?;
        Ok(changed > 0)
    }
}

impl Store {
    pub fn live_breakdown(&self, session_id: &str) -> Result<Option<StoredBreakdown>> {
        Ok(self
            .conn
            .prepare_cached(
                "SELECT session_id, ts_ms, received_ms, json FROM live_breakdowns WHERE session_id = ?1",
            )?
            .query_row([session_id], read_breakdown)
            .optional()?)
    }

    pub fn recent_breakdowns(&self, limit: usize) -> Result<Vec<StoredBreakdown>> {
        let mut statement = self.conn.prepare_cached(
            "SELECT session_id, ts_ms, received_ms, json FROM live_breakdowns
             ORDER BY ts_ms DESC, session_id LIMIT ?1",
        )?;
        let rows = statement.query_map([limit as i64], read_breakdown)?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }
}

fn read_breakdown(r: &rusqlite::Row) -> rusqlite::Result<StoredBreakdown> {
    Ok(StoredBreakdown {
        session_id: r.get(0)?,
        ts_ms: r.get(1)?,
        received_ms: r.get(2)?,
        json: r.get(3)?,
    })
}

use std::collections::BTreeMap;

pub fn frontmatter(text: &str) -> BTreeMap<String, String> {
    let mut fields = BTreeMap::new();
    let mut lines = text.trim_start_matches('\u{feff}').lines();
    if lines.next().map(str::trim_end) != Some("---") {
        return fields;
    }
    let body: Vec<&str> = lines.take_while(|line| line.trim_end() != "---").collect();
    let mut index = 0;
    while index < body.len() {
        let line = body[index];
        index += 1;
        if line.starts_with([' ', '\t']) || line.trim_start().starts_with('#') {
            continue;
        }
        let Some((key, value)) = line.split_once(':') else {
            continue;
        };
        let continued: Vec<&str> = body[index..]
            .iter()
            .take_while(|next| next.trim().is_empty() || next.starts_with([' ', '\t']))
            .copied()
            .collect();
        index += continued.len();
        let value = value.trim();
        let parts = continued
            .iter()
            .map(|part| part.trim())
            .filter(|part| !part.is_empty());
        let joined = match value.chars().next() {
            Some('|') => parts.collect::<Vec<_>>().join("\n"),
            Some('>') => parts.collect::<Vec<_>>().join(" "),
            _ => std::iter::once(value)
                .chain(parts)
                .collect::<Vec<_>>()
                .join(" "),
        };
        fields.insert(key.trim().to_string(), unquoted(joined.trim()));
    }
    fields
}

fn unquoted(value: &str) -> String {
    for quote in ['"', '\''] {
        if value.len() >= 2 && value.starts_with(quote) && value.ends_with(quote) {
            return value[1..value.len() - 1].to_string();
        }
    }
    value.to_string()
}

pub fn claude_md(roots: &Roots, sources: &mut Vec<Source>) {
    let mut seen = HashSet::new();

        if !seen.insert(identity(path)) {
            return;
        }
        if let Some(text) = read_text(path) {
            sources.push(Source {

                scope,
                name,
                path: Some(display(path)),
                plugin: None,
                loading,
                chars: text.chars,
                file_chars: text.chars,
            });
        }

    let user = &roots.claude_dir;
    add(
        Scope::User,
        "CLAUDE.md".into(),
        &user.join("CLAUDE.md"),
        Loading::Always,
    );
    for rule in rules(&user.join("rules")) {
        add(
            Scope::User,
            relative(&rule, user, 0),
            &rule,
            Loading::Always,
        );
    }
    let Some(project) = &roots.project else {
        return;
    };
    for (depth, dir) in project.ancestors().enumerate() {

            (Scope::Local, "CLAUDE.local.md"),

                Loading::Always,
            );
        }
    }

            continue;

        let chars = files
            .iter()
            .filter_map(|file| read_text(file))
            .map(|text| text.chars)
            .sum();

            path: display(&dir),
            files: files.len() as u64,

        return;
    };
    let dir = projects.join(project_key(project)).join("memory");

        .chars()

fn index_chars(content: Option<&str>, chars: u64) -> u64 {
    match content {
        Some(content) => content
            .split_inclusive('\n')
            .take(MEMORY_INDEX_LINES)
            .map(|line| line.chars().count() as u64)
            .sum(),

fn rules(dir: &Path) -> Vec<PathBuf> {
    let mut found: Vec<PathBuf> = walkdir::WalkDir::new(dir)
        .max_depth(RULES_MAX_DEPTH)
        .into_iter()
        .filter_map(Result::ok)
        .map(walkdir::DirEntry::into_path)
        .filter(|path| is_markdown(path))
        .collect();
    found.sort();

}

fn nested(project: &Path) -> Vec<PathBuf> {
    let mut found: Vec<PathBuf> = walkdir::WalkDir::new(project)
        .min_depth(1)
        .max_depth(NESTED_MAX_DEPTH)
        .into_iter()
        .filter_entry(|entry| {
            let name = entry.file_name().to_string_lossy();
            !(entry.file_type().is_dir()
                && (name.starts_with('.') || SKIPPED_DIRS.contains(&name.as_ref())))
        })
        .take(NESTED_MAX_ENTRIES)
        .filter_map(Result::ok)
        .filter(|entry| entry.depth() >= 2 && entry.file_type().is_file())
        .filter(|entry| NESTED_NAMES.contains(&entry.file_name().to_string_lossy().as_ref()))
        .map(walkdir::DirEntry::into_path)
        .collect();
    found.sort();
    found
}

    let inner = path
        .strip_prefix(base)
        .unwrap_or(path)
        .display()
        .to_string();
    format!("{}{inner}", "../".repeat(depth))

}

    let mut add = |scope: Scope, dir: &Path, plugin: Option<&str>| {
        for skill_dir in sorted_entries(dir) {
            let file = skill_dir.join("SKILL.md");
            let Some(text) = read_text(&file) else {
                continue;
            };
            let fields = frontmatter(text.content.as_deref().unwrap_or(""));
            let own = fields
                .get("name")
                .cloned()
                .unwrap_or_else(|| stem(&skill_dir));
            let name = qualified(plugin, &own);
            let listed = fields
                .get("disable-model-invocation")
                .is_none_or(|value| value != "true");
            let (loading, chars) = if listed {
                (
                    Loading::Listing,
                    listing_chars(&name, fields.get("description")),
                )
            } else {
                (Loading::OnDemand, text.chars)
            };
            sources.push(Source {
                kind: SourceKind::Skill,
                scope,
                name,
                path: Some(display(&file)),
                plugin: plugin.map(String::from),
                loading,
                chars,
                file_chars: text.chars,
            });
        }
    };
    add(Scope::User, &roots.claude_dir.join("skills"), None);
    if let Some(project) = &roots.project {
        add(Scope::Project, &project.join(".claude/skills"), None);
    }
    for plugin in plugins {
        add(
            Scope::Plugin,
            &plugin.dir.join("skills"),
            Some(&plugin.short),
        );
    }
}

pub fn agents(roots: &Roots, plugins: &[Plugin], sources: &mut Vec<Source>) {
    for (scope, dir, plugin) in definition_dirs(roots, plugins, "agents") {
        for file in sorted_entries(&dir).into_iter().filter(|p| is_markdown(p)) {
            let Some(text) = read_text(&file) else {
                continue;
            };
            let fields = frontmatter(text.content.as_deref().unwrap_or(""));
            let own = fields.get("name").cloned().unwrap_or_else(|| stem(&file));
            let name = qualified(plugin.as_deref(), &own);
            sources.push(Source {
                kind: SourceKind::Agent,
                scope,
                chars: listing_chars(&name, fields.get("description")),
                name,
                path: Some(display(&file)),
                plugin: plugin.clone(),
                loading: Loading::Listing,
                file_chars: text.chars,
            });
        }
    }
}

pub fn output_styles(
    roots: &Roots,
    plugins: &[Plugin],
    settings: &Settings,
    sources: &mut Vec<Source>,
) {
    for (scope, dir, plugin) in definition_dirs(roots, plugins, "output-styles") {
        for file in sorted_entries(&dir).into_iter().filter(|p| is_markdown(p)) {
            let Some(text) = read_text(&file) else {
                continue;
            };
            let fields = frontmatter(text.content.as_deref().unwrap_or(""));
            let own = fields.get("name").cloned().unwrap_or_else(|| stem(&file));
            let name = qualified(plugin.as_deref(), &own);
            let active = settings.output_style.as_deref().is_some_and(|style| {
                style.eq_ignore_ascii_case(&name) || style.eq_ignore_ascii_case(&own)
            });
            sources.push(Source {
                kind: SourceKind::OutputStyle,
                scope,
                name,
                path: Some(display(&file)),
                plugin: plugin.clone(),
                loading: if active {
                    Loading::Always
                } else {
                    Loading::Off
                },
                chars: text.chars,
                file_chars: text.chars,
            });
        }
    }
}

fn definition_dirs(
    roots: &Roots,
    plugins: &[Plugin],
    folder: &str,
) -> Vec<(Scope, PathBuf, Option<String>)> {
    let mut dirs = vec![(Scope::User, roots.claude_dir.join(folder), None)];
    if let Some(project) = &roots.project {
        dirs.push((Scope::Project, project.join(".claude").join(folder), None));
    }
    for plugin in plugins {
        dirs.push((
            Scope::Plugin,
            plugin.dir.join(folder),
            Some(plugin.short.clone()),
        ));
    }
    dirs
}

fn install_of(installed: &Value, key: &str, project: Option<&Path>) -> Option<(Scope, PathBuf)> {
    installed
        .pointer("/plugins")?
        .get(key)?
        .as_array()?
        .iter()
        .find_map(|entry| {
            let dir = PathBuf::from(entry.get("installPath")?.as_str()?);
            let scope = match entry.get("scope").and_then(Value::as_str) {
                Some("user") | None => Scope::User,
                Some(other) => {
                    let at = entry.get("projectPath").and_then(Value::as_str)?;
                    if project != Some(Path::new(at)) {
                        return None;
                    }
                    if other == "local" {
                        Scope::Local
                    } else {
                        Scope::Project
                    }
                }
            };
            Some((scope, dir))
        })
}

fn listing_chars(name: &str, description: Option<&String>) -> u64 {
    let line = format!(
        "- {name}: {}",
        description.map(String::as_str).unwrap_or("")
    );
    line.chars().count() as u64
}

fn qualified(plugin: Option<&str>, name: &str) -> String {
    match plugin {
        Some(plugin) => format!("{plugin}:{name}"),
        None => name.to_string(),
    }
}

fn stem(path: &Path) -> String {
    path.file_stem()
        .map(|stem| stem.to_string_lossy().into_owned())
        .unwrap_or_default()
}

use std::collections::BTreeMap;

use anyhow::Result;
use rusqlite::{OptionalExtension, params};

use super::{GENERATION_MARK, Store};
use crate::transcript::{Record, parse_line};

pub const PROMPT_SEARCH_LIMIT: i64 = 500;
const MAIN_THREAD: &str = "f.path NOT LIKE '%/subagents/%' AND instr(f.path, '#gen-') = 0";

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct AttachmentPoint {
    pub ts: i64,
    pub kind: String,
    pub chars: u64,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ToolResultPoint {
    pub tool: Option<String>,
    pub ts: i64,
    pub chars: u64,
    pub images: u32,
}

impl Store {
    pub fn main_attachments(&self, session_id: &str) -> Result<Vec<AttachmentPoint>> {
        let sql = format!(
            "SELECT a.ts, a.kind, a.chars FROM attachments a JOIN files f ON f.id = a.file_id
             WHERE a.session_id = ?1 AND a.ts IS NOT NULL AND {MAIN_THREAD}
             ORDER BY a.ts, a.file_id, a.line_no"
        );
        let mut statement = self.conn.prepare_cached(&sql)?;
        let rows = statement.query_map([session_id], |r| {
            Ok(AttachmentPoint {
                ts: r.get(0)?,
                kind: r.get(1)?,
                chars: r.get::<_, i64>(2)? as u64,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn main_compactions(&self, session_id: &str) -> Result<Vec<i64>> {
        let sql = format!(
            "SELECT c.ts FROM compactions c JOIN files f ON f.id = c.file_id
             WHERE c.session_id = ?1 AND c.ts IS NOT NULL AND {MAIN_THREAD} ORDER BY c.ts"
        );
        let mut statement = self.conn.prepare_cached(&sql)?;
        let rows = statement.query_map([session_id], |r| r.get(0))?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn first_prompt_chars(&self, session_id: &str) -> Result<Option<u64>> {
        let suffix = format!("/{session_id}.jsonl");
        let mut files = self
            .conn
            .prepare_cached("SELECT id, path FROM files WHERE path LIKE '%.jsonl' ORDER BY id")?;
        let ids: Vec<i64> = files
            .query_map([], |r| Ok((r.get::<_, i64>(0)?, r.get::<_, String>(1)?)))?
            .filter_map(rusqlite::Result::ok)
            .filter(|(_, path)| path.ends_with(&suffix) && !path.contains(GENERATION_MARK))
            .map(|(id, _)| id)
            .collect();
        let mut users = self.conn.prepare_cached(
            "SELECT json FROM raw_records WHERE file_id = ?1 AND kind = 'user' ORDER BY line_no LIMIT ?2",

pub fn parse(ts_ms: i64, json: &str) -> Option<Breakdown> {
    let data: Value = serde_json::from_str(json).ok()?;
    let categories = data
        .get("categories")?
        .as_array()?
        .iter()
        .filter_map(category)
        .collect();
    let skills = data.get("skills");
    Some(Breakdown {
        ts_ms,
        model: text(&data, "model").unwrap_or_default(),
        total_tokens: count(&data, "totalTokens"),
        max_tokens: count(&data, "rawMaxTokens").max(count(&data, "maxTokens")),
        percentage: data
            .get("percentage")
            .and_then(Value::as_f64)
            .unwrap_or(0.0),
        auto_compact_threshold: data
            .get("autoCompactThreshold")
            .and_then(Value::as_f64)
            .map(|v| v.max(0.0).round() as u64),
        categories,
        memory_files: each(&data, "memoryFiles", |item| {
            Some(MemoryFile {
                path: text(item, "path")?,
                kind: text(item, "type").unwrap_or_default(),
                tokens: count(item, "tokens"),
            })
        }),
        mcp_tools: each(&data, "mcpTools", |item| {
            Some(McpTool {
                name: text(item, "name")?,
                server: text(item, "serverName").unwrap_or_default(),
                tokens: count(item, "tokens"),
                loaded: item
                    .get("isLoaded")
                    .and_then(Value::as_bool)
                    .unwrap_or(true),
            })
        }),
        agents: each(&data, "agents", |item| {
            Some(Entry {
                name: text(item, "agentType")?,
                source: text(item, "source").unwrap_or_default(),
                plugin: None,
                tokens: count(item, "tokens"),
            })
        }),
        skills: skills
            .map(|skills| {
                each(skills, "skillFrontmatter", |item| {
                    Some(Entry {
                        name: text(item, "name")?,
                        source: text(item, "source").unwrap_or_default(),
                        plugin: text(item, "pluginName"),
                        tokens: count(item, "tokens"),
                    })
                })
            })
            .unwrap_or_default(),
        skills_total: skills.map_or(0, |s| count(s, "totalSkills")),
        skills_included: skills.map_or(0, |s| count(s, "includedSkills")),
    })
}

fn category(item: &Value) -> Option<Category> {
    let deferred = item
        .get("isDeferred")
        .and_then(Value::as_bool)
        .unwrap_or(false);
    let kind = match item.get("kind").and_then(Value::as_str) {
        _ if deferred => CategoryKind::Deferred,
        Some("free") => CategoryKind::Free,
        Some("buffer") => CategoryKind::Buffer,
        Some("deferred") => CategoryKind::Deferred,
        _ => CategoryKind::Used,
    };
    Some(Category {
        name: text(item, "name")?,
        tokens: count(item, "tokens"),
        color: text(item, "color").unwrap_or_default(),
        kind,
    })
}

fn each<T>(data: &Value, key: &str, read: impl Fn(&Value) -> Option<T>) -> Vec<T> {
    data.get(key)
        .and_then(Value::as_array)
        .map(|items| items.iter().filter_map(read).collect())
        .unwrap_or_default()
}

fn text(data: &Value, key: &str) -> Option<String> {
    data.get(key)?.as_str().map(String::from)
}

fn count(data: &Value, key: &str) -> u64 {
    data.get(key)
        .and_then(Value::as_f64)
        .filter(|v| v.is_finite())
        .map_or(0, |v| v.max(0.0).round() as u64)
}

use std::collections::BTreeMap;

use serde::{Deserialize, Serialize};

use super::breakdown::Breakdown;
use crate::config_scan::{Loading, Scan, SourceKind};

pub const DEFAULT_PROSE: f64 = 3.5;
pub const DEFAULT_CODE: f64 = 3.0;
pub const DEFAULT_SCHEMA: f64 = 2.5;
pub const MIN_PAIR_TOKENS: u64 = 25;
pub const MIN_PAIRS: usize = 3;
pub const MIN_FACTOR: f64 = 0.5;
pub const MAX_FACTOR: f64 = 2.0;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum TextKind {
    Prose,
    Code,
    Schema,
}

#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct Ratios {
    pub prose: f64,
    pub code: f64,
    pub schema: f64,
    pub calibrated: bool,
    pub pairs: usize,
}

impl Default for Ratios {
    fn default() -> Self {
        Self {
            prose: DEFAULT_PROSE,
            code: DEFAULT_CODE,
            schema: DEFAULT_SCHEMA,
            calibrated: false,
            pairs: 0,
        }
    }
}

impl Ratios {
    pub fn of(&self, kind: TextKind) -> f64 {
        match kind {
            TextKind::Prose => self.prose,
            TextKind::Code => self.code,
            TextKind::Schema => self.schema,
        }
    }

    pub fn tokens(&self, chars: u64, kind: TextKind) -> u64 {
        (chars as f64 / self.of(kind)).round() as u64
    }
}

pub fn calibrate(scan: &Scan, recent_first: &[Breakdown]) -> Ratios {
    let mut pairs: BTreeMap<(SourceKind, String), f64> = BTreeMap::new();
    for breakdown in recent_first {
        let measured = breakdown
            .memory_files
            .iter()
            .map(|file| {
                (
                    [SourceKind::ClaudeMd, SourceKind::Memory].as_slice(),
                    file.path.as_str(),
                    file.tokens,
                )
            })
            .chain(breakdown.skills.iter().map(|skill| {
                (
                    [SourceKind::Skill].as_slice(),
                    skill.name.as_str(),
                    skill.tokens,
                )
            }))
            .chain(breakdown.agents.iter().map(|agent| {
                (
                    [SourceKind::Agent].as_slice(),
                    agent.name.as_str(),
                    agent.tokens,
                )
            }));
        for (kinds, key, tokens) in measured {
            if tokens < MIN_PAIR_TOKENS {
                continue;
            }
            let source = scan.sources.iter().find(|source| {
                kinds.contains(&source.kind)
                    && source.loading != Loading::Off
                    && source.chars > 0
                    && match source.kind {
                        SourceKind::ClaudeMd | SourceKind::Memory => {
                            source.path.as_deref() == Some(key)
                        }
                        _ => source.name == key,
                    }
            });
            if let Some(source) = source {
                pairs
                    .entry((source.kind, key.to_string()))
                    .or_insert(source.chars as f64 / tokens as f64);
            }
        }
    }
    if pairs.len() < MIN_PAIRS {
        return Ratios::default();
    }
    let mut ratios: Vec<f64> = pairs.into_values().collect();
    ratios.sort_by(f64::total_cmp);
    let middle = ratios.len() / 2;
    let median = if ratios.len().is_multiple_of(2) {
        (ratios[middle - 1] + ratios[middle]) / 2.0
    } else {
        ratios[middle]
    };
    let factor = (median / DEFAULT_PROSE).clamp(MIN_FACTOR, MAX_FACTOR);
    Ratios {
        prose: DEFAULT_PROSE * factor,
        code: DEFAULT_CODE * factor,
        schema: DEFAULT_SCHEMA * factor,
        calibrated: true,
        pairs: ratios.len(),
    }
}

use serde::{Deserialize, Serialize};

pub fn classify(kind: &str) -> Option<(Part, TextKind)> {
    Some(match kind {
        "instructions" | "nested_memory" => (Part::Memory, TextKind::Prose),
        "skill_listing" | "invoked_skills" => (Part::Skills, TextKind::Prose),
        "mcp_instructions_delta" => (Part::Mcp, TextKind::Prose),
        "deferred_tools_delta" | "deferred_tools_record" => (Part::Mcp, TextKind::Schema),
        "agent_listing_delta" => (Part::Agents, TextKind::Prose),
        "file" | "edited_text_file" | "selected_lines_in_ide" | "compact_file_reference" => {
            (Part::Files, TextKind::Code)
        }
        "hook_additional_context" => (Part::Hooks, TextKind::Prose),
        "environment"
        | "date"
        | "model"
        | "session_context"
        | "total_tokens_reminder"
        | "silent_turn_reminder"
        | "task_status"
        | "auto_mode" => (Part::Reminders, TextKind::Prose),
        _ => return None,
    })
}

pub fn compose(
    requests: &[RequestPoint],
    attachments: &[AttachmentPoint],
    compactions: &[i64],
    first_prompt_chars: Option<u64>,
    ratios: &Ratios,
) -> Option<History> {
    let main: Vec<&RequestPoint> = requests
        .iter()
        .filter(|r| !r.is_sidechain && r.agent_id.is_none())
        .collect();
    let first = *main.first()?;
    let mut estimated: Vec<(i64, Part, u64)> = attachments
        .iter()
        .filter_map(|a| {
            classify(&a.kind).map(|(part, text)| (a.ts, part, ratios.tokens(a.chars, text)))
        })
        .collect();
    estimated.sort_by_key(|(ts, _, _)| *ts);
    let mut compactions = compactions.to_vec();
    compactions.sort_unstable();
    let initial_estimate: u64 = estimated
        .iter()
        .filter(|(ts, _, _)| *ts <= first.ts)
        .map(|(_, _, tokens)| tokens)
        .sum();
    let measured = first.tokens.prompt_total();
    let first_message = ratios.tokens(first_prompt_chars.unwrap_or(0), TextKind::Prose);
    let fixed = measured.saturating_sub(first_message);
    let (scale, system) = if initial_estimate > fixed {
        (fixed as f64 / initial_estimate as f64, 0)
    } else {
        (1.0, fixed - initial_estimate)
    };
    let scaled = |tokens: u64| (tokens as f64 * scale).round() as u64;
    let mut initial_parts: BTreeMap<Part, u64> = BTreeMap::new();
    let mut injected_later = 0;
    for (ts, part, tokens) in &estimated {
        if *ts <= first.ts {
            *initial_parts.entry(*part).or_default() += scaled(*tokens);
        } else {
            injected_later += scaled(*tokens);
        }
    }
    let mut points = Vec::with_capacity(main.len());
    let mut injected: BTreeMap<Part, u64> = BTreeMap::new();
    let (mut next_attachment, mut next_compaction) = (0, 0);
    for request in &main {
        let mut compacted = false;
        loop {
            let attachment_ts = estimated
                .get(next_attachment)
                .map(|(ts, _, _)| *ts)
                .filter(|ts| *ts <= request.ts);
            let compaction_ts = compactions
                .get(next_compaction)
                .copied()
                .filter(|ts| *ts <= request.ts);
            match (compaction_ts, attachment_ts) {
                (Some(c), a) if a.is_none_or(|a| c <= a) => {
                    injected.clear();
                    compacted = true;
                    next_compaction += 1;
                }
                (_, Some(_)) => {
                    let (_, part, tokens) = estimated[next_attachment];
                    *injected.entry(part).or_default() += scaled(tokens);
                    next_attachment += 1;
                }
                _ => break,
            }
        }
        points.push(Point {
            ts_ms: request.ts * 1000,
            prompt_tokens: request.tokens.prompt_total(),
            injected_tokens: injected.values().sum(),
            compacted,
        });
    }
    let last = points.last().copied()?;
    let mut now = vec![Share {
        part: Part::System,
        tokens: system,
    }];
    now.extend(
        injected
            .iter()
            .filter(|(_, t)| **t > 0)
            .map(|(part, tokens)| Share {
                part: *part,
                tokens: *tokens,
            }),
    );
    now.push(Share {
        part: Part::Messages,
        tokens: last
            .prompt_tokens
            .saturating_sub(system + last.injected_tokens),
    });
    let mut initial = vec![Share {
        part: Part::System,
        tokens: system,
    }];
    initial.extend(
        initial_parts
            .iter()
            .filter(|(_, t)| **t > 0)
            .map(|(part, tokens)| Share {
                part: *part,
                tokens: *tokens,
            }),
    );
    Some(History {
        first_request_ms: first.ts * 1000,
        measured_tokens: measured,
        first_message_tokens: first_message,
        scale,
        initial,
        now,
        injected_later_tokens: injected_later,
        compactions: compactions.iter().filter(|ts| **ts >= first.ts).count() as u64,
        points: thinned(points),
    })
}

fn thinned(points: Vec<Point>) -> Vec<Point> {
    if points.len() <= MAX_POINTS {
        return points;
    }
    let last = points.len() - 1;
    let mut keep: Vec<usize> = (0..MAX_POINTS)
        .map(|i| i * last / (MAX_POINTS - 1))
        .collect();
    keep.extend(
        points
            .iter()
            .enumerate()
            .filter(|(_, p)| p.compacted)
            .map(|(i, _)| i),
    );
    keep.sort_unstable();
    keep.dedup();
    keep.into_iter().map(|i| points[i]).collect()
}

use std::collections::BTreeMap;

use serde::{Deserialize, Serialize};

use super::breakdown::Breakdown;
use super::ratios::{Ratios, TextKind};
use crate::config_scan::{Loading, Scan, Scope, SourceKind};

pub const MAX_ITEMS: usize = 100;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ItemKind {
    MemoryFile,
    Skill,
    McpServer,
    Agent,
    OutputStyle,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Item {
    pub kind: ItemKind,
    pub name: String,
    pub detail: Option<String>,
    pub tokens: u64,
    pub estimated: bool,
    pub uses_session: Option<u64>,
    pub uses_14d: Option<u64>,
}

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct Uses {
    pub session_skills: BTreeMap<String, u64>,
    pub recent_skills: BTreeMap<String, u64>,
    pub session_tools: BTreeMap<String, u64>,
    pub recent_tools: BTreeMap<String, u64>,
}

pub fn items(
    breakdown: Option<&Breakdown>,
    scan: &Scan,
    ratios: &Ratios,
    uses: &Uses,
) -> Vec<Item> {
    let mut items = match breakdown {
        Some(breakdown) => measured(breakdown, scan, uses),
        None => estimated(scan, ratios, uses),
    };
    items.extend(
        scan.sources
            .iter()
            .filter(|s| s.kind == SourceKind::OutputStyle && s.loading == Loading::Always)
            .map(|style| Item {
                kind: ItemKind::OutputStyle,
                name: style.name.clone(),
                detail: Some(scope_label(style.scope).into()),
                tokens: ratios.tokens(style.chars, TextKind::Prose),
                estimated: true,
                uses_session: None,
                uses_14d: None,
            }),
    );
    items.sort_by(|a, b| {
        b.tokens
            .cmp(&a.tokens)
            .then_with(|| a.kind.cmp(&b.kind))
            .then_with(|| a.name.cmp(&b.name))
    });
    items
}

pub fn sized(items: &[Item]) -> Vec<Item> {
    items
        .iter()
        .filter(|item| item.tokens > 0)
        .take(MAX_ITEMS)
        .cloned()
        .collect()
}

pub fn dead_weight(items: &[Item]) -> Vec<Item> {
    items
        .iter()
        .filter(|item| item.tokens > 0 && item.uses_14d == Some(0))
        .cloned()
        .collect()
}

fn measured(breakdown: &Breakdown, scan: &Scan, uses: &Uses) -> Vec<Item> {
    let mut items: Vec<Item> = breakdown
        .memory_files
        .iter()
        .map(|file| Item {
            kind: ItemKind::MemoryFile,
            name: scan
                .sources
                .iter()
                .find(|s| s.path.as_deref() == Some(file.path.as_str()))
                .map(|s| s.name.clone())
                .unwrap_or_else(|| file_name(&file.path)),
            detail: Some(file.kind.clone()).filter(|kind| !kind.is_empty()),
            tokens: file.tokens,
            estimated: false,
            uses_session: None,
            uses_14d: None,
        })
        .collect();
    items.extend(breakdown.skills.iter().map(|skill| Item {
        kind: ItemKind::Skill,
        name: skill.name.clone(),
        detail: skill.plugin.clone(),
        tokens: skill.tokens,
        estimated: false,
        uses_session: Some(count(&uses.session_skills, &skill.name)),
        uses_14d: Some(count(&uses.recent_skills, &skill.name)),
    }));
    let mut servers: BTreeMap<&str, (u64, Vec<&str>)> = BTreeMap::new();
    for tool in &breakdown.mcp_tools {
        let server = servers.entry(tool.server.as_str()).or_default();
        if tool.loaded {
            server.0 += tool.tokens;
        }
        server.1.push(tool.name.as_str());
    }
    items.extend(servers.into_iter().map(|(server, (tokens, tools))| Item {
        kind: ItemKind::McpServer,
        name: server.to_string(),
        detail: Some(format!(
            "{} tool{}",
            tools.len(),
            if tools.len() == 1 { "" } else { "s" }
        )),
        tokens,
        estimated: false,
        uses_session: Some(tools.iter().map(|t| count(&uses.session_tools, t)).sum()),
        uses_14d: Some(tools.iter().map(|t| count(&uses.recent_tools, t)).sum()),
    }));
    items.extend(breakdown.agents.iter().map(|agent| Item {
        kind: ItemKind::Agent,
        name: agent.name.clone(),
        detail: None,
        tokens: agent.tokens,
        estimated: false,
        uses_session: None,
        uses_14d: None,
    }));
    items
}

fn estimated(scan: &Scan, ratios: &Ratios, uses: &Uses) -> Vec<Item> {
    scan.sources
        .iter()
        .filter_map(|source| {
            let kind = match (source.kind, source.loading) {
                (SourceKind::ClaudeMd | SourceKind::Memory, Loading::Always) => {
                    ItemKind::MemoryFile
                }
                (SourceKind::Skill, Loading::Listing) => ItemKind::Skill,
                (SourceKind::Agent, Loading::Listing) => ItemKind::Agent,
                _ => return None,
            };
            let skill = kind == ItemKind::Skill;
            Some(Item {
                kind,
                name: source.name.clone(),
                detail: if skill {
                    source.plugin.clone()
                } else {
                    Some(scope_label(source.scope).into())
                },
                tokens: ratios.tokens(source.chars, TextKind::Prose),
                estimated: true,
                uses_session: skill.then(|| count(&uses.session_skills, &source.name)),
                uses_14d: skill.then(|| count(&uses.recent_skills, &source.name)),
            })
        })
        .collect()
}

fn count(uses: &BTreeMap<String, u64>, name: &str) -> u64 {
    uses.get(name).copied().unwrap_or(0)
}

fn file_name(path: &str) -> String {
    path.rsplit('/').next().unwrap_or(path).to_string()
}

fn scope_label(scope: Scope) -> &'static str {
    match scope {
        Scope::User => "User",
        Scope::Project => "Project",
        Scope::Local => "Local",
        Scope::Nested => "Nested",
        Scope::Plugin => "Plugin",
    }
}

use std::path::PathBuf;
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant, SystemTime};

use anyhow::Result;

use super::{REBUILDING, Reply, State, epoch_ms, failure, json, session_of};

use crate::context_model::{self, ContextReport, Request};
use hyper::StatusCode;

pub const SCAN_TTL: Duration = Duration::from_secs(30);
pub const SCAN_CACHE_SIZE: usize = 16;

#[derive(Default)]
pub struct Scans {
    entries: Mutex<Vec<Cached>>,
}

struct Cached {
    roots: Roots,
    at: Instant,
    at_ms: i64,
    scan: Arc<Scan>,
}

impl Scans {
    pub fn get(&self, roots: &Roots, now: Instant) -> (Arc<Scan>, i64) {
        {
            let entries = self.entries.lock().unwrap_or_else(|p| p.into_inner());
            if let Some(cached) = entries
                .iter()
                .find(|cached| cached.roots == *roots && now.duration_since(cached.at) < SCAN_TTL)
            {
                return (cached.scan.clone(), cached.at_ms);
            }
        }
        let scan = Arc::new(config_scan::scan(roots));
        let at_ms = epoch_ms(SystemTime::now());
        let mut entries = self.entries.lock().unwrap_or_else(|p| p.into_inner());
        entries.retain(|cached| cached.roots != *roots);
        entries.push(Cached {
            roots: roots.clone(),
            at: now,
            at_ms,
            scan: scan.clone(),
        });
        if entries.len() > SCAN_CACHE_SIZE {
            entries.remove(0);
        }
        (scan, at_ms)
    }
}

import type { ThemeKey } from 'claude-code'

import type { ConfigGroup, ContextItem, ContextReport, Daemon, History, ItemKind, LiveContext, Local, Part, SourceKind } from '../types'

const CATEGORY_KINDS: Readonly<Record<string, ItemKind>> = {

const PARTS: Record<Part, { label: string; color: ThemeKey }> = {

  memory: { label: 'Memory files', color: 'autoAccept' },
  skills: { label: 'Skills', color: 'suggestion' },

const SOURCES: [SourceKind, string][] = [
  ['claude_md', 'CLAUDE.md files'],
  ['memory', 'Memory files'],
  ['skill', 'Skills'],
  ['agent', 'Agents'],
  ['output_style', 'Output styles'],

export type ContextInput = {
  width: number
  nowMs: number
  report: ContextReport | null
  local: Local
  daemon: Daemon

type Row = { key: string; name: string; tokens: number; color: ThemeKey; kind?: ItemKind }

export function themeColor(name: string): ThemeKey {
  return THEME_KEYS.find(key => key === name) ?? 'text'
}

export function reportOf(input: Pick<ContextInput, 'report' | 'local'>): ContextReport | null {
  const { report, local } = input
  return report !== null && (local.session === null || report.session === local.session) ? report : null
}

export function compositionOf(input: Pick<ContextInput, 'report' | 'local'>): LiveContext | null {
  const local = input.local.breakdown
  const stored = reportOf(input)?.live ?? null
  if (local === null) return stored
  return stored !== null && stored.ts_ms > local.ts_ms ? stored : local
}

export function contextScreen(input: ContextInput): Line[] {
  const width = Math.max(MIN_CONTENT, input.width - 2 * PADDING)
  const report = reportOf(input)
  const composition = compositionOf(input)
  const sections = [
    notice(input, width),
    headline(input, composition, width),
    composition !== null ? categories(input, composition, width) : estimate(input, report, width),
    largest(input, report, composition !== null, width),
    unused(report, width),
    toolResults(report, width),
    configured(input, report, width),
  ].filter(section => section.length > 0)
  return sections.flatMap((section, index) => (index === 0 ? section : [gap(index), ...section]))
}

function headline(input: ContextInput, composition: LiveContext | null, width: number): Line[] {
  const measure = input.local.measure
  if (composition === null && (measure === null || measure.contextPercent === null)) {
    return [plain('ctx-head', 'Context', { bold: true }), prose('ctx-empty', 'The breakdown appears after your first prompt ✻', { dim: true })]
  }
  const title = composition === null ? 'Context' : `Context · ${modelName(composition.model)}`
  const used = composition?.total_tokens ?? measure?.contextTokens ?? null
  const window = composition?.max_tokens ?? measure?.contextWindow ?? 0
  const fill = composition?.percentage ?? measure?.contextPercent ?? 0
  const amount = used === null ? tokens(window) : `${tokens(used)} / ${tokens(window)}`
  const color: ThemeKey = fill >= CONTEXT_WARNING ? 'warning' : 'text'
  const lines = [pair('ctx-head', title, amount, width, {}, { bold: true }), meter('ctx-bar', '', fill / 100, percent(fill).padStart(4), width, color)]
  const threshold = composition?.auto_compact_threshold ?? null
  if (threshold !== null && used !== null) {
    const due = used >= threshold
    const text = due ? `Auto-compact at ${tokens(threshold)} · due now` : `Auto-compact at ${tokens(threshold)} · ${tokens(threshold - used)} to go`
    lines.push(prose('ctx-compact', text, due ? { color: 'warning' } : { dim: true }))
  }
  return lines
}

function categories(input: ContextInput, composition: LiveContext, width: number): Line[] {
  const rows: Row[] = composition.categories.flatMap((category, index) =>
    category.kind === 'used'
      ? [{ key: `ctx-cat-${index}`, name: category.name, tokens: category.tokens, color: themeColor(category.color), kind: CATEGORY_KINDS[category.name] }]
      : [],
  )
  const drill = { items: reportOf(input)?.items ?? [], expanded: input.expanded }
  const lines = [heading('ctx-categories', 'By category', width, 'categories'), ...shareRows(rows, width, false, drill)]
  composition.categories.forEach((category, index) => {
    if (category.kind === 'free' || category.kind === 'buffer') {
      lines.push(pair(`ctx-cat-${index}`, `  ${category.name}`, tokens(category.tokens), width, { dim: true }, { dim: true }))
    }
  })
  const deferred = composition.categories.filter(category => category.kind === 'deferred').reduce((sum, category) => sum + category.tokens, 0)
  if (deferred > 0) lines.push(prose('ctx-deferred', `+ ${tokens(deferred)} of tool schemas load on demand`, { dim: true }, 2))
  lines.push(...injected(reportOf(input)?.history ?? null))
  if (input.expanded.includes('categories')) {
    const ago = duration(Math.max(0, input.nowMs - composition.ts_ms))
    lines.push(prose('explain-categories', `Claude Code's own /context breakdown, counted ${ago} ago after a turn. Bars share what is in use; free space and the compaction buffer are the window left. A row with ▸ opens its items.`, { dim: true }))
  }
  return lines
}

function estimate(input: ContextInput, report: ContextReport | null, width: number): Line[] {
  const history = report?.history ?? null
  if (history === null || report === null) return []
  const rows: Row[] = history.now.map(share => ({
    key: `ctx-part-${share.part}`,
    name: PARTS[share.part].label,
    tokens: share.tokens,
    color: PARTS[share.part].color,
    kind: PART_KINDS[share.part],
  }))
  const drill = { items: report.items, expanded: input.expanded }
  const lines = [heading('ctx-estimate', 'Estimated from the transcript', width, 'estimate'), ...shareRows(rows, width, true, drill), ...injected(history)]
  if (input.expanded.includes('estimate')) {
    const ratio = report.ratios.prose.toFixed(1)
    const how = report.ratios.calibrated ? `calibrated on ${report.ratios.pairs} items` : 'until a breakdown calibrates it'
    lines.push(
      prose(
        'explain-estimate',
        `Text Claude Code injected, at ${ratio} characters per token (${how}), fitted to the ${tokens(history.measured_tokens)} tokens of your first request. The rest of each request is messages.`,
        { dim: true },
      ),
    )
  }
  return lines
}

function injected(history: History | null): Line[] {
  if (history === null || (history.injected_later_tokens === 0 && history.compactions === 0)) return []
  const parts = [`~${tokens(history.injected_later_tokens)} injected since your first request`]
  if (history.compactions > 0) parts.push(`${history.compactions} compaction${history.compactions === 1 ? '' : 's'}`)
  return [prose('ctx-injected', parts.join(' · '), { dim: true })]
}

function largest(input: ContextInput, report: ContextReport | null, exact: boolean, width: number): Line[] {
  const items = report?.items.slice(0, TOP_SHOWN) ?? []
  if (items.length === 0) return []
  const lines = [heading('ctx-top', 'Largest items', width, 'items'), ...items.map((item, index) => itemRow(`ctx-top-${index}`, item, width))]
  if (input.expanded.includes('items')) {
    const how = exact ? 'counted by Claude Code' : 'estimated from their size on disk'
    lines.push(prose('explain-items', `What your setup loads into every request, ${how}. Skills and agents cost their listing line until used.`, { dim: true }))
  }
  return lines
}

function unused(report: ContextReport | null, width: number): Line[] {
  const items = report?.dead_weight ?? []
  if (items.length === 0) return []
  const total = items.reduce((sum, item) => sum + item.tokens, 0)
  const estimated = items.some(item => item.estimated)
  return [
    pair('ctx-unused', 'Not used in 14 days', `${estimated ? '~' : ''}${tokens(total)} a turn`, width, { dim: true }, { bold: true }),
    ...items.slice(0, UNUSED_SHOWN).map((item, index) => itemRow(`ctx-unused-${index}`, item, width)),
  ]
}

function toolResults(report: ContextReport | null, width: number): Line[] {
  const results = report?.tool_results.slice(0, TOOL_RESULTS_SHOWN) ?? []
  if (results.length === 0) return []
  return [
    heading('ctx-results', 'Largest tool results', width),
    ...results.map((result, index) => pair(`ctx-result-${index}`, `  ${toolName(result.tool)}`, `~${tokens(result.tokens)}`, width, {}, { dim: true })),
  ]
}

function configured(input: ContextInput, report: ContextReport | null, width: number): Line[] {
  const groups = report?.config.groups ?? []
  if (groups.length === 0) return []
  const lines = [heading('ctx-config', 'Configured', width, 'config')]
  for (const [kind, label] of SOURCES) {
    const mine = groups.filter(group => group.kind === kind)
    if (mine.length === 0) continue
    lines.push(pair(`ctx-config-${kind}`, `  ${label}`, configValue(mine), width, {}, { dim: true }))
  }
  if (input.expanded.includes('config') && report !== null) {
    const ago = duration(Math.max(0, input.nowMs - report.config.scanned_at_ms))
    lines.push(
      prose(
        'explain-config',
        `Read from disk ${ago} ago, never changed. On-demand files load when Claude works in their folder; an MCP server's size is known once a session has loaded it.`,
        { dim: true },
      ),
    )
  }
  return lines
}

function configValue(groups: ConfigGroup[]): string {
  const count = (loading: string) => groups.filter(group => group.loading === loading).reduce((sum, group) => sum + group.count, 0)
  const parts = [String(groups.reduce((sum, group) => sum + group.count, 0))]
  if (count('on_demand') > 0) parts.push(`${count('on_demand')} on demand`)
  if (count('off') > 0) parts.push(`${count('off')} off`)
  return parts.join(' · ')
}

function shareRows(rows: Row[], width: number, estimated: boolean, drill: Drill): Line[] {
  const total = rows.reduce((sum, row) => sum + row.tokens, 0)
  const labelWidth = Math.min(LABEL_COLUMNS, Math.max(...rows.map(row => row.name.length), 1))
  return rows.flatMap(row => {
    const members = row.kind === undefined ? [] : drill.items.filter(item => item.kind === row.kind)
    const toggle = members.length > 0 ? `open-${row.kind}` : undefined
    const isOpen = toggle !== undefined && drill.expanded.includes(toggle)
    const mark = toggle === undefined ? ' ' : isOpen ? '▾' : '▸'
    const label = `${mark} ${fit(row.name, labelWidth).padEnd(labelWidth)} `
    const value = `${estimated ? '~' : ''}${tokens(row.tokens)}`.padStart(VALUE_COLUMNS)
    const cells = bar(total > 0 ? row.tokens / total : 0, width - label.length - value.length - 1)
    const line: Line = {
      key: row.key,
      segments: [{ text: label, dim: true }, { text: cells.filled, color: row.color }, { text: cells.track, dim: true }, { text: ` ${value}` }],
    }
    if (toggle === undefined) return [line]
    line.toggle = toggle
    return isOpen ? [line, ...drillRows(row.key, members, width)] : [line]
  })
}

function drillRows(key: string, items: readonly ContextItem[], width: number): Line[] {
  const lines = items
    .slice(0, DRILL_SHOWN)
    .map((item, index) => pair(`${key}-item-${index}`, `    ${drillLabel(item)}`, `${item.estimated ? '~' : ''}${tokens(item.tokens)}`, width, {}, { dim: true }))
  const rest = items.slice(DRILL_SHOWN)
  if (rest.length > 0) {
    const sum = rest.reduce((total, item) => total + item.tokens, 0)
    const value = `${rest.some(item => item.estimated) ? '~' : ''}${tokens(sum)}`
    lines.push(pair(`${key}-more`, `    + ${rest.length} more`, value, width, {}, { dim: true }))
  }
  return lines
}

function drillLabel(item: ContextItem): string {
  return item.detail === null || item.kind === 'skill' ? item.name : `${item.name} · ${item.detail}`
}

function itemRow(key: string, item: ContextItem, width: number): Line {
  return pair(key, `  ${itemLabel(item)}`, `${item.estimated ? '~' : ''}${tokens(item.tokens)}`, width, {}, { dim: true })
}

function itemLabel(item: ContextItem): string {
  if (item.kind === 'memory_file') return item.detail === null ? item.name : `${item.name} · ${item.detail}`
  if (item.kind === 'mcp_server') return item.detail === null ? `MCP ${item.name}` : `MCP ${item.name} · ${item.detail}`
  if (item.kind === 'skill') return `Skill ${item.name}`
  if (item.kind === 'agent') return `Agent ${item.name}`
  return `Style ${item.name}`
}

function toolName(tool: string | null): string {
  if (tool === null) return 'A tool'
  const mcp = /^mcp__(.+?)__(.+)$/.exec(tool)
  return mcp === null ? tool : `${mcp[1]} ${mcp[2]}`
}
