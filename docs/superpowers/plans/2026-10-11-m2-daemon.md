# claude-plus Milestone 2 (Daemon and API) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A resident `claude-plus daemon` that keeps the store live by tailing transcripts, answers health, session snapshots and mod events as JSON over a private Unix socket, and is the only writer, with `import`, `stats` and `reindex` deferring to it while it runs.

**Architecture:** One writer thread owns the writable `Store` and runs every ingest, reindex and event write from a single queue, draining queued mod events between files and batches so they never wait behind a long job.
A current-thread Tokio runtime runs the notify-driven tail with debouncing, a periodic rescan, signal handling and a hyper HTTP/1 server on `~/.claude-plus/daemon.sock`, whose read routes use a second, read-only store connection.
`daemon --ensure`, `daemon stop` and the deferring CLI commands talk to it through a small synchronous hyper client, and a single instance is guaranteed by an exclusive lock on `~/.claude-plus/daemon.lock` plus a socket probe.

**Tech Stack:** Rust (edition 2024, MSRV 1.88 unchanged), new crates tokio 1.53.1, hyper 1.11.1, hyper-util 0.1.21, http-body-util 0.1.5, notify 8.2.0, rustix 1.1.5; existing rusqlite, serde, serde_json, clap, walkdir, chrono, indicatif, comfy-table, thiserror, anyhow; dev: tempfile, assert_cmd, predicates, tokio `test-util`.
Versions were checked on crates.io on 2026-10-10 and each is the newest release at least two weeks old (cutoff 2026-09-26):
tokio 1.53.1 (2026-07-20, 1.53.2 is newer than the cutoff), hyper 1.11.1 (2026-08-28, 1.12.0 is newer), hyper-util 0.1.21 (2026-09-24, MSRV 1.85), http-body-util 0.1.5, notify 8.2.0 (9.0 exists only as release candidates), rustix 1.1.5.
`cargo +1.88 check --locked --all-targets` passes with all of them.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 2 "Technology", 4 "Units" rows `ingest`, `api` and `daemon`, "Data sources", "Daemon lifecycle", 7 "Error handling and safety", 8 "Testing", 9 milestone 2: "Daemon and API: lifecycle with `--ensure`, live tail, HTTP over Unix socket, event intake from the mod").

## Decisions

The spec is silent on these points, so this plan decides them.

1. Raw mod events go to a new `events` table (schema v8: `session_id`, `kind`, `ts_ms`, `received_ms`, `json`).
   The table is not derived, so `reindex` keeps it.
2. A single writer thread owns the writable store, and ingest, imports, reindex and events all go through its queue.
   API reads use a second, read-only connection.
3. The writer drains queued mod events after every file and every committed batch of an ingest or reindex.
   Measured on 390,417 real transcript lines: `POST /events` took at most 229 ms during the 37 s cold backfill and 315 ms during an 8.8 s reindex, under the mod's 500 ms timeout.
4. While a daemon runs, `import`, `stats` and `reindex` send internal `POST /import` and `POST /reindex` requests, show progress by polling `/health`, and print the same report as a local run.
   An import's report sums every ingest the daemon finished while that import waited.
5. When a daemon holds the lock but does not answer, or reads another Claude directory, the CLI refuses to write and names `claude-plus daemon stop`.
6. Unchanged files are detected with a read before the write lock is taken, so a no-op import takes no write lock (it took 1,014 before).
   Reconcile rebuilds only the sessions an ingest touched (a full rebuild took about 80 ms before).
7. Reindex commits every 5,000 records at file boundaries and holds `meta.reindex_pending` while it runs.
   An interrupted reindex is finished by the next import or daemon scan, and `doctor` reports it.
8. `Store::begin_reindex` clears the derived tables with foreign keys switched off, which lets SQLite truncate them (1.4 s down to 18 ms on real data).
9. A failing migration reports `schema migration step N (vX) failed: <sqlite message>` without repeating the SQL.
10. The instance lock is an exclusive `flock` taken through rustix, and the lock file holds the holder's pid.
    std `File::try_lock` needs Rust 1.89, and MSRV stays 1.88.
11. `daemon --ensure` keeps a daemon of the same version and replaces one of another version.
    It waits up to 3 s for health, and it reports "Started" only when its own child became the daemon, so concurrent ensures converge on one daemon.
12. The hidden flag `--detached` (the child of `--ensure`) calls `setsid` and logs only to the file.
    The hidden flag `--rescan-secs` (default 60) exists for tests.
13. `daemon stop` sends `POST /shutdown`, waits up to 5 s for the lock to free, then sends SIGTERM to the pid in the lock file.
14. The log is `~/.claude-plus/daemon.log` with mode 0600 and lines like `2026-10-11T08:00:00.123Z info  message`, the level padded to five characters.
    Above 5 MiB it is rotated once to `daemon.log.1` when the daemon opens it, and a foreground daemon also echoes to stderr.
15. The tail watches the canonical projects directory recursively and maps paths back to the configured root.
    Changes are debounced (200 ms quiet, 1 s at most), and directories created since the last batch are walked at flush, because Linux inotify misses files written into a new nested directory before its watch exists.
    A rescan every 60 s is the fallback, and a missing projects directory is retried at every rescan.
16. Ingest lag in `/health` is the age of the oldest change notice still queued.
17. `POST /events` takes a body of at most 1 MiB (413 above) with at most 256 events, and each event is validated on its own; rejections are listed by index.
    Kinds: `session.start`, `session.end`, `session.measure`, `session.usage`, `session.compact`, `turn.step`, `turn.complete`.
    The session id has 1 to 128 characters from `[A-Za-z0-9_-]`, `ts_ms` is an integer of at least 0, and `data` is a JSON object.
18. Snapshot v1 uses millisecond timestamps, includes reconciled adjustments in tokens and cost, sorts models by cost descending, counts subagents as distinct `agent_id` values on sidechain requests, and sets `known` when the store has a session row, a request or a measure for the id.
    Later milestones may add fields without changing `v`; renaming or removing a field bumps `v`.
19. The socket path limit (103 bytes on macOS, 107 on Linux) is checked before anything is created, with a message naming `CLAUDE_PLUS_HOME`, and `doctor` shows it.
20. The crate stays Unix-only (Windows is a non-goal).
21. The spec lists insta snapshots for daemon tests; M2 pins its only JSON contract (snapshot v1) with an exact string comparison instead of adding a dependency for one assertion.
22. `cli::format::duration` renders uptimes as `45s`, `3m 12s`, `1h 5m` and `3d 4h`.

## API Contract (v1)

Everything is HTTP/1.1 over the Unix socket `~/.claude-plus/daemon.sock` (mode 0600), with JSON bodies and `content-type: application/json`.
Every error is `{"error": "<reason>"}` with the status below.

| Route | Purpose | Success | Errors |
|---|---|---|---|
| `GET /health` | Liveness, version, schema, ingest state | 200 `Health` | none |
| `GET /snapshot?session=<id>` | Session totals and the latest pushed measure, read by the mod | 200 `Snapshot` | 400 missing or invalid session, 500 store read failed |
| `POST /events` | Event intake from the mod | 200 `EventsAccepted` | 400 not JSON or no `events` array or more than 256 events, 413 body above 1 MiB, 503 daemon stopping |
| `POST /import` | Internal: the CLI's `import` and `stats` | 200 `ImportOutcome` | 503 ingest failed or daemon stopping |
| `POST /reindex` | Internal: the CLI's `reindex` | 200 `{"requests":N,"records":N}` | 503 reindex failed or daemon stopping |
| `POST /shutdown` | Internal: `daemon stop` | 202 `{"stopping":true}` | none |

A known path with the wrong method answers 405 with an `Allow` header and `{"error":"use GET for /health"}`; any other path answers 404 `{"error":"no route for GET /nope"}`.
`/history` and `/insights` belong to later milestones.

`GET /health`:

```json
{"v":1,"version":"0.1.0","schema":8,"pid":67172,"uptime_s":41,"claude_dir":"/Users/me/.claude","ingest":{"lag_ms":0,"backlog":0,"last_ingest_ms":1791664272802,"progress":null,"watching":true,"last_error":null}}
```

`ingest.progress` is `{"done":863,"total":1017}` while a scan or reindex runs, `lag_ms` is the age of the oldest queued change notice, and `last_error` holds the last ingest or reconcile failure.

use anyhow::Result;
use rusqlite::{OptionalExtension, params};

use super::{Store, Writer};

#[derive(Debug, Clone, PartialEq)]
pub struct EventRow {
    pub session_id: String,
    pub kind: String,
    pub ts_ms: i64,
    pub received_ms: i64,
    pub json: String,
}

#[derive(Debug, Clone, PartialEq)]
pub struct StoredEvent {
    pub ts_ms: i64,
    pub received_ms: i64,
    pub json: String,
}

impl Writer<'_> {
    pub fn event(&mut self, row: &EventRow) -> Result<()> {
        self.tx
            .prepare_cached(
                "INSERT INTO events (session_id, kind, ts_ms, received_ms, json) VALUES (?1, ?2, ?3, ?4, ?5)",
            )?
            .execute(params![
                row.session_id,
                row.kind,
                row.ts_ms,
                row.received_ms,
                row.json
            ])?;
        Ok(())
    }
}

impl Store {
    pub fn latest_event(&self, session_id: &str, kind: &str) -> Result<Option<StoredEvent>> {
        Ok(self
            .conn
            .prepare_cached(
                "SELECT ts_ms, received_ms, json FROM events WHERE session_id = ?1 AND kind = ?2

Reindex held the write lock for 5 to 7 s on real data.

use anyhow::Result;

use super::Store;
use crate::transcript::TokenCounts;

#[derive(Debug, Clone, Default, PartialEq)]
pub struct SessionTotals {
    pub known: bool,
    pub cost_usd: f64,
    pub reconciled_usd: f64,
    pub unpriced_requests: u64,
    pub requests: u64,
    pub subagents: u64,
    pub last_request_ts: Option<i64>,
    pub tokens: TokenCounts,
    pub models: Vec<ModelTotal>,
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct ModelTotal {
    pub model: String,
    pub requests: u64,
    pub cost_usd: f64,
    pub unpriced_requests: u64,
}

impl Store {
    pub fn session_totals(&self, session_id: &str) -> Result<SessionTotals> {
        let mut totals = SessionTotals {
            known: self
                .conn
                .prepare_cached("SELECT 1 FROM sessions WHERE id = ?1")?
                .exists([session_id])?,
            ..Default::default()
        };
        let mut requests = self.conn.prepare_cached(
            "SELECT model, COUNT(*), COALESCE(SUM(cost_usd), 0), SUM(cost_usd IS NULL), SUM(input),
                    SUM(output), SUM(thinking), SUM(cache_read), SUM(cache_write_5m),
                    SUM(cache_write_1h), MAX(ts)
             FROM requests WHERE session_id = ?1 GROUP BY model",
        )?;
        let mut rows = requests.query([session_id])?;
        while let Some(r) = rows.next()? {
            let count = |index| -> rusqlite::Result<u64> { Ok(r.get::<_, i64>(index)? as u64) };
            let model = ModelTotal {
                model: r.get(0)?,
                requests: count(1)?,
                cost_usd: r.get(2)?,
                unpriced_requests: count(3)?,
            };
            totals.known = true;
            totals.requests += model.requests;
            totals.cost_usd += model.cost_usd;
            totals.unpriced_requests += model.unpriced_requests;
            add(
                &mut totals.tokens,
                TokenCounts {
                    input: count(4)?,
                    output: count(5)?,
                    thinking: count(6)?,
                    cache_read: count(7)?,
                    cache_write_5m: count(8)?,
                    cache_write_1h: count(9)?,
                },
            );
            totals.last_request_ts = totals.last_request_ts.max(r.get(10)?);
            totals.models.push(model);
        }
        let mut adjustments = self.conn.prepare_cached(
            "SELECT model, COALESCE(SUM(cost_usd), 0), SUM(input), SUM(output), SUM(cache_read),
                    SUM(cache_write)
             FROM adjustments WHERE session_id = ?1 GROUP BY model",
        )?;
        let mut rows = adjustments.query([session_id])?;
        while let Some(r) = rows.next()? {
            let count = |index| -> rusqlite::Result<u64> { Ok(r.get::<_, i64>(index)? as u64) };
            let model: String = r.get(0)?;
            let cost_usd: f64 = r.get(1)?;
            totals.cost_usd += cost_usd;
            totals.reconciled_usd += cost_usd;
            add(
                &mut totals.tokens,
                TokenCounts {
                    input: count(2)?,
                    output: count(3)?,
                    cache_read: count(4)?,
                    cache_write_5m: count(5)?,
                    ..Default::default()
                },
            );
            match totals.models.iter_mut().find(|m| m.model == model) {
                Some(existing) => existing.cost_usd += cost_usd,
                None => totals.models.push(ModelTotal {
                    model,
                    cost_usd,
                    ..Default::default()
                }),
            }
        }
        totals.models.sort_by(|a, b| {
            b.cost_usd
                .total_cmp(&a.cost_usd)
                .then_with(|| a.model.cmp(&b.model))
        });
        totals.subagents = self.conn.query_row(
            "SELECT COUNT(DISTINCT agent_id) FROM requests
             WHERE session_id = ?1 AND is_sidechain = 1 AND agent_id IS NOT NULL",
            [session_id],
            |r| r.get::<_, i64>(0),
        )? as u64;
        Ok(totals)
    }
}

fn add(total: &mut TokenCounts, more: TokenCounts) {
    total.input += more.input;
    total.output += more.output;
    total.thinking += more.thinking;
    total.cache_read += more.cache_read;
    total.cache_write_5m += more.cache_write_5m;
    total.cache_write_1h += more.cache_write_1h;
}

mod tests {
    use super::*;

    #[test]
    fn one_holder_at_a_time_and_its_pid_is_readable() {
        let temp = tempfile::tempdir().unwrap();
        let path = temp.path().join("daemon.lock");
        assert_eq!(probe(&path).unwrap(), Holder::Free);
        assert!(!path.exists());
        let held = InstanceLock::acquire(&path).unwrap();
        let pid = Some(std::process::id());
        assert_eq!(probe(&path).unwrap(), Holder::Held { pid });
        let error = InstanceLock::acquire(&path).err().expect("must be held");
        assert_eq!(
            error.to_string(),
            format!(
                "a claude-plus daemon is already running (pid {})",
                std::process::id()
            )
        );
        assert_eq!(error.downcast_ref::<AlreadyRunning>().unwrap().pid, pid);
        drop(held);
        assert_eq!(probe(&path).unwrap(), Holder::Free);
        assert_eq!(std::fs::read_to_string(&path).unwrap(), "");
        InstanceLock::acquire(&path).unwrap();
    }

    #[test]
    fn a_probe_never_makes_the_daemon_fail_to_start() {
        let temp = tempfile::tempdir().unwrap();
        let path = temp.path().join("daemon.lock");
        std::fs::write(&path, "").unwrap();
        let prober = File::open(&path).unwrap();
        flock(&prober, FlockOperation::NonBlockingLockShared).unwrap();
        let release = std::thread::spawn(move || {
            std::thread::sleep(RETRY);
            flock(&prober, FlockOperation::Unlock).unwrap();
        });
        assert!(InstanceLock::acquire(&path).is_ok());
        release.join().unwrap();
    }

const ATTEMPTS: u32 = 5;
const RETRY: Duration = Duration::from_millis(20);

#[derive(Debug, thiserror::Error)]
#[error("a claude-plus daemon is already running{}", pid_suffix(*.pid))]
pub struct AlreadyRunning {
    pub pid: Option<u32>,
}

fn pid_suffix(pid: Option<u32>) -> String {
    pid.map(|pid| format!(" (pid {pid})")).unwrap_or_default()
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Holder {
    Free,
    Held { pid: Option<u32> },
}

pub struct InstanceLock {
    file: File,
}

impl InstanceLock {
    pub fn acquire(path: &Path) -> Result<Self> {
        let mut file = OpenOptions::new()
            .read(true)
            .write(true)
            .create(true)
            .truncate(false)
            .mode(0o600)
            .open(path)
            .with_context(|| format!("cannot open {}", path.display()))?;
        for attempt in 1..=ATTEMPTS {
            match flock(&file, FlockOperation::NonBlockingLockExclusive) {
                Ok(()) => {
                    file.set_len(0)?;
                    file.rewind()?;
                    write!(file, "{}", std::process::id())?;
                    file.flush()?;
                    return Ok(Self { file });
                }
                Err(error) if error.kind() == ErrorKind::WouldBlock && attempt < ATTEMPTS => {
                    std::thread::sleep(RETRY);
                }
                Err(error) if error.kind() == ErrorKind::WouldBlock => break,
                Err(error) => {
                    return Err(error).with_context(|| format!("cannot lock {}", path.display()));
                }
            }
        }
        Err(AlreadyRunning {
            pid: read_pid(&mut file),
        }
        .into())
    }
}

impl Drop for InstanceLock {
    fn drop(&mut self) {
        let _ = self.file.set_len(0);
    }
}

pub fn probe(path: &Path) -> Result<Holder> {
    let mut file = match File::open(path) {
        Ok(file) => file,
        Err(error) if error.kind() == ErrorKind::NotFound => return Ok(Holder::Free),
        Err(error) => return Err(error).with_context(|| format!("cannot open {}", path.display())),
    };
    match flock(&file, FlockOperation::NonBlockingLockShared) {
        Ok(()) => {
            flock(&file, FlockOperation::Unlock)?;
            Ok(Holder::Free)
        }
        Err(error) if error.kind() == ErrorKind::WouldBlock => Ok(Holder::Held {
            pid: read_pid(&mut file),
        }),
        Err(error) => Err(error).with_context(|| format!("cannot probe {}", path.display())),
    }
}

fn read_pid(file: &mut File) -> Option<u32> {
    let mut text = String::new();
    file.rewind().ok()?;
    file.read_to_string(&mut text).ok()?;
    text.trim().parse().ok()

use std::collections::BTreeSet;
use std::path::{Path, PathBuf};
use std::time::Duration;

use anyhow::{Context, Result};
use notify::{Event, EventKind, RecommendedWatcher, RecursiveMode, Watcher};
use tokio::sync::mpsc::{UnboundedReceiver, UnboundedSender, unbounded_channel};
use tokio::time::Instant;

use super::discover::is_transcript;

pub const QUIET: Duration = Duration::from_millis(200);
pub const MAX_WAIT: Duration = Duration::from_secs(1);

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Batch {
    pub paths: BTreeSet<PathBuf>,
    pub noticed_at: std::time::Instant,
}

pub struct Changes {
    receiver: UnboundedReceiver<PathBuf>,
    root: PathBuf,
    _watcher: RecommendedWatcher,
}

impl Changes {
    pub async fn next_batch(&mut self) -> Option<Batch> {
        loop {
            let batch = debounce(&mut self.receiver, QUIET, MAX_WAIT).await?;
            let root = self.root.clone();
            let paths = tokio::task::spawn_blocking(move || expand(&root, batch.paths))
                .await
                .ok()?;
            if !paths.is_empty() {
                return Some(Batch {
                    paths,
                    noticed_at: batch.noticed_at,
                });
            }
        }
    }
}

pub fn watch(projects_dir: &Path) -> Result<Changes> {
    let canonical = std::fs::canonicalize(projects_dir)
        .with_context(|| format!("cannot watch {}", projects_dir.display()))?;
    let root = projects_dir.to_path_buf();
    let (sender, receiver) = unbounded_channel();
    let watched = canonical.clone();
    let forwarded_root = root.clone();
    let mut watcher = notify::recommended_watcher(move |event: notify::Result<Event>| {
        if let Ok(event) = event {
            forward(&event, &watched, &forwarded_root, &sender);
        }
    })?;
    watcher
        .watch(&canonical, RecursiveMode::Recursive)
        .with_context(|| format!("cannot watch {}", projects_dir.display()))?;
    Ok(Changes {
        receiver,
        root,
        _watcher: watcher,
    })
}

fn forward(event: &Event, canonical: &Path, root: &Path, sender: &UnboundedSender<PathBuf>) {
    if matches!(event.kind, EventKind::Access(_)) {
        return;
    }
    for path in &event.paths {
        let Some(path) = under_root(path, canonical, root) else {
            continue;
        };
        let created_dir = matches!(event.kind, EventKind::Create(_)) && path.is_dir();
        if created_dir || is_transcript(root, &path) {
            let _ = sender.send(path);
        }
    }
}

fn expand(root: &Path, paths: BTreeSet<PathBuf>) -> BTreeSet<PathBuf> {
    let mut files = BTreeSet::new();
    for path in paths {
        if path.is_dir() {
            files.extend(
                walkdir::WalkDir::new(&path)
                    .into_iter()
                    .filter_map(Result::ok)
                    .map(walkdir::DirEntry::into_path)
                    .filter(|file| is_transcript(root, file)),
            );
        } else if is_transcript(root, &path) {
            files.insert(path);
        }
    }
    files
}

fn under_root(path: &Path, canonical: &Path, root: &Path) -> Option<PathBuf> {
    if let Ok(relative) = path.strip_prefix(canonical) {
        return Some(root.join(relative));
    }
    path.strip_prefix(root).ok().map(|_| path.to_path_buf())
}

pub async fn debounce(
    receiver: &mut UnboundedReceiver<PathBuf>,
    quiet: Duration,
    max_wait: Duration,
) -> Option<Batch> {
    let first = receiver.recv().await?;
    let noticed_at = Instant::now();
    let deadline = noticed_at + max_wait;
    let mut paths = BTreeSet::from([first]);
    loop {
        let flush_at = (Instant::now() + quiet).min(deadline);
        tokio::select! {
            next = receiver.recv() => match next {
                Some(path) => {
                    paths.insert(path);
                }
                None => break,
            },
            () = tokio::time::sleep_until(flush_at) => break,
        }
    }
    Some(Batch {
        paths,
        noticed_at: noticed_at.into_std(),
    })
}

use std::collections::{BTreeMap, VecDeque};
use std::path::PathBuf;
use std::sync::atomic::{AtomicBool, AtomicU64, Ordering};
use std::sync::{Arc, Mutex, mpsc};
use std::thread::JoinHandle;
use std::time::{Duration, Instant, SystemTime};

use anyhow::{Result, anyhow};
use tokio::sync::oneshot;

use super::log::Log;
use crate::ingest::{IngestReport, Ingestor, Rebuilt, TranscriptFile};
use crate::pricing::PriceTable;
use crate::store::{EventRow, Store};

#[derive(Debug, Clone, Default, PartialEq)]
pub struct ScanOutcome {
    pub report: IngestReport,
    pub reconcile_error: Option<String>,
}

#[derive(Debug, Clone, Default)]
pub struct IngestStatus {
    backlog: VecDeque<Instant>,
    pub last_ingest: Option<SystemTime>,
    pub progress: Option<(usize, usize)>,
    pub last_error: Option<String>,
}

impl IngestStatus {
    pub fn lag(&self, now: Instant) -> Duration {
        self.backlog.front().map_or(Duration::ZERO, |oldest| {
            now.saturating_duration_since(*oldest)
        })
    }

    pub fn backlog(&self) -> usize {
        self.backlog.len()
    }
}

type Reply<T> = oneshot::Sender<Result<T, String>>;

enum Job {
    Files(Vec<TranscriptFile>),
    Scan(Option<(u64, Reply<ScanOutcome>)>),
    Events(Vec<EventRow>, Reply<()>),
    Reindex(Reply<Rebuilt>),
    Stop,
    #[cfg(test)]
    Hold(mpsc::Receiver<()>),
}

#[derive(Default)]
struct Shared {
    status: Mutex<IngestStatus>,
    collectors: Mutex<BTreeMap<u64, IngestReport>>,
    next_collector: AtomicU64,
}

#[derive(Clone)]
pub struct WriterHandle {
    jobs: mpsc::Sender<Job>,
    shared: Arc<Shared>,
    cancel: Arc<AtomicBool>,
}

const STOPPING: &str = "the claude-plus daemon is stopping";

impl WriterHandle {
    pub fn ingest(&self, files: Vec<TranscriptFile>, noticed_at: Instant) {
        self.enqueue_ingest(Job::Files(files), noticed_at);
    }

    pub fn scan(&self) {
        self.enqueue_ingest(Job::Scan(None), Instant::now());
    }

    pub async fn import(&self) -> Result<ScanOutcome> {
        let id = self.shared.next_collector.fetch_add(1, Ordering::Relaxed);
        lock(&self.shared.collectors).insert(id, IngestReport::default());
        let (reply, answer) = oneshot::channel();
        self.enqueue_ingest(Job::Scan(Some((id, reply))), Instant::now());
        let outcome = wait(answer).await;
        lock(&self.shared.collectors).remove(&id);
        outcome
    }

    pub async fn store_events(&self, rows: Vec<EventRow>) -> Result<()> {
        let (reply, answer) = oneshot::channel();
        self.send(Job::Events(rows, reply));
        wait(answer).await
    }

    pub async fn reindex(&self) -> Result<Rebuilt> {
        let (reply, answer) = oneshot::channel();
        self.send(Job::Reindex(reply));
        wait(answer).await
    }

    pub fn status(&self) -> IngestStatus {
        lock(&self.shared.status).clone()
    }

    pub fn stop(&self) {
        self.cancel.store(true, Ordering::Relaxed);
        self.send(Job::Stop);
    }

    fn enqueue_ingest(&self, job: Job, noticed_at: Instant) {
        let mut status = lock(&self.shared.status);
        if self.jobs.send(job).is_ok() {
            status.backlog.push_back(noticed_at);
        }
    }

    fn send(&self, job: Job) {
        let _ = self.jobs.send(job);
    }

    #[cfg(test)]
    fn hold(&self) -> mpsc::Sender<()> {
        let (release, held) = mpsc::channel();
        self.send(Job::Hold(held));
        release
    }
}

async fn wait<T>(answer: oneshot::Receiver<Result<T, String>>) -> Result<T> {
    match answer.await {
        Ok(result) => result.map_err(|message| anyhow!(message)),
        Err(_) => Err(anyhow!(STOPPING)),
    }
}

fn lock<T>(mutex: &Mutex<T>) -> std::sync::MutexGuard<'_, T> {
    mutex
        .lock()
        .unwrap_or_else(|poisoned| poisoned.into_inner())
}

pub fn spawn(
    store: Store,
    prices: PriceTable,
    projects_dir: PathBuf,
    log: Arc<Log>,
) -> Result<(WriterHandle, JoinHandle<()>)> {
    let (jobs, queue) = mpsc::channel();
    let handle = WriterHandle {
        jobs,
        shared: Arc::new(Shared::default()),
        cancel: Arc::new(AtomicBool::new(false)),
    };
    let mut worker = Worker {
        store,
        prices,
        projects_dir,
        log,
        shared: handle.shared.clone(),
        cancel: handle.cancel.clone(),
    };
    let thread = std::thread::Builder::new()
        .name("claude-plus-writer".into())
        .spawn(move || worker.run(queue))?;
    Ok((handle, thread))
}

struct Worker {
    store: Store,
    prices: PriceTable,
    projects_dir: PathBuf,
    log: Arc<Log>,
    shared: Arc<Shared>,
    cancel: Arc<AtomicBool>,
}

impl Worker {
    fn run(&mut self, queue: mpsc::Receiver<Job>) {
        let mut deferred = VecDeque::new();
        loop {
            let Some(job) = deferred.pop_front().or_else(|| queue.recv().ok()) else {
                break;
            };
            if self.cancel.load(Ordering::Relaxed) {
                break;
            }
            let mut drain = |store: &mut Store| {
                while let Ok(job) = queue.try_recv() {
                    match job {
                        Job::Events(rows, reply) => answer(reply, store_events(store, &rows)),
                        #[cfg(test)]
                        Job::Hold(held) => {
                            let _ = held.recv();
                        }
                        other => deferred.push_back(other),
                    }
                }
            };
            match job {
                Job::Files(files) => {
                    let outcome = self.ingest_files(&files, &mut drain);
                    self.finish_ingest(outcome, None);
                }
                Job::Scan(reply) => {
                    let outcome = self.scan(&mut drain);
                    self.finish_ingest(outcome, reply);
                }
                Job::Events(rows, reply) => answer(reply, store_events(&mut self.store, &rows)),
                Job::Reindex(reply) => answer(reply, self.reindex(&mut drain)),
                Job::Stop => break,
                #[cfg(test)]
                Job::Hold(held) => {
                    let _ = held.recv();
                }
            }
        }
    }

    fn ingestor<'a>(&'a mut self, drain: &'a mut dyn FnMut(&mut Store)) -> Ingestor<'a> {
        Ingestor::new(&mut self.store, &self.prices)
            .cancelled_by(&self.cancel)
            .pausing_with(drain)
    }

    fn ingest_files(
        &mut self,
        files: &[TranscriptFile],
        drain: &mut dyn FnMut(&mut Store),
    ) -> Result<ScanOutcome> {
        let mut ingestor = self.ingestor(drain);
        let report = ingestor.ingest_listed(files, &mut |_, _| {})?;
        Ok(reconciled(&mut ingestor, report))
    }

    fn scan(&mut self, drain: &mut dyn FnMut(&mut Store)) -> Result<ScanOutcome> {
        let shared = self.shared.clone();
        let mut progress = |done: usize, total: usize| {
            lock(&shared.status).progress = Some((done, total));
        };
        let projects_dir = self.projects_dir.clone();
        let mut ingestor = self.ingestor(drain);
        ingestor.finish_interrupted_reindex(&mut progress)?;
        let report = ingestor.ingest_all(&projects_dir, &mut progress)?;
        Ok(reconciled(&mut ingestor, report))
    }

    fn finish_ingest(
        &mut self,
        outcome: Result<ScanOutcome>,
        reply: Option<(u64, Reply<ScanOutcome>)>,
    ) {
        let outcome = outcome.map_err(|error| format!("{error:#}"));
        let problem = match &outcome {
            Ok(done) => done
                .reconcile_error
                .as_ref()
                .map(|error| format!("reconcile failed: {error}")),
            Err(error) => Some(format!("ingest failed: {error}")),
        };
        if let Some(problem) = &problem {
            self.log.warn(problem);
        }
        {
            let mut status = lock(&self.shared.status);
            status.backlog.pop_front();
            status.progress = None;
            status.last_error = problem;
            if let Ok(done) = &outcome {
                status.last_ingest = Some(SystemTime::now());
                for collected in lock(&self.shared.collectors).values_mut() {
                    collected.add(&done.report);
                }
            }
        }
        if let Some((id, reply)) = reply {
            let collected = lock(&self.shared.collectors).remove(&id);
            let _ = reply.send(outcome.map(|done| ScanOutcome {
                report: collected.unwrap_or(done.report),
                reconcile_error: done.reconcile_error,
            }));
        }
    }

    fn reindex(&mut self, drain: &mut dyn FnMut(&mut Store)) -> Result<Rebuilt> {
        let shared = self.shared.clone();
        let rebuilt = self.ingestor(drain).reindex(&mut |done, total| {
            lock(&shared.status).progress = Some((done, total));
        });
        lock(&self.shared.status).progress = None;
        rebuilt
    }
}

fn store_events(store: &mut Store, rows: &[EventRow]) -> Result<()> {
    let mut writer = store.writer()?;
    for row in rows {
        writer.event(row)?;
    }
    writer.commit()
}

fn answer<T>(reply: Reply<T>, result: Result<T>) {
    let _ = reply.send(result.map_err(|error| format!("{error:#}")));
}

fn reconciled(ingestor: &mut Ingestor, report: IngestReport) -> ScanOutcome {
    let reconcile_error = ingestor
        .reconcile(&report)
        .err()
        .map(|error| format!("{error:#}"));
    ScanOutcome {
        report,
        reconcile_error,
    }
}

        path: &str,
        body: Option<Vec<u8>>,
    ) -> Result<(StatusCode, Bytes), ClientError> {
        self.runtime
            .block_on(exchange(&self.socket, method, path, body, self.timeout))

    fn call<T: DeserializeOwned>(
        &self,
        method: Method,
        path: &str,
        body: Option<Vec<u8>>,
        timeout: Duration,
    ) -> Result<T, ClientError> {
        let (status, bytes) =

                .block_on(exchange(&self.socket, method, path, body, timeout))?;

            let message = serde_json::from_slice::<ErrorBody>(&bytes)

                .unwrap_or_else(|_| String::from_utf8_lossy(&bytes).into_owned());
            return Err(ClientError::Status {
                status: status.as_u16(),
                message,
            });
        }
        serde_json::from_slice(&bytes).map_err(|error| ClientError::Transport(error.to_string()))
    }

async fn exchange(
    socket: &Path,
    method: Method,
    path: &str,
    body: Option<Vec<u8>>,
    timeout: Duration,
) -> Result<(StatusCode, Bytes), ClientError> {
    let transport = |error: &dyn std::fmt::Display| ClientError::Transport(error.to_string());
    let attempt = async {
        let stream = UnixStream::connect(socket)
            .await
            .map_err(|error| match error.kind() {
                ErrorKind::NotFound | ErrorKind::ConnectionRefused => {
                    ClientError::NotRunning(socket.display().to_string())
                }
                _ => transport(&error),
            })?;
        let (mut sender, connection) = hyper::client::conn::http1::handshake(TokioIo::new(stream))
            .await
            .map_err(|e| transport(&e))?;
        tokio::spawn(connection);
        let mut request = Request::builder()
            .method(method)
            .uri(path)
            .header(HOST, "claude-plus");
        if body.is_some() {
            request = request.header(CONTENT_TYPE, "application/json");
        }
        let request = request
            .body(Full::new(Bytes::from(body.unwrap_or_default())))
            .map_err(|e| transport(&e))?;
        let response = sender
            .send_request(request)
            .await
            .map_err(|e| transport(&e))?;
        let status = response.status();
        let bytes = response
            .into_body()
            .collect()
            .await
            .map_err(|e| transport(&e))?
            .to_bytes();
        Ok((status, bytes))
    };
    tokio::time::timeout(timeout, attempt)
        .await
        .unwrap_or(Err(ClientError::Timeout(timeout.as_millis())))
}

                    continue;

    Health {
        v: API_VERSION,
        version: env!("CARGO_PKG_VERSION").to_string(),
        schema: Store::latest_schema_version(),
        pid: std::process::id(),

        ingest: IngestHealth {

            last_ingest_ms: status.last_ingest.map(epoch_ms),
            progress: status

            watching: state.watching.load(Ordering::Relaxed),
            last_error: status.last_error,
        },
    }
}

async fn snapshot(state: Arc<State>, query: Option<&str>) -> Reply {
    let session = query
        .unwrap_or("")
        .split('&')
        .find_map(|pair| pair.strip_prefix("session="))
        .map(str::to_string);
    let Some(session) = session else {
        return failure(
            StatusCode::BAD_REQUEST,
            "session query parameter is required",
        );
    };
    if !events::is_session_id(&session) {
        return failure(StatusCode::BAD_REQUEST, events::SESSION_RULE);
    }
    let built = tokio::task::spawn_blocking(move || -> Result<Snapshot> {
        let reader = state.reader.lock().unwrap_or_else(|p| p.into_inner());
        let totals = reader.session_totals(&session)?;
        let measure = reader.latest_event(&session, MEASURE_KIND)?;
        Snapshot::of(&session, totals, measure, epoch_ms(SystemTime::now()))
    })
    .await;
    match built {
        Ok(Ok(snapshot)) => json(StatusCode::OK, &snapshot),
        Ok(Err(error)) => failure(StatusCode::INTERNAL_SERVER_ERROR, format!("{error:#}")),
        Err(error) => failure(StatusCode::INTERNAL_SERVER_ERROR, error.to_string()),
    }
}

async fn events<B>(state: Arc<State>, body: B) -> Reply
where
    B: Body<Data = Bytes>,
    B::Error: Into<Box<dyn std::error::Error + Send + Sync>>,
{
    let bytes = match Limited::new(body, MAX_BODY_BYTES).collect().await {
        Ok(collected) => collected.to_bytes(),
        Err(error) if error.is::<LengthLimitError>() => {
            return failure(
                StatusCode::PAYLOAD_TOO_LARGE,
                "request body is larger than 1 MiB",
            );
        }
        Err(error) => return failure(StatusCode::BAD_REQUEST, error.to_string()),
    };
    let body: serde_json::Value = match serde_json::from_slice(&bytes) {
        Ok(body) => body,
        Err(error) => {
            return failure(
                StatusCode::BAD_REQUEST,
                format!("body is not valid JSON: {error}"),
            );
        }
    };
    let validated = match events::validate(&body, epoch_ms(SystemTime::now())) {
        Ok(validated) => validated,
        Err(message) => return failure(StatusCode::BAD_REQUEST, message),
    };
    let accepted = validated.rows.len();
    if accepted > 0
        && let Err(error) = state.writer.store_events(validated.rows).await
    {
        return failure(StatusCode::SERVICE_UNAVAILABLE, format!("{error:#}"));
    }
    json(
        StatusCode::OK,
        &EventsAccepted {
            accepted,
            rejected: validated.rejected,
        },
    )
}

fn json(status: StatusCode, body: &impl Serialize) -> Reply {
    let bytes = serde_json::to_vec(body).expect("wire types serialize");
    Response::builder()
        .status(status)
        .header(CONTENT_TYPE, "application/json")
        .body(Full::new(Bytes::from(bytes)))
        .expect("valid response")
}

fn failure(status: StatusCode, message: impl Into<String>) -> Reply {
    json(
        status,
        &ErrorBody {
            error: message.into(),
        },
    )
}

pub fn epoch_ms(time: SystemTime) -> i64 {
    time.duration_since(UNIX_EPOCH)
        .map(|d| i64::try_from(d.as_millis()).unwrap_or(i64::MAX))
        .unwrap_or(0)
}

struct Foreground {
    child: Child,
}

impl Foreground {
    fn start(env: &Env, extra: &[&str]) -> Self {
        let child = process(env, &[&["daemon"], extra].concat())
            .stdin(Stdio::null())
            .stdout(Stdio::null())
            .stderr(Stdio::null())
            .spawn()
            .unwrap();
        let daemon = Self { child };
        eventually("the daemon to answer", || health(env));
        daemon
    }

    fn signal(&self, signal: Signal) {
        let pid = Pid::from_raw(self.child.id() as i32).unwrap();
        kill_process(pid, signal).unwrap();
    }
}

    fn drop(&mut self) {
        if self.child.try_wait().ok().flatten().is_none() {
            self.signal(Signal::TERM);
            let _ = self.child.wait();
        }
    }

    match status {
        Status::Running(health) if health.version == version => Next::Keep(health),
        Status::Running(health) => Next::Replace(health),
        Status::NotRunning => Next::Start,
        Status::Unresponsive { pid } => Next::Wait(pid),

pub fn stop(paths: &Paths) -> Result<Stopped> {

        Status::NotRunning => return Ok(Stopped::NotRunning),
        Status::Running(health) => {
            let _ = Client::new(&paths.socket())
                .with_timeout(PROBE_TIMEOUT)
                .shutdown();
            Some(health.pid)
        }
        Status::Unresponsive { .. } => None,
    };
    if let Some(pid) = asked
        && wait_until_free(paths, STOP_TIMEOUT)?
    {
        return Ok(Stopped::Stopped { pid });
    }
    let pid = match probe(&paths.daemon_lock())? {
        Holder::Free => {
            return Ok(Stopped::Stopped {
                pid: asked.unwrap_or(0),
            });
        }
        Holder::Held { pid: Some(pid) } => pid,
        Holder::Held { pid: None } => bail!(unresponsive(paths, None)),
    };

        .with_context(|| format!("invalid daemon pid {pid}"))?;

        return Ok(Stopped::Stopped { pid });

    let mut child = Command::new(std::env::current_exe()?)
        .args(["daemon", "--detached"])
        .stdin(Stdio::null())
        .stdout(Stdio::null())
        .stderr(Stdio::null())
        .spawn()

            return Some(health);
        }
        if Instant::now() >= deadline {
            return None;
        }
        std::thread::sleep(POLL);
    }

    let deadline = Instant::now() + timeout;

        if probe(&paths.daemon_lock())? == Holder::Free {
            return Ok(true);
        }
        if Instant::now() >= deadline {
            return Ok(false);
        }
        std::thread::sleep(POLL);
    }
}
