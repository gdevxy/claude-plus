# claude-plus Milestone 1 (Core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Rust CLI that imports every Claude Code transcript into a local SQLite store with exact per-request costs, and reports them with `claude-plus import`, `claude-plus stats`, `claude-plus doctor` and `claude-plus reindex`.

**Architecture:** One crate with a library (`src/lib.rs`) and a thin binary (`src/main.rs`).
Transcript lines are parsed into typed records by `transcript`, priced by `pricing`, written by `store` and driven by `ingest`, which streams files from per-file byte checkpoints.
The CLI layer only wires these together and formats output.

**Tech Stack:** Rust 1.99 stable (edition 2024), rusqlite (bundled SQLite), serde_json, toml, chrono, clap, walkdir, indicatif, comfy-table, thiserror, anyhow; dev: tempfile, assert_cmd, predicates.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 4 "Units", "Transcript facts verified on real data", "Storage schema", 5 "Request cost", 7, 8, milestone 1).

## Global Constraints

- Toolchain PATH for every shell: `export PATH="/opt/homebrew/opt/rustup/bin:$HOME/.cargo/bin:$PATH"`.
- Never use the em dash character anywhere (code, comments, docs, output strings); use `-`.
- No code comments unless absolutely necessary; self-explanatory names instead.
- Every Markdown sentence on its own line.
- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` must pass at the end of every task.
- No network access anywhere in the binary.
- `~/.claude` is resolved from `CLAUDE_CONFIG_DIR` when set; `~/.claude-plus` from `CLAUDE_PLUS_HOME` when set.
- The data directory is created with mode 0700, the database file with 0600.
- The parser must never panic on any input line.
- Requests are deduplicated on `requestId`, falling back to `message.id`, then the record `uuid`.
- Unknown models are never priced by guess: `cost_usd` is NULL and they are counted as unpriced.
- Commit messages use Conventional Commits and never include a co-author line.

## Review Focus

1. A response written as several records with the same `requestId`, and the same request present again in a resumed or forked session file, must count once, with the final (highest) `output_tokens` of its streamed records (Task 4 test `streamed_records_keep_the_highest_output`, Task 5 tests `duplicate_requests_across_records_and_files_count_once` and `streamed_output_keeps_final_usage`).
2. A transcript line half-written by Claude Code while importing must not be an error and must be imported on the next run (Task 5 test `truncated_last_line_is_picked_up_later`).
3. An import interrupted midway on gigabytes of history must resume without double counting and with bounded memory (Task 5 test `resume_from_checkpoint_after_partial_import`, batched commits).
4. Dated, bracketed, unknown and `<synthetic>` model ids: dated and bracketed normalize to a priced model, unknown stays unpriced and counted, synthetic is skipped (Task 3 tests and Task 5 test `synthetic_and_unknown_models`).
5. Null or missing usage fields and non-UTF-8 bytes must be treated as zero or replaced, never panic (Task 2 tests `null_usage_fields_are_zero`, `garbage_lines_error_without_panic`, Task 5 test `non_utf8_bytes_are_tolerated`).

impl Paths {
    pub fn from_env() -> Result<Self> {
        let home = std::env::var_os("HOME").map(PathBuf::from).context("HOME is not set")?;
        Ok(Self::resolve(
            &home,
            std::env::var_os("CLAUDE_CONFIG_DIR").map(PathBuf::from),
            std::env::var_os("CLAUDE_PLUS_HOME").map(PathBuf::from),
        ))
    }

    pub fn resolve(home: &Path, claude_config_dir: Option<PathBuf>, plus_home: Option<PathBuf>) -> Self {
        Self {
            claude_dir: claude_config_dir.unwrap_or_else(|| home.join(".claude")),
            data_dir: plus_home.unwrap_or_else(|| home.join(".claude-plus")),
        }
    }

    pub fn projects_dir(&self) -> PathBuf {
        self.claude_dir.join("projects")
    }

    pub fn database(&self) -> PathBuf {
        self.data_dir.join("data.db")
    }

    pub fn settings_file(&self) -> PathBuf {
        self.claude_dir.join("settings.json")
    }

    pub fn ensure_data_dir(&self) -> Result<()> {
        std::fs::create_dir_all(&self.data_dir)
            .with_context(|| format!("cannot create {}", self.data_dir.display()))?;
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            std::fs::set_permissions(&self.data_dir, std::fs::Permissions::from_mode(0o700))?;
        }
        Ok(())
    }
}

pub fn string_chars(value: &Value) -> u64 {
    match value {
        Value::String(s) => s.chars().count() as u64,
        Value::Array(items) => items.iter().map(string_chars).sum(),
        Value::Object(map) => match shrunk_length(map) {
            Some(length) => length,
            None => map.values().map(string_chars).sum(),
        },
        _ => 0,
    }
}

pub fn shrink(value: &Value, max_len: usize) -> Value {
    match value {
        Value::String(s) if s.len() > max_len => json!({ SHRUNK_KEY: s.chars().count() }),
        Value::Array(items) => Value::Array(items.iter().map(|item| shrink(item, max_len)).collect()),
        Value::Object(map) => Value::Object(
            map.iter().map(|(key, item)| (key.clone(), shrink(item, max_len))).collect::<Map<_, _>>(),
        ),
        other => other.clone(),
    }
}

fn shrunk_length(map: &Map<String, Value>) -> Option<u64> {
    if map.len() == 1 { map.get(SHRUNK_KEY)?.as_u64() } else { None }
}

impl TokenCounts {
    pub fn from_usage(usage: &Value) -> Self {
        let total_write = number(usage, "/cache_creation_input_tokens");
        let write_1h = number(usage, "/cache_creation/ephemeral_1h_input_tokens");
        let write_5m = usage
            .pointer("/cache_creation/ephemeral_5m_input_tokens")
            .and_then(Value::as_u64)
            .unwrap_or_else(|| total_write.saturating_sub(write_1h));
        Self {
            input: number(usage, "/input_tokens"),
            output: number(usage, "/output_tokens"),
            thinking: number(usage, "/output_tokens_details/thinking_tokens"),
            cache_read: number(usage, "/cache_read_input_tokens"),
            cache_write_5m: write_5m,
            cache_write_1h: write_1h,
        }
    }

    pub fn cache_write(&self) -> u64 {
        self.cache_write_5m + self.cache_write_1h
    }

    pub fn prompt_total(&self) -> u64 {
        self.input + self.cache_read + self.cache_write()
    }

    pub fn is_empty(&self) -> bool {
        self.prompt_total() == 0 && self.output == 0
    }
}

fn number(value: &Value, pointer: &str) -> u64 {

pub fn parse_value(raw: Value) -> Result<Parsed, ParseError> {
    if !raw.is_object() {
        return Err(ParseError::NotAnObject);
    }
    let record = match text(&raw, "/type").as_deref() {
        Some("assistant") => Record::Assistant(assistant(&raw)),
        Some("user") => Record::User(user(&raw)),
        Some("attachment") => Record::Attachment(attachment(&raw)),
        Some("system") if text(&raw, "/subtype").as_deref() == Some("compact_boundary") => {

        Some("cost-state") => Record::CostState(cost_state(&raw)),
        Some("custom-title") => title(&raw, "/customTitle", true),
        Some("ai-title") => title(&raw, "/aiTitle", false),
        Some(kind) => Record::Other { kind: kind.to_string() },
        None => Record::Other { kind: "unknown".to_string() },

            Some(ToolUse {
                id: text(block, "/id")?,
                name: text(block, "/name")?,
                input_chars: block.get("input").map(string_chars).unwrap_or(0),
            })
        })
        .collect();
    AssistantRecord {
        common: common(raw),

        tool_uses,
        skill: text(raw, "/attributionSkill"),
        mcp_server: text(raw, "/attributionMcpServer"),
        effort: text(raw, "/perTurnEffort").or_else(|| text(raw, "/effort")),
    }
}

fn user(raw: &Value) -> UserRecord {
    let is_meta = raw.pointer("/isMeta").and_then(Value::as_bool).unwrap_or(false);
    let content = raw.pointer("/message/content");
    let tool_results: Vec<ToolResult> = blocks(raw)
        .filter(|block| text(block, "/type").as_deref() == Some("tool_result"))
        .filter_map(|block| {
            Some(ToolResult {
                tool_use_id: text(block, "/tool_use_id")?,
                chars: block.get("content").map(string_chars).unwrap_or(0),
                is_error: block.get("is_error").and_then(Value::as_bool).unwrap_or(false),
            })
        })
        .collect();
    let text_chars = match content {
        Some(Value::String(s)) => s.chars().count() as u64,
        _ => blocks(raw)
            .filter(|block| text(block, "/type").as_deref() == Some("text"))
            .map(|block| block.get("text").map(string_chars).unwrap_or(0))
            .sum(),
    };
    UserRecord {
        common: common(raw),
        is_prompt: !is_meta && tool_results.is_empty() && text_chars > 0,
        text_chars,
        tool_results,
    }
}

fn attachment(raw: &Value) -> AttachmentRecord {
    let body = raw.get("attachment").cloned().unwrap_or(Value::Null);
    let mut names = strings(&body, "/names");
    names.extend(strings(&body, "/addedNames"));
    names.extend(field_of_each(&body, "/files", "/path"));
    names.extend(field_of_each(&body, "/entries", "/name"));
    if let Some(path) = text(&body, "/path") {
        names.push(path);
    }
    AttachmentRecord {
        common: common(raw),
        kind: text(&body, "/type").unwrap_or_else(|| "unknown".to_string()),
        chars: string_chars(&body),
        names,
    }
}

        trigger: text(raw, "/compactMetadata/trigger"),
        pre_tokens: raw.pointer("/compactMetadata/preTokens").and_then(Value::as_u64),
        post_tokens: raw.pointer("/compactMetadata/postTokens").and_then(Value::as_u64),
    }
}

        .and_then(Value::as_object)
        .map(|models| {
            models
                .iter()
                .filter_map(|(model, usage)| Some((model.clone(), usage.get("costUSD")?.as_f64()?)))

        .unwrap_or_default();

        Some(title) => Record::Title(TitleRecord { session_id: text(raw, "/sessionId"), title, is_custom }),
        None => Record::Other { kind: text(raw, "/type").unwrap_or_default() },

    raw.pointer("/message/content").and_then(Value::as_array).into_iter().flatten()

    value.pointer(pointer).and_then(Value::as_str).map(str::to_string)
}

fn strings(value: &Value, pointer: &str) -> Vec<String> {
    value
        .pointer(pointer)
        .and_then(Value::as_array)
        .map(|items| items.iter().filter_map(Value::as_str).map(str::to_string).collect())
        .unwrap_or_default()
}

    value
        .pointer(array)
        .and_then(Value::as_array)
        .map(|items| items.iter().filter_map(|item| text(item, field)).collect())
        .unwrap_or_default()
}

#[derive(Debug, Clone, Deserialize)]
pub struct PriceTable {
    version: String,
    #[serde(default = "default_write_5m")]
    cache_write_5m_multiplier: f64,
    #[serde(default = "default_write_1h")]
    cache_write_1h_multiplier: f64,
    #[serde(default)]
    models: BTreeMap<String, ModelPrice>,
}

#[derive(Debug, Clone, Deserialize)]
struct ModelPrice {
    input: f64,
    output: f64,
    cache_read: f64,
    #[serde(default)]
    tiers: Vec<Tier>,
}

#[derive(Debug, Clone, Deserialize)]
struct Tier {
    above_prompt_tokens: u64,
    input: f64,
    output: f64,
    cache_read: f64,
}

struct Rates {
    input: f64,
    output: f64,
    cache_read: f64,
}

fn default_write_5m() -> f64 {
    1.25
}

fn default_write_1h() -> f64 {
    2.0
}

impl PriceTable {
    pub fn bundled() -> Self {
        Self::from_toml(BUNDLED).expect("bundled price table is valid")
    }

    pub fn from_toml(source: &str) -> Result<Self> {
        toml::from_str(source).context("invalid price table")
    }

    pub fn merged_with(mut self, overrides: PriceTable) -> Self {
        self.version = format!("{}+{}", self.version, overrides.version);
        self.models.extend(overrides.models);
        self
    }

    pub fn version(&self) -> &str {
        &self.version
    }

    pub fn knows(&self, model: &str) -> bool {
        self.models.contains_key(normalize_model(model))
    }

    pub fn cost(&self, model: &str, tokens: &TokenCounts) -> Option<f64> {
        let price = self.models.get(normalize_model(model))?;
        let rates = price.rates_for(tokens.prompt_total());
        let usd = tokens.input as f64 * rates.input
            + tokens.cache_write_5m as f64 * rates.input * self.cache_write_5m_multiplier
            + tokens.cache_write_1h as f64 * rates.input * self.cache_write_1h_multiplier
            + tokens.cache_read as f64 * rates.cache_read
            + tokens.output as f64 * rates.output;
        Some(usd / PER_MILLION)
    }
}

impl ModelPrice {
    fn rates_for(&self, prompt_tokens: u64) -> Rates {
        self.tiers
            .iter()
            .filter(|tier| prompt_tokens > tier.above_prompt_tokens)
            .max_by_key(|tier| tier.above_prompt_tokens)
            .map(|tier| Rates { input: tier.input, output: tier.output, cache_read: tier.cache_read })
            .unwrap_or(Rates { input: self.input, output: self.output, cache_read: self.cache_read })
    }
}

pub fn normalize_model(model: &str) -> &str {
    let without_bracket = model.split('[').next().unwrap_or(model);
    match without_bracket.rsplit_once('-') {
        Some((base, suffix)) if suffix.len() == 8 && suffix.bytes().all(|b| b.is_ascii_digit()) => base,
        _ => without_bracket,
    }
}

    pub fn file(&mut self, path: &str, size: u64, mtime: i64) -> Result<i64> {
        let existing: Option<i64> =
            self.tx.query_row("SELECT id FROM files WHERE path = ?1", [path], |r| r.get(0)).optional()?;
        if let Some(id) = existing {
            return Ok(id);
        }
        self.tx.execute("INSERT INTO files (path, size, mtime) VALUES (?1, ?2, ?3)", params![path, size as i64, mtime])?;
        Ok(self.tx.last_insert_rowid())
    }

    pub fn advance_file(&mut self, file_id: i64, offset: u64, lines: u64, size: u64, mtime: i64, new_parse_errors: u64) -> Result<()> {
        self.tx.execute(
            "UPDATE files SET offset = ?2, lines = ?3, size = ?4, mtime = ?5, parse_errors = parse_errors + ?6 WHERE id = ?1",
            params![file_id, offset as i64, lines as i64, size as i64, mtime, new_parse_errors as i64],
        )?;
        Ok(())
    }

    pub fn reset_file(&mut self, file_id: i64) -> Result<()> {
        self.tx.execute("UPDATE files SET offset = 0, lines = 0, parse_errors = 0 WHERE id = ?1", [file_id])?;
        Ok(())
    }

    pub fn raw(&mut self, file_id: i64, line_no: u64, kind: &str, json: &str) -> Result<()> {
        self.tx.execute(
            "INSERT OR REPLACE INTO raw_records (file_id, line_no, kind, json) VALUES (?1, ?2, ?3, ?4)",
            params![file_id, line_no as i64, kind, json],
        )?;
        Ok(())
    }

    pub fn session(&mut self, row: &SessionRow) -> Result<()> {
        self.tx.execute(
            "INSERT INTO sessions (id, project, cwd, started_at, last_seen_at) VALUES (?1, ?2, ?3, ?4, ?4)
             ON CONFLICT(id) DO UPDATE SET
               cwd = COALESCE(sessions.cwd, excluded.cwd),
               started_at = CASE WHEN excluded.started_at IS NULL THEN sessions.started_at
                                 WHEN sessions.started_at IS NULL THEN excluded.started_at
                                 ELSE MIN(sessions.started_at, excluded.started_at) END,
               last_seen_at = CASE WHEN excluded.last_seen_at IS NULL THEN sessions.last_seen_at
                                   WHEN sessions.last_seen_at IS NULL THEN excluded.last_seen_at
                                   ELSE MAX(sessions.last_seen_at, excluded.last_seen_at) END",
            params![row.id, row.project, row.cwd, row.ts],
        )?;
        Ok(())

        let stored_output: Option<i64> =

        if stored_output.is_some_and(|output| output >= t.output as i64) {
            return Ok(RequestWrite::Unchanged);

               input = excluded.input, output = excluded.output, thinking = excluded.thinking,

        conn.pragma_update(None, "journal_mode", "WAL")?;
        conn.pragma_update(None, "synchronous", "NORMAL")?;
        Self::migrated(conn)

        Self::migrated(Connection::open_in_memory()?)
    }

    fn migrated(mut conn: Connection) -> Result<Self> {
        let current: usize = conn.pragma_query_value(None, "user_version", |r| r.get::<_, i64>(0))? as usize;
        let tx = conn.transaction()?;
        for migration in &schema::MIGRATIONS[current.min(schema::MIGRATIONS.len())..] {
            tx.execute_batch(migration)?;
        }
        tx.pragma_update(None, "user_version", schema::MIGRATIONS.len() as i64)?;
        tx.commit()?;
        Ok(Self { conn })

        Ok(Writer { tx: self.conn.transaction()? })

    pub fn daily_costs(&self, since_ts: i64, offset_seconds: i32) -> Result<Vec<DailyCost>> {
        let offset = FixedOffset::east_opt(offset_seconds).context("invalid UTC offset")?;
        let mut statement = self.conn.prepare(
            "SELECT ts, model, cost_usd FROM requests WHERE ts >= ?1 ORDER BY ts",
        )?;
        let mut grouped: std::collections::BTreeMap<(NaiveDate, String), DailyCost> = Default::default();
        let rows = statement.query_map([since_ts], |r| Ok((r.get::<_, i64>(0)?, r.get::<_, String>(1)?, r.get::<_, Option<f64>>(2)?)))?;
        for row in rows {
            let (ts, model, cost) = row?;
            let day = DateTime::from_timestamp(ts, 0).context("timestamp out of range")?.with_timezone(&offset).date_naive();
            let entry = grouped.entry((day, model.clone())).or_insert(DailyCost { day, model, requests: 0, cost_usd: 0.0, unpriced: 0 });
            entry.requests += 1;
            match cost {
                Some(usd) => entry.cost_usd += usd,
                None => entry.unpriced += 1,
            }
        }
        Ok(grouped.into_values().collect())
    }

    }

    pub fn cost_state_deltas(&self) -> Result<Vec<CostStateDelta>> {
        let mut statement = self.conn.prepare(

    }

        for table in schema::DERIVED_TABLES {
            tx.execute(&format!("DELETE FROM {table}"), [])?;
        }

    }

        Ok(self.conn.query_row("SELECT COALESCE(SUM(parse_errors), 0) FROM files", [], |r| r.get::<_, i64>(0))? as u64)
    }

        Ok(self.conn.query_row("SELECT COUNT(*) FROM files", [], |r| r.get::<_, i64>(0))? as u64)

        match reader.read_until(b'\n', &mut buffer) {
            Ok(0) => None,
            Ok(_) if buffer.last() != Some(&b'\n') => None,
            Ok(read) => {
                position += read as u64;
                buffer.pop();
                if buffer.last() == Some(&b'\r') {
                    buffer.pop();
                }
                Some(Ok(Line { text: String::from_utf8_lossy(&buffer).into_owned(), end_offset: position }))
            }
            Err(error) => Some(Err(error.into())),
        }
    }))

pub fn discover(projects_dir: &Path) -> anyhow::Result<Vec<TranscriptFile>> {
    if !projects_dir.exists() {
        return Ok(Vec::new());
    }
    let mut files: Vec<TranscriptFile> = walkdir::WalkDir::new(projects_dir)
        .min_depth(2)
        .max_depth(4)
        .into_iter()
        .filter_map(Result::ok)
        .filter(|entry| entry.file_type().is_file())
        .filter(|entry| entry.path().extension().is_some_and(|ext| ext == "jsonl"))
        .filter(|entry| is_session_file(projects_dir, entry.path()))
        .map(|entry| TranscriptFile::from_path(entry.path()))
        .collect();
    files.sort_by(|a, b| a.path.cmp(&b.path));
    Ok(files)
}

fn is_session_file(root: &Path, path: &Path) -> bool {
    let depth = path.strip_prefix(root).map(|p| p.components().count()).unwrap_or(0);
    let in_subagents = path.parent().and_then(Path::file_name).is_some_and(|n| n == "subagents");
    depth == 2 || (depth == 4 && in_subagents)

impl IngestReport {
    pub fn add(&mut self, other: &IngestReport) {
        self.files_seen += other.files_seen;
        self.files_changed += other.files_changed;
        self.lines += other.lines;
        self.requests_inserted += other.requests_inserted;
        self.duplicate_requests += other.duplicate_requests;
        self.unpriced_requests += other.unpriced_requests;
        self.parse_errors += other.parse_errors;

pub struct Ingestor<'a> {
    store: &'a mut Store,
    prices: &'a PriceTable,
}

impl<'a> Ingestor<'a> {
    pub fn new(store: &'a mut Store, prices: &'a PriceTable) -> Self {
        Self { store, prices }
    }

    pub fn ingest_all(&mut self, projects_dir: &Path, on_file: &mut dyn FnMut(usize, usize)) -> Result<IngestReport> {
        let files = discover(projects_dir)?;
        let mut report = IngestReport::default();
        for (index, file) in files.iter().enumerate() {
            report.add(&self.ingest_file(file)?);
            on_file(index + 1, files.len());
        }
        Ok(report)
    }

    pub fn ingest_file(&mut self, file: &TranscriptFile) -> Result<IngestReport> {
        self.ingest_file_limited(file, u64::MAX)
    }

    pub(crate) fn ingest_file_limited(&mut self, file: &TranscriptFile, max_lines: u64) -> Result<IngestReport> {
        let mut report = IngestReport { files_seen: 1, ..Default::default() };
        let metadata = std::fs::metadata(&file.path)?;
        let size = metadata.len();
        let mtime = metadata
            .modified()
            .ok()
            .and_then(|t| t.duration_since(std::time::UNIX_EPOCH).ok())
            .map(|d| d.as_secs() as i64)
            .unwrap_or(0);
        let path = file.path.to_string_lossy().into_owned();
        let checkpoint = self.store.checkpoint(&path)?;
        if let Some(cp) = &checkpoint {
            if cp.size == size && cp.mtime == mtime && cp.offset == size {
                return Ok(report);
            }
        }

        let mut writer = self.store.writer()?;
        let file_id = writer.file(&path, size, mtime)?;
        let (mut offset, mut line_no) = match &checkpoint {
            Some(cp) if size >= cp.offset => (cp.offset, cp.lines),
            Some(_) => {
                writer.reset_file(file_id)?;
                (0, 0)
            }
            None => (0, 0),
        };
        report.files_changed = 1;

        let mut batch_errors = 0;
        let mut in_batch = 0;
        for line in lines::complete_lines(&file.path, offset)? {
            if report.lines >= max_lines {
                break;
            }
            let line = line?;
            line_no += 1;
            report.lines += 1;
            offset = line.end_offset;
            if line.text.trim().is_empty() {
                continue;
            }
            match parse_line(&line.text) {
                Ok(parsed) => apply(&mut writer, self.prices, file, file_id, line_no, &parsed, &mut report)?,
                Err(_) => {
                    report.parse_errors += 1;
                    batch_errors += 1;
                }
            }
            in_batch += 1;
            if in_batch == BATCH_LINES {
                writer.advance_file(file_id, offset, line_no, size, mtime, batch_errors)?;
                writer.commit()?;
                writer = self.store.writer()?;
                batch_errors = 0;
                in_batch = 0;
            }
        }
        writer.advance_file(file_id, offset, line_no, size, mtime, batch_errors)?;
        writer.commit()?;
        Ok(report)
    }
}

pub fn apply(
    writer: &mut Writer,
    prices: &PriceTable,
    file: &TranscriptFile,
    file_id: i64,
    line_no: u64,
    parsed: &Parsed,
    report: &mut IngestReport,
) -> Result<()> {
    let kind = parsed.record.kind();
    if !SKIPPED_RAW_KINDS.contains(&kind) {
        writer.raw(file_id, line_no, kind, &shrink(&parsed.raw, RAW_STRING_LIMIT).to_string())?;
    }
    let common = parsed.record.common();
    let session_id = common
        .and_then(|c| c.session_id.clone())
        .unwrap_or_else(|| file.session_hint.clone());
    let ts = common.and_then(|c| c.timestamp).map(|t| t.timestamp());
    if common.is_some() {
        writer.session(&SessionRow { id: session_id.clone(), project: file.project.clone(), cwd: common.and_then(|c| c.cwd.clone()), ts })?;
    }

    match &parsed.record {
        Record::Assistant(a) if a.is_billable() => {
            let Some(key) = a.dedup_key.clone() else { return Ok(()) };
            let cost_usd = prices.cost(&a.model, &a.usage);
            let write = writer.request(&RequestRow {
                key,
                session_id: session_id.clone(),
                ts: ts.unwrap_or(0),
                model: a.model.clone(),
                tokens: a.usage,
                cost_usd,
                is_sidechain: a.common.is_sidechain || file.agent_id.is_some(),
                agent_id: a.common.agent_id.clone().or_else(|| file.agent_id.clone()),
                skill: a.skill.clone(),
                mcp_server: a.mcp_server.clone(),
                effort: a.effort.clone(),
            })?;
            match write {
                RequestWrite::Inserted => {
                    report.requests_inserted += 1;
                    if cost_usd.is_none() {
                        report.unpriced_requests += 1;
                    }
                }
                RequestWrite::Updated | RequestWrite::Unchanged => report.duplicate_requests += 1,
            }
            for tool in &a.tool_uses {
                writer.tool_use(&ToolUseRow { id: tool.id.clone(), session_id: session_id.clone(), ts: ts.unwrap_or(0), name: tool.name.clone(), input_chars: tool.input_chars })?;
            }
        }
        Record::User(u) => {
            for result in &u.tool_results {
                writer.tool_result(&ToolResultRow { tool_use_id: result.tool_use_id.clone(), session_id: session_id.clone(), ts: ts.unwrap_or(0), chars: result.chars, images: result.images, is_error: result.is_error })?;
            }
        }
        Record::Attachment(a) => {
            writer.attachment(&AttachmentRow { file_id, line_no, session_id, ts, kind: a.kind.clone(), chars: a.chars, names: a.names.clone() })?;
        }
        Record::CompactBoundary(c) => {
            writer.compaction(&CompactionRow { file_id, line_no, session_id, ts, trigger: c.trigger.clone(), pre_tokens: c.pre_tokens, post_tokens: c.post_tokens })?;
        }
        Record::CostState(c) => {
            let session_id = c.session_id.clone().unwrap_or_else(|| file.session_hint.clone());
            writer.cost_state(&CostStateRow { file_id, line_no, session_id, total_cost_usd: c.total_cost_usd, json: parsed.raw.to_string() })?;
        }
        Record::Title(t) => {
            let session_id = t.session_id.clone().unwrap_or_else(|| file.session_hint.clone());
            writer.session(&SessionRow { id: session_id.clone(), project: file.project.clone(), cwd: None, ts: None })?;
            writer.title(&session_id, &t.title, t.is_custom)?;
        }
        _ => {}
    }
    Ok(())
}

    if value.abs() < 1.0 { format!("${value:.4}") } else { format!("${value:.2}") }

pub fn count(value: u64) -> String {
    let digits = value.to_string();
    let mut out = String::new();
    for (index, ch) in digits.chars().enumerate() {
        if index > 0 && (digits.len() - index) % 3 == 0 {
            out.push(',');
        }
        out.push(ch);
    }
    out
}

pub fn plural(value: u64, singular: &str, plural: &str) -> String {

        total_cost += row.cost_usd;

            Cell::new(row.day.to_string()),
            Cell::new(&row.model),
            Cell::new(count(row.requests)).set_alignment(CellAlignment::Right),
            Cell::new(cost).set_alignment(CellAlignment::Right),
        ]);
    }
    table.add_row(vec![
        Cell::new("Total"),
        Cell::new(""),
        Cell::new(count(total_requests)).set_alignment(CellAlignment::Right),
        Cell::new(usd(total_cost)).set_alignment(CellAlignment::Right),
    ]);

pub fn run(paths: &Paths, prices: &PriceTable) -> Result<()> {
    let files = discover(&paths.projects_dir())?;

    println!("  Claude dir: {} · {}", paths.claude_dir.display(), plural(files.len() as u64, "transcript file", "transcript files"));
    println!("  Data dir:   {}", paths.data_dir.display());
    println!("  {}", retention(paths));
    println!("  Price table: prices {}", prices.version());

    let store = super::open_store(paths)?;
    let totals = store.totals()?;
    println!("  Imported: {} in {} · {}", plural(totals.requests, "request", "requests"), plural(store.file_count()?, "file", "files"), plural(store.parse_error_total()?, "unparsable line", "unparsable lines"));
    for (model, requests) in store.unpriced_models()? {
        println!("  Unknown price: {model} ({})", plural(requests, "request", "requests"));
    }

    let deltas = store.cost_state_deltas()?;
    let comparable: Vec<_> = deltas.iter().filter(|d| d.claude_usd > 0.0).collect();
    let ours: f64 = comparable.iter().map(|d| d.ours_usd).sum();
    let claude: f64 = comparable.iter().map(|d| d.claude_usd).sum();

        usd(claude)
    );
    Ok(())
}

use std::path::PathBuf;

use anyhow::Result;

use super::format::plural;
use crate::ingest::{IngestReport, TranscriptFile, apply};
use crate::paths::Paths;
use crate::pricing::PriceTable;
use crate::transcript::parse_line;

pub fn run(paths: &Paths, prices: &PriceTable) -> Result<()> {
    let mut store = super::open_store(paths)?;
    store.clear_derived()?;
    let mut report = IngestReport::default();
    let mut records = 0u64;
    for (file_id, path) in store.raw_files()? {
        let rows = store.raw_records(file_id, &[])?;
        let location = TranscriptFile::from_path(&PathBuf::from(&path));
        let mut writer = store.writer()?;
        for row in &rows {
            let Ok(parsed) = parse_line(&row.json) else { continue };
            apply(&mut writer, prices, &location, row.file_id, row.line_no, &parsed, &mut report)?;
            records += 1;
        }
        writer.commit()?;
    }
    println!("✻ Rebuilt {} from {}", plural(report.requests_inserted, "request", "requests"), plural(records, "stored record", "stored records"));
    Ok(())
}
