# claude-plus Milestone 6 (Insights View and Alerts) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pane gains an Insights view (hotkey `4`) that ranks friendly, evidence-backed tips by their estimated weekly saving in dollars and percent of the 5h limit, from the ten rules of spec section 6 over the last 14 days, and celebrates wins; the mod greets the first session of a day with a recap toast, says what a session cost when it ends, and raises the three alerts of the spec (cache about to go cold, 5h pace running out before its reset, context near auto-compact) as toasts, with an opt-in chime.

**Architecture:** A new daemon unit `insights` holds the `Rule` trait, the ten rules (`cache.rs`, `setup.rs`, `usage.rs`), their shared pricing helpers and wording (`words.rs`), and `report.rs`, which reads the last 14 days from the store, the config scan and the context breakdowns into an `InsightContext`, evaluates every rule, ranks the findings and adds wins and a daily recap as `InsightsReport` v1; a new route `GET /insights?session=` serves it.
Store schema v15 keeps what the rules need and the store did not have: the main thread's human prompts (`prompts`) and the file, command or pattern of each tool use (`tool_uses.target`).
The mod fetches the report while the Insights view is shown and once at the start of an interactive session, lays it out with a pure screen model (`hooks/insights.ts`), decides alerts with a pure function (`hooks/alerts.ts`) on every tick, and keeps every `$` call and atom in `hooks/register.tsx`.

**Tech Stack:** Rust (edition 2024, MSRV 1.88), no new crates; Claude Code 2.1.296 function hooks (TypeScript, JSX with `h`, `$.ui.toast`, `$.audio.play`, `$.session.usage`, the `session.end` hook), `claude plugin validate` and `claude plugin test`, TypeScript 6.0.3 through `npx` for type-checking only; Python 3 from the system for the one script that writes the chime.
Node and npx are installed at `/opt/homebrew/bin`; there is no global `tsc`, and `npx --offline -p typescript@6.0.3 tsc` runs from the npx cache.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 3 "The pane" view 4, "Look and feel" (wins, tips with the payoff first, the recap toast, the opt-in chime) and "Alerts", 4 "Units" `insights` and `api` (`GET /insights`), 5 "Cache model" and "Subscription percent", 6 "Insights" rules 1 to 10, 7 "Error handling and safety", 8 "Testing", 9 milestone 6: "Insights view and alerts").

## Decisions

The spec is silent on these points, so this plan decides them.

1. The report gets its own route, `GET /insights?session=<id>`, because the setup rules need the session's project and the rules read two weeks of history, which only matters while the Insights view is shown or once at session start.
   A missing or malformed `session` is 400 with the message of the other session routes, another method is 405 and a store being rebuilt is 503.
   The route reads through its own read-only connection (`insights_reader`), as `/history` does since the M5 review, so a cold report never holds the reader that `/snapshot` and `/context` share.
   The route is new, so `API_VERSION` stays 1, and the report carries its own `v: 1` (`INSIGHTS_VERSION`).
2. Every rule looks at the last 14 days (`WINDOW_DAYS`) ending now, and a saving per week is the 14-day saving halved.
   A priced tip under $0.10 a week is dropped, so the view never suggests change for pennies.
   Tokens a request carries are priced at what the front of its prompt paid, since Claude Code lays the prompt out stable part first: from its cache reads, then its 1h writes, then its 5m writes, then its input, at the tier of the whole prompt (fix wave).
   The share of the 5h window uses the M5 `Rates` (made public) of the stored `five_hour` fits, for the model the main thread spent most on; it is `null` until calibrated, and the mod then leaves it out.
3. Findings are ranked by weekly saving, highest first; tips without a saving (costly tasks, retention) come last; ties keep the rule order of the spec.
   Each finding carries `tip` (lower case, the mod prefixes `Save ~$x/week: ` as the spec's title), up to three evidence lines plus `and N more ...`, `saving_usd`, `saving_pct_5h`, a confidence (`high`, `medium` or `low`) and `how`, the derivation the `?` opens.
4. Schema v15 adds a `prompts` table (one row per human prompt of the main thread, keyed by the entry's `uuid`, meta entries and slash commands left out) and `tool_uses.target` (the first of `file_path`, `notebook_path`, `command`, `url`, `pattern` and `path` in the tool input, at most 256 characters as the redaction keeps), with the indexes `prompts_by_ts` and `tool_results_by_ts`.
   Both are derived data, so `prompts` joins `DERIVED_TABLES` and the migration asks for a reindex when the store holds requests.
   Schema v16 (fix wave) adds `attachments.removed_names` (the `removedNames` of a delta, with `readdedNames` counted as added) and the index `prompts_by_session`, and asks for a reindex when the store holds attachments.
5. Rules about habits (rebuilds, tool results, compaction, model fit, task cost) read every session of the 14 days; rules about the setup (MCP servers, skills, memory) price only the requests of the session's project, because that is the setup the config scan reads.
   A session without a title is named `Untitled <first 8 characters of its id>`, as in the History view.
6. Idle cache rebuilds (rule 1) are the M3 `cache_model` rebuilds after a gap longer than the cache lifetime, on the main thread; the saving is what they cost above a warm cache read, less the premium of the base context that the tip's own fresh start still writes (the smallest prompt of the session, capped at the rebuild), and the evidence names the count, the sessions, the typical (median) break against the lifetime, and the tokens each rebuild rewrote.
   Mid-session cache busts (rule 8) are the rebuilds within the lifetime, grouped by cause: a model switch (the M3 cause), an MCP tool change (a main-thread `deferred_tools_delta` that adds or removes an `mcp__` tool, or an `mcp_instructions_delta` that adds or removes a server, between the two requests), a setup change (a main-thread skill listing, instructions, nested memory or agent listing between them), or no known cause.
   The tip comes from the costliest known cause; when only unknown causes remain the finding is unpriced, low confidence and only watches for them, because the real transcripts showed no MCP change ever breaking a warm cache (fix wave).
7. Unused MCP servers and skills (rules 2 and 3) are the M4 "Not used in 14 days" items of the Context view, each priced as its tokens on every main-thread request of the project; the evidence says whether each was used in the last 30 days, and the confidence is high when the sizes come from Claude Code's own `/context` breakdown and medium when they are estimated from the config files.
   A tip needs at least $0.10 a week of carried tokens, so an item carried on a handful of requests is no tip.
8. Oversized memory (rule 4) counts lines of at least 24 characters, holding at least one letter or digit, that repeat across two or more distinct CLAUDE.md and memory files loaded in every request, plus whatever exceeds 40,000 characters, priced as prose at the calibrated ratio on every main-thread request of the project.
9. Large tool results (rule 5) are main-thread results of at least 20,000 characters; the part above 10,000 characters is priced at the code ratio on every request until the next compaction of its session, and they are grouped by tool and normalized target: the path relative to the project for files, the program and its first path or word for a shell command (after `cd`, assignments, `sudo`-like prefixes and variables), the whole target otherwise; only the label is shortened to 30 characters (a path keeps its tail, a word its head).
   The tip names the costliest named source: reading a big file in parts (also for `cat`-like commands on a file), trimming the output of a named program, or asking another tool for smaller results; a command longer than the stored 256 characters has no target and is named `Bash commands too long to name` (fix wave).
10. Late compaction (rule 6) replays each session's main turns under a policy of `/compact` once the prompt passes a threshold, splitting at the compactions that really happened (fix wave).
    Each compaction removes the context above the restart size and saves what each later turn paid for those tokens, and costs its own summary request (a cache read of the context plus the summary written) and the rewrite premium of the turn after it; the restart, rewrite and summary sizes are the medians of the user's own compactions, with defaults of 68k, 40k and 20k tokens.
    Thresholds from 50k to 900k are tried; the net counts every session the policy touches, losers included, and the tip names the highest threshold within 10% of the best positive net, so it never advises a compaction that costs more than it saves.
11. Model fit (rule 7) finds sessions where every task (prompt to next prompt, subagents included) took at most 3 main-thread requests and 1,000 output tokens on Opus, Fable or Mythos, and reprices them on the M3 forecast's alternative model at the same token counts; the most common effort of those requests is named in the evidence when it was set, but not priced, because the transcripts do not say what a lower effort would have cost.
12. Cost-per-task outliers (rule 9) need at least 10 tasks and name the ones that cost at least 5 times the median and at least $1, without a saving and with low confidence, since how to split a task cannot be priced.
13. Transcript retention (rule 10) fires while `cleanupPeriodDays` in `~/.claude/settings.json` is under 90 days, the longest History range, and counts 30 days when it is unset, as Claude Code does; it has no saving, and `how` says exactly what to add and that only that file was read, since managed or project settings may already keep more.
    The daemon only reads the file.
14. Wins are what cache hits saved over the last 7 local days and the run of days at or above 90% hit ratio ending yesterday, read over the last 90 days, idle days skipped and today counted once it qualifies.
    The mod shows the streak from 2 days on, in the success color.
    The daemon words every value as the pane does: money as `$4.18` or `$9,682`, tokens as `287k`, `1.2M`, `18.4B` or `2.4T`, counts grouped as `1,284`, with a no-break space between a value and its unit or the word it counts (`3 rebuilds`, `2h 48m`, `Opus 5.5` joined by U+00A0) so a wrap never splits them.
15. The recap covers the last local day with requests before today, labelled `Yesterday` or its date (`Oct 7`), with its cost including the reconciled cost spread to that day (so it agrees with `stats` and `export`), hit ratio and biggest win: the streak once it reaches 3 days, else what cache hits saved, else none.
    The mod toasts it for 8 s at the start of an interactive session, once per recap day (plugin store key `recap`), after `daemon --ensure` has finished, and again on the next tick when the store was rebuilding; a `claude -p` run gets none.
16. When a session ends with `/clear` or `/resume`, the mod toasts what it cost and what cache hits saved, from the snapshot it already holds (`That session: $4.18 · cache hits saved you $3.20 ✻`); a session under one cent says nothing, and an exit says nothing because the terminal is gone.
17. The three alerts are decided by a pure function on every tick from the snapshot and the local measure, each at most once:
    the cache warning in the last minute of a warm cache while Claude is not working, once per expiry, with the forecast's rewarming cost;
    the pace warning when the 5h forecast fills the window before its reset, once per window (a reset moving by under a minute is the same window);
    the context warning at 90% of the auto-compact threshold, again only after context dropped under 80%.
    What fired lives in an `alerted` atom (shape `alerted-2`) tied to the session and the model, so a new session starts clean and `/model` forgets the cached threshold; each tick writes only the fields it changed onto the current value.
    Alerts wait while the recap or another toast shows, and alerts due in one tick are joined with ` · ` into one toast.
18. The auto-compact threshold comes from the last Context breakdown the mod received; when there is none and context passes 60%, the mod asks `$.session.usage({ breakdown: 'summary' })` once per session, which sends no request.
19. Alerts are on by default and the new plugin option `alerts` turns them off; the new option `chime` (off by default) plays `sounds/chime.wav` with the cache warning only.
    The chime is a soft 0.6 s tone (880 Hz with two quieter partials, 22,050 Hz mono, 26,504 bytes) written by `mod-dev/chime.py`, which is deterministic, so the committed file can be checked by its hash.
20. Toasts and the chime are for interactive sessions only (`session.start` with `isInteractive`, or `/plus`).
21. The mod asks for `/insights` with a 3 s timeout, beside the ticker and one at a time, as `/history` does; it asks at once when the view opens, then every 60 s while it is shown, and keeps the last report in an `insights` atom (shape `insights-1`) while the daemon is down.
    A report for another session is dropped.
    A failed request is kept in an `insightsFailure` atom and said in place of the loading line (`Could not look for savings: ...`, `Trying again every 60 s`), or under the counts of a kept report (`Could not refresh: ...`); a 404 from a daemon that predates `/insights` reads `This claude-plus daemon is older than the pane and has no Insights` and `Run claude-plus daemon stop to restart it`, as the History view does since the M5 review.
22. The view reads top to bottom: `Insights` with `up to ~$x/week` (the sum of the priced tips, in the accent color, with a `?` saying tips can overlap), a dim line counting the tips with the 5h share when it fits, the wins, then each tip: `Save ~$x/week:` in bold success color and the tip, the dim evidence indented by two, and a dim line with the 5h share and the confidence and a `?` for `how`.
    The view lives in `hooks/insights.ts` like the History view, not in `views/`, because it is a pure screen model.
23. Before the first report the view reads `Looking for ways to save… ✻`; without requests in 14 days `Insights need a few sessions of history ✻`; without findings `No savings to suggest right now ✻ your setup looks lean`.
24. The header gains `4: Insights`; at 40 columns, where the four full labels do not fit, every tab shortens to `Live`, `Ctx`, `Hist` and `Tips`, the active one included, so no hotkey label moves when the view changes (fix wave).
25. The Context and History views keep polling `/context` every 10 s; the Insights view does not, so the poll now runs only on those two.
26. The M2 writer test that waits for the reindex marker raced the writer and could hang the whole suite; Task 1 makes it deterministic, because a hung test is a defect whichever milestone wrote it.

## Review Focus

1. A tip must never claim more than it can save: each rule prices only what its change would remove, at the price the requests paid, and drops tips under $0.10 a week (Task 2 test `a_priced_finding_reports_a_weekly_saving_with_its_share_of_a_five_hour_window`, Task 5 tests `large_tool_results_are_priced_until_the_next_compaction_and_grouped_by_target` and `sessions_that_stayed_above_100k_for_ten_turns_suggest_compacting_earlier`).

The report must read two weeks of history from the store without scanning a table or holding the reader that `/snapshot` shares, and the derived prompts must survive a reindex and a rewritten transcript (Task 1 tests `the_insights_reads_search_indexes_instead_of_scanning_tables` and `main_thread_prompts_and_tool_targets_are_derived_once`, Task 6 test `the_report_reads_the_last_two_weeks_from_the_store_and_ranks_its_findings`, Task 7 test `an_insights_report_does_not_wait_for_a_snapshot`).

Every alert and the recap must show once, only in an interactive session, and respect the `alerts` and `chime` options (Task 10 tests `the cache warns once in its last minute, with what rewarming would cost` and `context warns at 90% of the auto-compact threshold and again only after dropping under 80%`, Task 11 tests `the first session after a day of work is greeted with a recap toast, once`, `a session without a terminal gets no recap and no alerts` and `alerts=false raises no alert`).

## API Contract (`GET /insights?session=s1`, v1)

The report for the fixture of the store test of Task 6 is, exactly (floats rounded to 6 decimals here):

```json
{
  "v": 1,
  "session": "s1",
  "generated_at_ms": 1791720000000,
  "since_ms": 1790510400000,
  "requests": 3,
  "sessions": 1,
  "findings": [
    {
      "rule": "model_fit",
      "tip": "use Sonnet 5.5 for quick questions and small edits",
      "evidence": [
        "1 session of quick tasks ran on Opus 5.5",
        "The same tokens on Sonnet 5.5 would cost $0.51 instead of $1.03"
      ],
      "saving_usd": 0.25653,
      "saving_pct_5h": null,
      "confidence": "medium",
      "how": "Finds sessions of the last 14 days where every task, from a prompt to the next one, took at most 3 main-thread requests and 1k output tokens on a top-tier model, and reprices those requests on Sonnet 5.5 at the same token counts."
    },
    {
      "rule": "idle_rebuilds",
      "tip": "start fresh after a break instead of rewarming a long context",
      "evidence": [
        "1 cache rebuild after a break, in 1 session, $0.48",
        "Typical break 20m, the cache lasts 5m",
        "Each rebuild rewrote ~100k tokens"
      ],
      "saving_usd": 0.24,
      "saving_pct_5h": null,
      "confidence": "high",
      "how": "Counts main-thread requests that rewrote the cache after a gap longer than its 5m lifetime in the last 14 days. The saving is what those rewrites cost above a warm cache read. Coming back with /clear or a new session rebuilds only a small context."
    },
    {
      "rule": "retention",
      "tip": "keep 90 days of transcripts to match the History range",
      "evidence": [
        "cleanupPeriodDays is 30, the default",
        "Claude Code deletes older transcripts, so /resume and a fresh import cannot reach them"
      ],
      "saving_usd": null,
      "saving_pct_5h": null,
      "confidence": "high",
      "how": "Add \"cleanupPeriodDays\": 90 to ~/.claude/settings.json. claude-plus keeps its own copy of what it has read either way."
    }
  ],
  "wins": {
    "saved_usd_7d": 0.38,
    "hit_streak_days": 0
  },
  "recap": {
    "day": "Yesterday",
    "start_ms": 1791590400000,
    "cost_usd": 1.02612,
    "hit_ratio": 0.3333,
    "saved_usd": 0.38,
    "win": "cache hits saved you $0.38"
  }
}
```

- `session` is the session asked for; `since_ms` is the start of the 14 days; `requests` counts the main-thread requests of the 14 days and `sessions` the sessions that spent in them.
- `findings` are ranked by `saving_usd` (USD per week), and those without one come last; `saving_pct_5h` is `null` until the 5h limit is calibrated.
- `rule` is one of `idle_rebuilds`, `unused_mcp_servers`, `unused_skills`, `oversized_memory`, `large_tool_results`, `late_compaction`, `model_fit`, `cache_busts`, `costly_tasks` and `retention`, in the order of spec section 6.
- `wins.saved_usd_7d` is what cache hits saved in the last 7 local days and `wins.hit_streak_days` the run of days at or above 90%.
- `recap` is `null` when no day before today has requests in the last 30 days; `start_ms` is that day's local midnight, and the mod greets once per value.
- Errors: 400 `{"error": "session query parameter is required"}` or the session rule of the other routes, 405 for another method, 503 `{"error": "the store is being rebuilt"}`.

- Produces:

```rust
// crate::store
pub struct PromptPoint { pub session_id: String, pub ts: i64 }
pub struct LargeResult { pub session_id: String, pub ts: i64, pub chars: u64, pub tool: Option<String>, pub target: Option<String> }
pub struct PrefixChange { pub ts: i64, pub kind: String }
pub struct PromptRow { pub uuid: String, pub session_id: String, pub ts: i64 }
// ToolUseRow gains pub target: Option<String>
impl Store {
    pub fn prompts_between(&self, since_ts: i64, until_ts: i64) -> Result<Vec<PromptPoint>>;
    pub fn large_tool_results_between(&self, since_ts: i64, until_ts: i64, min_chars: u64) -> Result<Vec<LargeResult>>;
```

```rust
use anyhow::Result;
use rusqlite::params;

use super::{PREFIX_KINDS, Store};

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PromptPoint {
    pub session_id: String,
    pub ts: i64,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LargeResult {
    pub session_id: String,
    pub ts: i64,
    pub chars: u64,
    pub tool: Option<String>,
    pub target: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PrefixChange {
    pub ts: i64,
    pub kind: String,
}

const PROMPTS_BETWEEN: &str =
    "SELECT session_id, ts FROM prompts WHERE ts >= ?1 AND ts < ?2 ORDER BY session_id, ts, uuid";

const LARGE_RESULTS_BETWEEN: &str = "SELECT r.session_id, r.ts, r.chars, u.name, u.target
     FROM tool_results r LEFT JOIN tool_uses u ON u.id = r.tool_use_id
     WHERE r.ts >= ?1 AND r.ts < ?2 AND r.chars >= ?3 AND r.is_sidechain = 0
     ORDER BY r.session_id, r.ts, r.tool_use_id";

fn prefix_kinds_sql() -> String {
    let kinds = vec!["?"; PREFIX_KINDS.len()].join(", ");
    format!(
        "SELECT ts, kind FROM attachments
         WHERE session_id = ? AND ts >= ? AND ts < ? AND kind IN ({kinds}) ORDER BY ts, kind"
    )
}

#[cfg(test)]
fn insights_statements() -> Vec<String> {
    vec![
        PROMPTS_BETWEEN.to_string(),
        LARGE_RESULTS_BETWEEN.to_string(),
        prefix_kinds_sql(),
    ]
}

impl Store {
    pub fn prompts_between(&self, since_ts: i64, until_ts: i64) -> Result<Vec<PromptPoint>> {
        let mut statement = self.conn.prepare_cached(PROMPTS_BETWEEN)?;
        let rows = statement.query_map([since_ts, until_ts], |r| {
            Ok(PromptPoint {
                session_id: r.get(0)?,
                ts: r.get(1)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn large_tool_results_between(
        &self,
        since_ts: i64,
        until_ts: i64,
        min_chars: u64,
    ) -> Result<Vec<LargeResult>> {
        let mut statement = self.conn.prepare_cached(LARGE_RESULTS_BETWEEN)?;
        let rows = statement.query_map(params![since_ts, until_ts, min_chars as i64], |r| {
            Ok(LargeResult {
                session_id: r.get(0)?,
                ts: r.get(1)?,
                chars: r.get::<_, i64>(2)? as u64,
                tool: r.get(3)?,
                target: r.get(4)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn prefix_kinds_between(
        &self,
        session_id: &str,
        since_ts: i64,
        until_ts: i64,
    ) -> Result<Vec<PrefixChange>> {
        let mut statement = self.conn.prepare_cached(&prefix_kinds_sql())?;
        let mut values: Vec<Value> = vec![
            session_id.to_string().into(),
            since_ts.into(),
            until_ts.into(),
        ];
        values.extend(
            PREFIX_KINDS
                .iter()
                .map(|kind| Value::from(kind.to_string())),
        );
        let rows = statement.query_map(rusqlite::params_from_iter(values), |r| {
            Ok(PrefixChange {
                ts: r.get(0)?,
                kind: r.get(1)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }
}
```

```rust
    format!("${}", grouped(usd.round() as u64))
}

pub fn tokens(count: u64) -> String {
    if count < 1000 {
        return count.to_string();
    }
    scaled(count as f64 / 1000.0, 0)
}

pub fn duration(ms: i64) -> String {
    if ms < MINUTE_MS {
        return "<1m".into();
    }
    if ms < HOUR_MS {
        return format!("{}m", ms / MINUTE_MS);
    }
    if ms < DAY_MS {
        let minutes = ms % HOUR_MS / MINUTE_MS;
        return match minutes {
            0 => format!("{}h", ms / HOUR_MS),
            _ => format!("{}h {minutes}m", ms / HOUR_MS),
        };
    }
    match ms % DAY_MS / HOUR_MS {
        0 => format!("{}d", ms / DAY_MS),
        hours => format!("{}d {hours}h", ms / DAY_MS),
    }
}

pub fn model_name(id: &str) -> String {
    let base = crate::pricing::normalize_model(id);
    let parts: Vec<&str> = base.split('-').collect();
    let Some(at) = parts.iter().position(|part| FAMILIES.contains(part)) else {
        return id.to_string();
    };
    let family = parts[at];
    let version: Vec<&str> = parts[at + 1..]
        .iter()
        .copied()
        .filter(|part| !part.is_empty() && part.bytes().all(|b| b.is_ascii_digit()))
        .collect();
    let name = format!("{}{}", family[..1].to_uppercase(), &family[1..]);
    match version.is_empty() {
        true => name,
        false => format!("{name} {}", version.join(".")),
    }
}

pub fn count(value: u64, one: &str, many: &str) -> String {
    format!("{} {}", grouped(value), if value == 1 { one } else { many })
}

pub fn times(value: u64) -> String {
    match value {
        1 => "once".into(),
        2 => "twice".into(),
        _ => format!("{} times", grouped(value)),
    }
}

fn scaled(value: f64, step: usize) -> String {
    let rounded = if value < 100.0 {
        (value * 10.0).round() / 10.0
    } else {
        value.round()
    };
    if rounded >= 1000.0 && step < TOKEN_UNITS.len() - 1 {
        return scaled(value / 1000.0, step + 1);
    }
    let unit = TOKEN_UNITS[step];
    if rounded.fract() == 0.0 {
        format!("{}{unit}", rounded as u64)
    } else {
        format!("{rounded:.1}{unit}")
    }
}

fn grouped(value: u64) -> String {
    let digits = value.to_string();
    let mut out = String::new();
    for (index, ch) in digits.chars().enumerate() {
        if index > 0 && (digits.len() - index).is_multiple_of(3) {
            out.push(',');
        }
        out.push(ch);
    }
    out
}
```

```rust
    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let idle: Vec<&Rebuilt> = ctx
            .rebuilds
            .iter()
            .filter(|r| r.rebuild.cause == RebuildCause::Idle)
            .collect();
        let Some(gap) = median(idle.iter().map(|r| r.gap_ms as f64).collect()) else {

        let rewritten = idle.iter().map(|r| r.rebuild.tokens).sum::<u64>() / idle.len() as u64;

            rule: RuleId::IdleRebuilds,

            }

        let Some((&top, _)) = busts
            .iter()
            .max_by(|a, b| a.1.1.total_cmp(&b.1.1).then_with(|| b.0.cmp(a.0)))
        else {
            return Vec::new();
        };
        let mut ordered: Vec<(Bust, (u64, f64))> = busts.into_iter().collect();
        ordered.sort_by(|a, b| b.1.1.total_cmp(&a.1.1).then_with(|| a.0.cmp(&b.0)));
        let usd = ordered.iter().map(|(_, (_, usd))| usd).sum();
        let draft = Draft {
            rule: RuleId::CacheBusts,
            tip: top.tip().into(),
            evidence: ordered
                .iter()
                .map(|(bust, (times, usd))| bust.line(*times, *usd))
                .collect(),
            confidence: Confidence::Medium,

                  The saving is what those rewrites cost above a warm cache read."
                .into(),
        };
        ctx.priced(draft, usd).into_iter().collect()
    }
}
```

```rust
fn unused(
    ctx: &InsightContext,
    kind: ItemKind,
    tip: impl Fn(&[&Item]) -> String,
) -> Option<Finding> {
    let items: Vec<&Item> = ctx.dead_weight.iter().filter(|i| i.kind == kind).collect();
    if items.is_empty() {
        return None;
    }
    let carried: u64 = items.iter().map(|i| i.tokens).sum();
    let month = |item: &Item| {
        ctx.month_items
            .iter()
            .find(|m| m.kind == item.kind && m.name == item.name)
            .and_then(|m| m.uses_14d)
            .unwrap_or(0)
    };
    let mut evidence = listed(
        &items,
        |item| match month(item) {
            0 => format!(
                "{}: ~{} tokens per request, unused for 30 days",
                item.name,
                tokens(item.tokens)
            ),
            uses => format!(
                "{}: ~{} tokens per request, used {} in 30 days",
                item.name,
                tokens(item.tokens),
                times(uses)
            ),
        },
        if kind == ItemKind::Skill {
            "skills"
        } else {
            "servers"
        },
    );
    evidence.push(format!(
        "Carried on {} in this project over 14 days",
        count(ctx.project_requests() as u64, "request", "requests")
    ));
    let measured = items.iter().all(|i| !i.estimated);
    let draft = Draft {
        rule: match kind {
            ItemKind::Skill => RuleId::UnusedSkills,
            _ => RuleId::UnusedMcpServers,

        evidence,
        confidence: if measured {
            Confidence::High
        } else {
            Confidence::Medium
        },
        how: format!(
            "{} Every main-thread request in this project carries {}, and the saving prices them at what those requests paid per prompt token. {}",

                "Token sizes come from Claude Code's own /context breakdown."
            } else {

    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let mut seen: BTreeMap<&str, Vec<&str>> = BTreeMap::new();
        for memory in ctx.memory {
            for line in memory.text.lines().map(str::trim) {
                if line.chars().count() >= DUPLICATE_MIN_CHARS {
                    seen.entry(line).or_default().push(&memory.name);
                }
            }
        }
        let repeats: Vec<(&str, usize)> = seen
            .iter()
            .filter(|(_, owners)| owners.len() > 1)
            .map(|(line, owners)| (*line, owners.len() - 1))
            .collect();
        let repeated_chars: u64 = repeats
            .iter()
            .map(|(line, extra)| (line.chars().count() * extra) as u64)
            .sum();

            .memory
            .iter()
            .map(|m| (m.name.as_str(), m.text.chars().count() as u64))

            .iter()
```

```rust
use std::collections::BTreeMap;

use super::words::{count, grouped, model_name, money, tokens};
use super::{Confidence, Draft, Finding, InsightContext, Rule, RuleId, is_main, listed, median};
use crate::context_model::TextKind;
use crate::forecast::{alternative_for, family};

pub const LARGE_RESULT_CHARS: u64 = 20_000;
pub const KEPT_RESULT_CHARS: u64 = 10_000;
pub const LATE_PROMPT_TOKENS: u64 = 100_000;
pub const MIN_LATE_TURNS: usize = 10;
pub const REGROWTH: f64 = 0.5;
pub const QUICK_REQUESTS: usize = 3;

pub const TOP_TIER: &[&str] = &["opus", "fable", "mythos"];

pub const OUTLIER_FACTOR: f64 = 5.0;
pub const MIN_OUTLIER_USD: f64 = 1.0;

pub struct Task<'a> {
    pub session_id: &'a str,
    pub requests: Vec<&'a SpentRequest>,
}

impl Task<'_> {
    fn main(&self) -> impl Iterator<Item = &&SpentRequest> {
        self.requests.iter().filter(|r| is_main(r))
    }

    fn is_quick(&self) -> bool {
        let main: Vec<&&SpentRequest> = self.main().collect();
        main.len() <= QUICK_REQUESTS
            && main.iter().map(|r| r.point.tokens.output).sum::<u64>() <= QUICK_OUTPUT_TOKENS
            && main
                .iter()
                .all(|r| TOP_TIER.contains(&family(&r.point.model)))
    }

    fn cost(&self) -> f64 {
        self.requests.iter().filter_map(|r| r.cost_usd).sum()
    }
}

pub fn tasks<'a>(ctx: &InsightContext<'a>) -> Vec<Task<'a>> {
    let mut starts: BTreeMap<&str, Vec<i64>> = BTreeMap::new();
    for prompt in ctx.prompts {
        starts
            .entry(&prompt.session_id)
            .or_default()
            .push(prompt.ts);
    }
    let mut tasks: BTreeMap<(&str, i64), Vec<&SpentRequest>> = BTreeMap::new();
    for request in ctx.requests {
        let Some(times) = starts.get(request.session_id.as_str()) else {
            continue;
        };
        let at = times.partition_point(|ts| *ts <= request.point.ts);
        if at > 0 {
            tasks
                .entry((&request.session_id, times[at - 1]))
                .or_default()
                .push(request);
        }
    }
    tasks
        .into_iter()
        .map(|((session_id, _), requests)| Task {
            session_id,
            requests,
        })
        .collect()
}

pub struct LargeToolResults;

#[derive(Default)]
struct Source {
    results: u64,
    tokens: u64,
    usd: f64,
}

impl Rule for LargeToolResults {
    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let mut sources: BTreeMap<(String, String), Source> = BTreeMap::new();
        for result in ctx.tool_results {
            let kept = ctx.ratios.tokens(
                result.chars.saturating_sub(KEPT_RESULT_CHARS),
                TextKind::Code,
            );
            let until = ctx
                .compactions
                .iter()
                .filter(|c| c.main && c.session_id == result.session_id && c.ts > result.ts)
                .map(|c| c.ts)
                .min()
                .unwrap_or(i64::MAX);
            let usd: f64 = ctx
                .main_requests()
                .filter(|r| r.session_id == result.session_id)
                .filter(|r| r.point.ts > result.ts && r.point.ts < until)
                .map(|r| kept as f64 * ctx.per_prompt_token(r))
                .sum();
            let tool = result.tool.clone().unwrap_or_else(|| "A tool".into());
            let source = sources.entry((tool, target_of(ctx, result))).or_default();
            source.results += 1;
            source.tokens += ctx.ratios.tokens(result.chars, TextKind::Code);
            source.usd += usd;
        }
        let mut ordered: Vec<(&(String, String), &Source)> = sources.iter().collect();
        ordered.sort_by(|a, b| b.1.usd.total_cmp(&a.1.usd).then_with(|| a.0.cmp(b.0)));
        let Some(((top, _), _)) = ordered.first() else {
            return Vec::new();
        };
        let tip = match top.as_str() {
            "Read" => "read big files in parts instead of whole",
            "Bash" => "trim long command output with head, tail or grep",
            _ => "ask for smaller tool results",
        };
        let usd = ordered.iter().map(|(_, source)| source.usd).sum();
        let draft = Draft {
            rule: RuleId::LargeToolResults,
            tip: tip.into(),
            evidence: listed(
                &ordered,
                |((tool, target), source)| {
                    let what = match target.is_empty() {
                        true => tool.clone(),
                        false => format!("{tool} {target}"),
                    };
                    format!(
                        "{what}: {}, ~{} tokens each",
                        count(source.results, "result", "results"),
                        tokens(source.tokens / source.results)
                    )
                },
                "sources",
            ),
            confidence: Confidence::Medium,
            how: format!(
                "Looks at main-thread tool results of {} characters or more in the last 14 days. \
                 Everything past the first {} characters is priced on each later request until the next compaction, \
                 at what those requests paid per prompt token.",
                grouped(LARGE_RESULT_CHARS),
                grouped(KEPT_RESULT_CHARS)
            ),
        };
        ctx.priced(draft, usd).into_iter().collect()
    }
}

fn target_of(ctx: &InsightContext, result: &LargeResult) -> String {
    let Some(target) = result.target.as_deref() else {
        return String::new();
    };
    let cwd = ctx
        .session(&result.session_id)
        .and_then(|s| s.cwd.as_deref())
        .map(|cwd| format!("{}/", cwd.trim_end_matches('/')));
    let relative = cwd
        .and_then(|cwd| target.strip_prefix(cwd.as_str()).map(String::from))
        .unwrap_or_else(|| target.to_string());
    let line = relative.lines().next().unwrap_or("").trim();
    let chars: Vec<char> = line.chars().collect();
    if chars.len() <= TARGET_CHARS {
        return line.to_string();
    }
    let kept = TARGET_CHARS - 1;
    match line.contains(' ') {
        true => format!("{}…", chars[..kept].iter().collect::<String>().trim_end()),
        false => format!(
            "…{}",
            chars[chars.len() - kept..].iter().collect::<String>()
        ),
    }
}

pub struct LateCompaction;

impl Rule for LateCompaction {
    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let mut sessions: BTreeMap<&str, (usize, u64, f64)> = BTreeMap::new();
        for request in ctx.main_requests() {
            let prompt = request.point.tokens.prompt_total();
            if prompt < LATE_PROMPT_TOKENS {
                continue;
            }
            let session = sessions.entry(&request.session_id).or_default();
            session.0 += 1;
            session.1 = session.1.max(prompt);
            session.2 +=
                REGROWTH * (prompt - LATE_PROMPT_TOKENS) as f64 * ctx.per_prompt_token(request);
        }
        let mut late: Vec<(&str, (usize, u64, f64))> = sessions
            .into_iter()
            .filter(|(_, (turns, _, _))| *turns >= MIN_LATE_TURNS)
            .collect();
        late.sort_by(|a, b| b.1.2.total_cmp(&a.1.2).then_with(|| a.0.cmp(b.0)));
        if late.is_empty() {
            return Vec::new();
        }
        let usd = late.iter().map(|(_, (_, _, usd))| usd).sum();
        let draft = Draft {
            rule: RuleId::LateCompaction,
            tip: "run /compact once a session passes 100k tokens".into(),
            evidence: listed(
                &late,
                |(session, (turns, peak, _))| {
                    format!(
                        "{}: {} above 100k, peak ~{}",
                        ctx.title(session),
                        count(*turns as u64, "turn", "turns"),
                        tokens(*peak)
                    )
                },
                "sessions",
            ),
            confidence: Confidence::Medium,
            how: format!(
                "Finds sessions of the last 14 days with {MIN_LATE_TURNS} or more main-thread turns above 100k prompt tokens. \
                 The saving prices half of the tokens past 100k on those turns: an earlier /compact summarizes them away, and the context grows back after it."
            ),
        };
        ctx.priced(draft, usd).into_iter().collect()
    }
}

pub struct ModelFit;

impl Rule for ModelFit {
    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let mut by_session: BTreeMap<&str, Vec<Task>> = BTreeMap::new();
        for task in tasks(ctx) {
            by_session.entry(task.session_id).or_default().push(task);
        }
        let quick_sessions: Vec<&Vec<Task>> = by_session
            .values()
            .filter(|tasks| tasks.iter().all(Task::is_quick))
            .collect();
        let quick: Vec<&SpentRequest> = quick_sessions
            .iter()
            .flat_map(|tasks| tasks.iter().flat_map(|task| task.main().copied()))
            .collect();
        let mut spend: BTreeMap<&str, f64> = BTreeMap::new();
        let (mut current, mut cheaper) = (0.0, 0.0);
        for request in &quick {
            let model = request.point.model.as_str();
            let (Some(paid), Some(alternative)) = (request.cost_usd, alternative_for(model)) else {
                continue;
            };
            let Some(repriced) = ctx.prices.cost(alternative, &request.point.tokens) else {
                continue;
            };
            *spend.entry(model).or_default() += paid;
            current += paid;
            cheaper += repriced;
        }
        let Some(model) = spend
            .iter()
            .max_by(|a, b| a.1.total_cmp(b.1).then_with(|| b.0.cmp(a.0)))
            .map(|(model, _)| *model)
        else {
            return Vec::new();
        };
        let alternative = alternative_for(model).unwrap_or_default();
        let mut evidence = vec![
            format!(
                "{} of quick tasks ran on {}",
                count(quick_sessions.len() as u64, "session", "sessions"),
                model_name(model)
            ),
            format!(
                "The same tokens on {} would cost {} instead of {}",
                model_name(alternative),
                money(cheaper),
                money(current)
            ),
        ];
        let mut efforts: BTreeMap<&str, usize> = BTreeMap::new();
        for request in &quick {
            if let Some(effort) = request.point.effort.as_deref() {
                *efforts.entry(effort).or_default() += 1;
            }
        }
        if let Some((effort, times)) = efforts.into_iter().max_by_key(|(_, n)| *n) {
            evidence.push(format!(
                "{} of {} at {effort} effort",
                times,
                count(quick.len() as u64, "request", "requests")
            ));
        }
        let draft = Draft {
            rule: RuleId::ModelFit,
            tip: format!(
                "use {} for quick questions and small edits",
                model_name(alternative)
            ),
            evidence,
            confidence: Confidence::Medium,
            how: format!(
                "Finds sessions of the last 14 days where every task, from a prompt to the next one, \
                 took at most {QUICK_REQUESTS} main-thread requests and {} output tokens on a top-tier model, \
                 and reprices those requests on {} at the same token counts.",
                tokens(QUICK_OUTPUT_TOKENS),
                model_name(alternative)
            ),
        };
        ctx.priced(draft, current - cheaper).into_iter().collect()
    }
}

pub struct CostlyTasks;

impl Rule for CostlyTasks {
    fn evaluate(&self, ctx: &InsightContext) -> Vec<Finding> {
        let all = tasks(ctx);
        if all.len() < MIN_TASKS {
            return Vec::new();
        }
        let Some(typical) = median(all.iter().map(Task::cost).collect()) else {
            return Vec::new();
        };
        let mut outliers: Vec<&Task> = all
            .iter()
            .filter(|t| t.cost() >= MIN_OUTLIER_USD && t.cost() >= OUTLIER_FACTOR * typical)
            .collect();
        outliers.sort_by(|a, b| b.cost().total_cmp(&a.cost()));
        if outliers.is_empty() {
            return Vec::new();
        }
        let mut evidence = listed(
            &outliers,
            |task| {
                format!(
                    "{}: {}, {}",
                    ctx.title(task.session_id),
                    money(task.cost()),
                    count(task.requests.len() as u64, "request", "requests")
                )
            },
            "tasks",
        );
        evidence.push(format!(
            "Your typical task costs {} across {}",
            money(typical),
            count(all.len() as u64, "task", "tasks")
        ));
        vec![
            Draft {
                rule: RuleId::CostlyTasks,
                tip: "break your biggest asks into smaller steps".into(),
                evidence,
                confidence: Confidence::Low,
                how: format!(
                    "A task runs from one prompt to the next, subagents included. \
                     These cost at least {} and {OUTLIER_FACTOR:.0} times your median task of the last 14 days. \
                     Smaller steps keep context short and let you stop early.",
                    money(MIN_OUTLIER_USD)
                ),
            }
            .into_finding(),
        ]
    }
}
```

```rust
pub fn days(spans: &calendar::Spans, requests: &[SpentRequest], prices: &PriceTable) -> Vec<Day> {
    let mut days: Vec<Day> = spans
        .spans
        .iter()
        .map(|span| Day {
            start: span.start,
            label: span.label.clone(),
            ..Default::default()
        })
        .collect();
    for request in requests {
        let Some(index) = spans.index_of(request.point.ts) else {
            continue;
        };
        let day = &mut days[index];
        let tokens = &request.point.tokens;
        day.requests += 1;
        day.cost_usd += request.cost_usd.unwrap_or(0.0);
        day.saved_usd +=
            cache_model::saved_usd(&request.point.model, tokens, prices).unwrap_or(0.0);
        day.read += tokens.cache_read;
        day.prompt += tokens.prompt_total();
    }

pub fn wins(days: &[Day]) -> Wins {
    let Some((today, before)) = days.split_last() else {
        return Wins {
            saved_usd_7d: 0.0,
            hit_streak_days: 0,
        };
    };

        .iter()
        .rev()
        .filter(|day| day.requests > 0)
        .take_while(|day| day.on_streak())

        saved_usd_7d: days.iter().rev().take(WEEK_DAYS).map(|d| d.saved_usd).sum(),
        hit_streak_days: streak + u64::from(today.on_streak()),

pub fn recap(days: &[Day]) -> Option<Recap> {
    let (_, before) = days.split_last()?;
    let index = before.iter().rposition(|day| day.requests > 0)?;
    let day = &before[index];
    let streak = before[..=index]
        .iter()
        .rev()
        .filter(|day| day.requests > 0)
        .take_while(|day| day.on_streak())
        .count() as u64;
    let win = if streak >= STREAK_WIN_DAYS {
        Some(format!(
            "{} in a row above 90% cache hits",
            count(streak, "day", "days")
        ))
    } else if day.saved_usd >= 0.01 {
        Some(format!("cache hits saved you {}", money(day.saved_usd)))
    } else {
        None
    };
    Some(Recap {
        day: match index + 1 == before.len() {
            true => "Yesterday".into(),
            false => day.label.clone(),
        },
        start_ms: day.start * 1000,
        cost_usd: day.cost_usd,
        hit_ratio: day.hit_ratio(),
        saved_usd: day.saved_usd,
        win,
    })
}

pub fn read<Tz: TimeZone>(
    store: &Store,
    prices: &PriceTable,
    request: &Request,
    tz: &Tz,
) -> Result<InsightsReport>
where
    Tz::Offset: std::fmt::Display,
{
    let now_s = request.now_ms.div_euclid(1000);
    let spans = calendar::spans(Range::Month, now_s, tz)?;
    let since = now_s - WINDOW_DAYS * DAY_S;
    let month = store.requests_between(spans.since().min(since), spans.until)?;
    let calendar_days = days(&spans, &month, prices);
    let requests: Vec<SpentRequest> = month
        .into_iter()
        .filter(|r| r.point.ts >= since && r.point.ts < spans.until)
        .collect();
    let sessions = store.sessions_spending_between(since, spans.until)?;
    let (rebuilds, compactions) =
        rebuilds(store, prices, &requests, since, spans.until, request.now_ms)?;
    let project = store.session_project(request.session)?;
    let live = store
        .live_breakdown(request.session)?
        .and_then(|stored| breakdown::parse(stored.ts_ms, &stored.json));
    let recent: Vec<breakdown::Breakdown> = store
        .recent_breakdowns(context_model::CALIBRATION_BREAKDOWNS)?
        .into_iter()
        .filter_map(|stored| breakdown::parse(stored.ts_ms, &stored.json))
        .collect();
    let ratios = context_model::ratios::calibrate(request.scan, &recent);
    let session_uses = |recent_skills, recent_tools| -> Result<Uses> {
        Ok(Uses {
            session_skills: store.skill_uses_in_session(request.session)?,
            recent_skills,
            session_tools: store.mcp_tool_uses_in_session(request.session)?,
            recent_tools,
        })
    };
    let fortnight = session_uses(
        store.skill_uses_since(since)?,
        store.mcp_tool_uses_since(since)?,
    )?;
    let month_since = now_s - MONTH_DAYS * DAY_S;
    let monthly = session_uses(
        store.skill_uses_since(month_since)?,
        store.mcp_tool_uses_since(month_since)?,
    )?;
    let all = items::items(live.as_ref(), request.scan, &ratios, &fortnight);
    let dead_weight = items::dead_weight(&all, live.as_ref());
    let month_items = items::items(live.as_ref(), request.scan, &ratios, &monthly);
    let memory = memory_texts(request.scan);
    let rates = Rates::of(&limits::stored_fit(store)?);
    let ctx = InsightContext {
        now_ms: request.now_ms,
        since_ts: since,
        prices,
        rates: &rates,
        requests: &requests,
        sessions: &sessions,
        project: project.as_deref(),
        prompts: &store.prompts_between(since, spans.until)?,
        rebuilds: &rebuilds,
        tool_results: &store.large_tool_results_between(since, spans.until, LARGE_RESULT_CHARS)?,
        compactions: &compactions,
        dead_weight: &dead_weight,
        month_items: &month_items,
        memory: &memory,
        ratios: &ratios,
        retention_days: request.retention_days,
    };
    Ok(InsightsReport {
        v: INSIGHTS_VERSION,
        session: request.session.to_string(),
        generated_at_ms: request.now_ms,
        since_ms: since * 1000,
        requests: requests.iter().filter(|r| is_main(r)).count() as u64,
        sessions: sessions.len() as u64,
        findings: evaluate(&ctx),
        wins: wins(&calendar_days),
        recap: recap(&calendar_days),
    })
}

fn rebuilds(
    store: &Store,
    prices: &PriceTable,
    requests: &[SpentRequest],
    since: i64,
    until: i64,
    now_ms: i64,
) -> Result<(Vec<Rebuilt>, Vec<CompactionPoint>)> {
    let ids: BTreeSet<&str> = requests.iter().map(|r| r.session_id.as_str()).collect();
    let mut rebuilt = Vec::new();
    let mut compactions = Vec::new();
    for session in ids {
        let previous = store.last_main_request_before(session, since)?;
        let from = previous.as_ref().map_or(since, |p| p.ts.min(since));
        let mut points: Vec<_> = previous.into_iter().collect();
        points.extend(
            requests
                .iter()
                .filter(|r| r.session_id == session)
                .map(|r| r.point.clone()),
        );
        let kinds = store.prefix_kinds_between(session, from, until)?;
        let compacted = store.compactions_between(session, from, until)?;
        let timeline = Timeline::build(&points, &[]);
        let main = timeline.main();
        let (ttl, _) = cache_model::ttl_of(&Thread::Main, &main, false);
        let changes: Vec<i64> = kinds.iter().map(|k| k.ts).collect();
        let compacted_ts: Vec<i64> = compacted.iter().map(|c| c.ts).collect();
        let found = cache_model::rebuilds(
            &main,
            ttl,
            &Context {
                prices,
                prefix_changes: &changes,
                compactions: &compacted_ts,
                subscription: false,
                now_ms,
            },
        );
        for rebuild in found.into_iter().filter(|r| r.ts_ms >= since * 1000) {
            let before = main
                .iter()
                .rev()
                .find(|o| o.ts_ms < rebuild.ts_ms)
                .map_or(rebuild.ts_ms, |o| o.ts_ms);
            let between: BTreeSet<String> = kinds
                .iter()
                .filter(|k| before < k.ts * 1000 && k.ts * 1000 <= rebuild.ts_ms)
                .map(|k| k.kind.clone())
                .collect();
            rebuilt.push(Rebuilt {
                session_id: session.to_string(),
                gap_ms: rebuild.ts_ms - before,
                ttl_ms: ttl.millis(),
                kinds: between.into_iter().collect(),
                rebuild,
            });
        }
        compactions.extend(compacted.into_iter().filter(|c| c.ts >= since));
    }
    Ok((rebuilt, compactions))
}

fn memory_texts(scan: &Scan) -> Vec<MemoryText> {
    let mut seen = BTreeMap::new();
    for source in &scan.sources {
        let always = matches!(source.kind, SourceKind::ClaudeMd | SourceKind::Memory)
            && source.loading == Loading::Always;
        let Some(path) = source.path.as_deref().filter(|_| always) else {
            continue;
        };
        let Some(text) = config_scan::read_text(Path::new(path)).and_then(|t| t.content) else {
            continue;
        };
        let text = match source.kind {
            SourceKind::Memory => text
                .split_inclusive('\n')
                .take(config_scan::MEMORY_INDEX_LINES)
                .collect(),
            _ => text,
        };
        seen.entry(path.to_string()).or_insert(MemoryText {
            name: source.name.clone(),
            text,
        });
    }
    seen.into_values().collect()
}
```

```rust
pub async fn insights(state: Arc<State>, query: Option<&str>) -> Reply {
    let session = match session_of(query) {

    let built = tokio::task::spawn_blocking(move || -> Result<Option<InsightsReport>> {
        let project_dir = {

            if reader.reindex_pending()? {

            claude_dir: state.claude_dir.clone(),
            claude_json: state.claude_json.clone(),
            project: project_dir.as_ref().map(PathBuf::from),
```

```ts
import type { Daemon, Finding, InsightsFailure, InsightsReport, Recap } from '../types'
import { money, percent } from './format'
import type { Line } from './state'
import { MIN_CONTENT, PADDING, WHY_COLUMNS, fitting, gap, notice, pair, plain, prose } from './state'

export const STREAK_SHOWN = 2
export const INDENT = 2
export const RETRY_SECONDS = 60

const CONFIDENCE: Readonly<Record<Finding['confidence'], string>> = { high: 'high confidence', medium: 'medium confidence', low: 'low confidence' }

export type InsightsInput = {
  width: number
  report: InsightsReport | null
  failure: InsightsFailure | null
  daemon: Daemon
  expanded: readonly string[]
}

export function weekly(usd: number): string {
  return `~${money(usd)}/week`
}

export function capitalized(text: string): string {
  return text.charAt(0).toUpperCase() + text.slice(1)
}

export function recapText(recap: Recap): string {
  const parts = [`${recap.day}: ${money(recap.cost_usd)}`]
  if (recap.hit_ratio !== null) parts.push(`${percent(recap.hit_ratio * 100)} cache hits`)
  if (recap.win !== null) parts.push(`biggest win: ${recap.win}`)
  return parts.join(' · ')
}

export function insightsScreen(input: InsightsInput): Line[] {
  const width = Math.max(MIN_CONTENT, input.width - 2 * PADDING)
  const report = input.report
  const sections = [
    notice(input, width),
    headline(input, report, width),
    ...(report === null || report.requests === 0 ? [] : [wins(report, width), ...report.findings.map(found => findingLines(input, found))]),
  ].filter(section => section.length > 0)
  return sections.flatMap((section, index) => (index === 0 ? section : [gap(index), ...section]))
}

function headline(input: InsightsInput, report: InsightsReport | null, width: number): Line[] {
  const title = plain('ins-head', 'Insights', { bold: true })
  if (report === null) {
    if (input.daemon.status !== 'ok') return []
    if (input.failure !== null) return [title, ...failed(input.failure)]
    return [title, prose('ins-loading', 'Looking for ways to save… ✻', { dim: true })]
  }
  if (report.requests === 0) return [title, prose('ins-empty', 'Insights need a few sessions of history ✻', { dim: true })]
  if (report.findings.length === 0) return [title, prose('ins-lean', 'No savings to suggest right now ✻ your setup looks lean', { dim: true })]
  const priced = report.findings.filter(found => found.saving_usd !== null)
  const total = priced.reduce((sum, found) => sum + (found.saving_usd ?? 0), 0)
  const lines: Line[] = []
  if (priced.length === 0) {
    lines.push(title)
  } else {
    lines.push({ ...pair('ins-head', 'Insights', `up to ${weekly(total)}`, width - WHY_COLUMNS, { color: 'claude', bold: true }, { bold: true }), why: 'ins-total' })
  }
  const count = report.findings.length
  const tips = `${count} ${count === 1 ? 'tip' : 'tips'} from your last 14 days`
  const shares = priced.map(found => found.saving_pct_5h).filter((pct): pct is number => pct !== null)
  const share = shares.length > 0 ? ` · ~${percent(shares.reduce((sum, pct) => sum + pct, 0))} of 5h` : ''
  lines.push(plain('ins-sub', fitting(width, `${tips}${share}`, tips), { dim: true }))
  if (input.failure !== null) lines.push(prose('ins-stale', `Could not refresh: ${input.failure.reason}`, { dim: true }))
  if (input.expanded.includes('ins-total')) {
    lines.push(
      prose('explain-ins-total', 'Each saving is a weekly estimate at API prices from your last 14 days. Tips can overlap, so the total is the most you could save.', {
        dim: true,
      }),
    )
  }
  return lines
}

function failed(failure: InsightsFailure): Line[] {
  if (failure.kind === 'missing') {
    return [
      prose('ins-failed', 'This claude-plus daemon is older than the pane and has no Insights', { dim: true }),
      prose('ins-retry', 'Run claude-plus daemon stop to restart it', { dim: true }),
    ]
  }
  return [
    prose('ins-failed', `Could not look for savings: ${failure.reason}`, { dim: true }),
    prose('ins-retry', `Trying again every ${RETRY_SECONDS} s`, { dim: true }),
  ]
}

function wins(report: InsightsReport, width: number): Line[] {
  const lines: Line[] = []
  const saved = report.wins.saved_usd_7d
  if (saved >= 0.01) {
    const text = `✻ Cache hits saved you ${money(saved)}`
    lines.push(plain('ins-win-saved', fitting(width, `${text} this week`, text), { color: 'success' }))
  }
  const streak = report.wins.hit_streak_days
  if (streak >= STREAK_SHOWN) {
    lines.push(plain('ins-win-streak', fitting(width, `✻ ${streak} days in a row above 90% cache hits`, `✻ ${streak} days above 90% cache hits`), { color: 'success' }))
  }
  return lines
}

function findingLines(input: InsightsInput, found: Finding): Line[] {
  const key = `ins-${found.rule}`
  const title: Line =
    found.saving_usd === null
      ? { key, segments: [{ text: capitalized(found.tip) }], wrap: true }
      : { key, segments: [{ text: `Save ${weekly(found.saving_usd)}`, color: 'success', bold: true }, { text: `: ${found.tip}` }], wrap: true }
  const lines: Line[] = [title, ...found.evidence.map((text, line) => prose(`${key}-${line}`, text, { dim: true }, INDENT))]
  const confidence = CONFIDENCE[found.confidence]
  const meta = found.saving_pct_5h === null ? confidence : `~${percent(found.saving_pct_5h)} of 5h · ${confidence}`
  lines.push({ key: `${key}-meta`, segments: [{ text: `${' '.repeat(INDENT)}${meta}`, dim: true }], why: key })
  if (input.expanded.includes(key)) lines.push(prose(`explain-${key}`, found.how, { dim: true }, INDENT))
  return lines
}
```

```ts
import type { Alerted, Daemon, Local, Snapshot } from '../types'
import { duration, money, tokens } from './format'
import { LAST_MINUTE_MS, RESET_TOLERANCE_MS, cacheClock, current, limitsOf } from './state'

export const CONTEXT_ALERT = 0.9
export const CONTEXT_REARM = 0.8
export const CONTEXT_ASK_PCT = 60
export const ALERT_TOAST_MS = 8000
export const CHIME = 'sounds/chime.wav'

export const EMPTY_ALERTED: Alerted = { session: null, cacheFor: null, paceFor: null, contextFired: false, threshold: null, thresholdAsked: false }

export type Alert = { kind: 'cache' | 'pace' | 'context'; text: string }

export type AlertInput = { nowMs: number; snapshot: Snapshot | null; local: Local; daemon: Daemon; known: Alerted }

export function ownAlerts(known: Alerted, session: string | null): Alerted {
  return known.session === session ? known : { ...EMPTY_ALERTED, session }
}

export function thresholdOf(local: Local, known: Alerted): number | null {
  return local.breakdown?.auto_compact_threshold ?? known.threshold
}

export function wantsThreshold(local: Local, known: Alerted): boolean {
  const percent = local.measure?.contextPercent ?? null
  return percent !== null && percent >= CONTEXT_ASK_PCT && thresholdOf(local, ownAlerts(known, local.session)) === null && !ownAlerts(known, local.session).thresholdAsked
}

export function alertsOf(input: AlertInput): { alerts: Alert[]; next: Alerted } {
  const known = ownAlerts(input.known, input.local.session)
  const alerts: Alert[] = []
  const next: Alerted = { ...known }
  const snapshot = current(input)
  const clock = cacheClock(snapshot, input.local, input.nowMs)
  if (clock.state === 'warm' && clock.remainingMs <= LAST_MINUTE_MS && !input.local.working && known.cacheFor !== clock.expiresAtMs) {
    const cold = snapshot?.live.forecast?.cold_usd ?? null
    const price = cold === null ? '' : ` rewarming later costs ~${money(cold)}`
    alerts.push({ kind: 'cache', text: `Cache goes cold in under a minute ✻${price}` })
    next.cacheFor = clock.expiresAtMs
  }
  const five = limitsOf({ ...input, snapshot }).find(limit => limit.window === 'five_hour')
  const full = five?.pace?.full_at_ms ?? null
  const resets = five?.resets_at_ms ?? null
  if (full !== null && resets !== null && full < resets && (known.paceFor === null || Math.abs(known.paceFor - resets) > RESET_TOLERANCE_MS)) {
    const left = duration(Math.max(0, full - input.nowMs))
    alerts.push({ kind: 'pace', text: `At this pace the 5h limit runs out in ${left}, before its reset in ${duration(resets - input.nowMs)}` })
    next.paceFor = resets
  }
  const used = input.local.measure?.contextTokens ?? null
  const threshold = thresholdOf(input.local, known)
  if (used !== null && threshold !== null && threshold > 0) {
    const ratio = used / threshold
    if (ratio >= CONTEXT_ALERT && !known.contextFired) {
      alerts.push({ kind: 'context', text: `Context is close to auto-compact, ${tokens(used)} of ${tokens(threshold)} ✻ /compact now to choose what stays` })
      next.contextFired = true
    }
    if (ratio < CONTEXT_REARM) next.contextFired = false
  }
  return { alerts, next }
}
```

```python
import math
import struct
import sys
import wave
from pathlib import Path

RATE = 22_050
SECONDS = 0.6
PEAK = 0.3
ATTACK = 0.01
DECAY = 0.12
PARTIALS = ((880.0, 1.0), (1760.0, 0.3), (2640.0, 0.1))


def sample(index: int) -> int:
    t = index / RATE
    envelope = min(1.0, t / ATTACK) * math.exp(-t / DECAY)
    tone = sum(level * math.sin(2 * math.pi * pitch * t) for pitch, level in PARTIALS)
    loudest = sum(level for _, level in PARTIALS)
    return round(32_767 * PEAK * envelope * tone / loudest)


def main() -> None:
    target = Path(sys.argv[1]) if len(sys.argv) > 1 else Path(__file__).resolve().parent.parent / "mod" / "sounds" / "chime.wav"
    target.parent.mkdir(parents=True, exist_ok=True)
    frames = b"".join(struct.pack("<h", sample(index)) for index in range(int(RATE * SECONDS)))
    with wave.open(str(target), "wb") as out:
        out.setnchannels(1)
        out.setsampwidth(2)
        out.setframerate(RATE)
        out.writeframes(frames)


if __name__ == "__main__":
    main()
```
