# claude-plus Milestone 5 (History View) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pane gains a History view (hotkey `3`) that draws, over the last 24 hours, 7, 30 or 90 days (`r`), the daily cost stacked by model, the cache hit ratio, the highest 5h limit use and the context growth of the current session as raster charts, ranks the top projects and sessions, and switches every number between dollars, tokens and percent of the 5h limit (`g`); the CLI gains `claude-plus export --format json|csv`.

**Architecture:** A new daemon unit `history` splits a range into local hours or calendar days (`history::calendar`), reads requests, adjustments, limit samples, prefix changes and compactions of the range through indexed store reads, and builds `HistoryReport` v1, which a new route `GET /history?range=` serves; `history::export` turns the same rows into JSON or CSV for the new `export` subcommand.
The mod fetches the report while the History view is shown, off the ticker, and keeps one report per range.
Charts are a pure grid of cells (`hooks/chart.ts`) laid out by a pure screen model (`hooks/history.ts`); the pane draws a grid as one `Raster` where Claude Code's theme has a known palette (`hooks/palette.ts`) and as rows of colored `Text` everywhere else, and every `$` call and atom stays in `hooks/register.tsx`.

**Tech Stack:** Rust (edition 2024, MSRV 1.88), no new crates (`chrono`, `serde_json`, `rusqlite` and `clap` are already dependencies); Claude Code 2.1.296 function hooks (TypeScript, JSX with `h`, `Raster` from the terminal element table), `claude plugin validate` and `claude plugin test`, TypeScript 6.0.3 through `npx` for type-checking only.
Node and npx are installed at `/opt/homebrew/bin`; there is no global `tsc`, and `npx --offline -p typescript@6.0.3 tsc` runs from the npx cache.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 3 "The pane" view 3 and "Look and feel", 4 "Units" `history` and the CLI's `export`, "Storage schema" `requests`, `adjustments`, `limit_samples`, `attachments`, `compactions`, 5 "Cache model" rebuild detection, 6 "Plan limits" calibration, 7 "Error handling and safety", 8 "Testing", 9 milestone 5: "History view with raster charts").

This plan starts from `main` at `18bbd53`, the end state of the M4 plan with its review fixes.

## Decisions

The spec is silent on these points, so this plan decides them.

1. The report gets its own route, `GET /history?range=24h|7d|30d|90d`, instead of a field in the snapshot, because it reads whole ranges and only matters while the History view is shown.
   A missing `range` means `7d`; anything else is 400 `range must be 24h, 7d, 30d or 90d`; another method is 405 and a store being rebuilt is 503, as on the other routes.
   The route is new, so `API_VERSION` stays 1, and the report carries its own `v: 1` (`HISTORY_VERSION`).
   The schema does not change.
2. `24h` is the last 24 local hours ending with the current one (labels `14:00`), and `7d`, `30d` and `90d` are local calendar days ending today (labels `Oct 5`), in the daemon's time zone, with days that skip midnight starting when the gap ends.
   The daemon writes the labels, so the mod needs no time zone.
   `local_midnight` moves from `cli/stats.rs` to `history/calendar.rs`, and `stats` uses it from there.
3. Spend counts what `stats` counts: request costs plus the reconciled adjustments from Claude Code's session counters (shown apart as `reconciled_usd`); a request on an unknown model counts as a request and as `unpriced`.
   Tokens are input, cache reads, cache writes and output of requests and adjustments.
4. Percent of the 5h window is the cost times the `pct_per_usd` of the stored `five_hour` fit of the model's family, once that fit has 20 pairs; a family without a calibrated fit of its own borrows the calibrated fit with the most pairs.
   With no calibrated fit at all every `pct_5h` is `null` and `calibration.calibrated` is `false`; the mod then skips `% of 5h` when `g` cycles, and it shows every percent with `~`.
5. The hit ratio is cache reads over prompt tokens (input, cache reads and cache writes) of every request in the bucket, subagents included; adjustments have no cache split and are left out.
6. Rebuilds are found per session on its main thread with the M3 `cache_model` rule, starting from the session's last main-thread request before the range so the first request of the range can be one; the lifetime is the observed one, else 5 minutes, and prefix changes and compactions are read from that request on.
   `cache_model` exports `rebuilds` and `saved_usd` for this, and `model` uses them, so the Live view does not change.
7. Compactions count the main thread only; the highest 5h use of a bucket is the highest `five_hour` limit sample in it, and a bucket without samples has none.
8. Models are ranked by cost, then tokens; the report lists the top 5 and every bucket lists all of its models, so the mod draws the rest together as `Other`.
   Model ids are normalized (a date suffix dropped) in the report; `export` keeps them as stored, as `stats` does.
9. A project is named by the last folder of its sessions' `cwd`, with the parent folder in front when two projects share a name, and by its Claude Code project key when no session has a `cwd`.
   The top 5 projects and the top 5 sessions are ranked by cost whatever `g` shows; a session without a title reads `Untitled <first 8 characters of its id>`.
10. Every store read of the report searches an index (`requests_by_ts`, `requests_by_session`, `adjustments_by_ts`, `limit_samples_by_window`, `attachments_by_session`, `compactions_by_session`), and a test asserts that no plan scans a table; attachments and compactions are read per session for that reason.
    On a real store of 82,000 requests the route answers in 30 to 50 ms for `24h` and `7d` and in 200 to 330 ms for `30d` and `90d` once warm, 0.82 s at most cold (measured after the M5 review; the plan first said 0.7 s).
    The route reads through its own read-only connection, so a report never holds the reader that `/snapshot` and `/context` share; on that store a snapshot sent during a cold `30d` report answers in 8 to 37 ms instead of 0.76 s.
11. The mod asks for `/history` with a 3 s timeout instead of the 500 ms of the other calls, runs the request beside the ticker instead of awaiting it, and runs one at a time, so a slow report neither cuts the request short nor stops the cache countdown.
    It asks at once when the view opens or the range changes, then every 30 s while the view is shown, and never from Live or Context.
12. Reports live in a `history` atom (shape `history-1`) as one report per range, so going back to a range draws at once; a report whose `range` is not the one asked for is dropped.
    The chosen range and metric live in a `chart` atom (`7d` and `Cost` at first), not in the plugin store, so a new Claude Code process starts at 7 days and Cost.
13. A chart is a grid of cells, each a glyph, a foreground and a background theme key or none, built by pure functions in `hooks/chart.ts`.
    The pane draws a grid as one `Raster` when it is drawn on the terminal and the theme is `dark`, `light`, `dark-daltonized` or `light-daltonized`, whose RGB values `hooks/palette.ts` holds as Claude Code 2.1.296 defines them; anywhere else (`auto`, the ANSI themes, a custom theme, the desktop and mobile surfaces) it draws the same cells as rows of `Text` with `color` and `backgroundColor` theme keys.
    `Raster` takes no theme keys, which is why the palette exists, and colors outside the palette's keys fall back to the terminal's default.
14. The mod reads the theme with `$.config.list()` (row `theme`) at `session.start` and before each history request, and a `config.set` hook on the key `theme` updates it as soon as a change is written.
    The validator reports `gating hook without .catch: config.set{key=theme}`; like the M4 note on `session.compact`, a failing observer fails open, which is right for a mod that only watches.
15. `Raster` cells are encoded by the mod's own base64 of little-endian u32 triplets, because the `es2023` library the mod is checked against has no `Uint8Array.toBase64`.
    Raster is tested three ways: pure tests pin the cells and their exact base64, the test painter (`tests/paint.ts`) decodes a mounted `Raster` back into glyphs for whole-frame tests, and `claude plugin test` mounts each chart through the engine, which refuses a tree whose cells do not decode or hold a wide glyph.
16. A chart of N buckets in W columns merges `ceil(N / W)` buckets into each bar, keeps the newest and drops the oldest `N mod per` that do not fill a bar, gives every bar `floor(W / bars)` columns with a one-column gap on its left from 3 columns on, and leaves the spare columns on the left, so the newest bar always ends at the right edge above `today` or `now`.
    The title says so: `Cost by day`, `Cost per 3 days`, `Tokens by hour`.
17. Bars are lower-eighth blocks (`▁` to `█`) 8 steps per row; where two models meet inside a cell the lower one is the glyph's color and the upper one the cell's background, the top cell takes the color of the model that fills most of it, and any spend at all shows at least one eighth.
    Models take `claude`, `permission`, `planMode`, `autoAccept` and `bashBorder` by rank, and `Other` takes `inactive`.
18. The view reads top to bottom, in the spec's order: `Last <range>` with the total, the session and request counts; the spend chart (6 rows, `peak <value>` on the right, an axis row, one legend row per model); `Cache hit ratio` (2 rows in `success`, with the scale starting at the lowest tenth of the shown ratios, at most 90%, which its `?` explains), `Saved by cache hits` and `Rebuilds`; `5h limit, highest` (3 rows on a fixed 100% scale, `warning` from 80% and `permission` below, left out without samples); `Top projects`; `Top sessions`; `Context this session` (a braille area of 3 rows over the M4 report's `history.points`, scaled to the context window, a `┊` in `warning` above each compaction and a note under it, left out before two requests).
19. With `% of 5h` shown the headline has a `?` that names how many limit readings the estimate learned from.
20. The header gains `3: History`; when `✻ claude-plus` and the three tabs do not fit (at 40 columns) the brand shortens to `✻`, which changes the first line of the M3 and M4 frame tests.
21. The History view puts a row of two plain Buttons under the header, `r: 7 days  g: Cost`, two columns apart; each label is the current choice, and pressing it or its hotkey moves to the next.
22. Before the first report of a range the view reads `Loading the last 30 days… ✻`; a range without requests reads `No requests in the last 30 days yet ✻`; with the daemon down and no report it shows only the daemon notice, and with a report it shows the notice above the kept report.
23. While the History view is shown the mod also polls `/context` every 10 s, as the Context view does, for the growth curve.
24. `claude-plus export --format json|csv [--days N]` imports first, as `stats` does, honors `CLAUDE_PLUS_NOW`, and prints one row per local day, project and model, in that order; without `--days` it prints all history.
    CSV is RFC 4180 with a header row and costs to 6 decimals; JSON is `{"v":1,"rows":[...]}`; an empty export is the header alone or `{"v":1,"rows":[]}`.
25. The History view has no animation and uses no `$.ui.blit`: its charts change at most every 30 s.

## Review Focus

1. Buckets must follow the person's calendar, not UTC: a day that skips its midnight starts when the gap ends, the week ends today and the day ends with the current hour (Task 2 tests `local_midnight_skipped_by_a_gap_starts_the_day_when_the_gap_ends`, `longer_ranges_are_local_calendar_days_with_today_last` and `a_day_is_the_last_24_local_hours_ending_with_this_one`).
2. The History totals and the export must agree with `stats`, reconciled spend included, and the 5h share must not appear before it is calibrated (Task 3 tests `the_week_report_matches_the_contract` and `without_a_calibrated_five_hour_fit_no_percent_is_shown`, Task 5 test `export_csv_is_exact_and_matches_stats`).
3. A Raster the engine cannot decode, or a wide glyph in it, refuses the whole pane: the cells must encode exactly and mount (Task 7 test `cells encode as little-endian code point, foreground and background in padded base64`, Task 9 test `the History tab draws raster charts at ${columns} columns`).
4. Where no palette is known the charts must still draw, in theme keys, and follow a theme change at once (Task 9 tests `charts are text in theme colors where the theme has no known palette, and follow a theme change` and `the desktop draws the charts as text`).
5. A slow `/history` must neither be cut short nor hold up the ticker, and the history store reads must not scan whole tables (Task 9 tests `a History report that takes two seconds still arrives and the countdown never waits for it` and `the History view asks for its report every 30 s while shown and not at all from Live`, Task 1 test `the_history_reads_search_indexes_instead_of_scanning_tables`).

const REQUESTS_BETWEEN: &str =
    "FROM requests WHERE ts >= ?1 AND ts < ?2 ORDER BY session_id, ts, key";

const LAST_MAIN_REQUEST_BEFORE: &str = "FROM requests
     WHERE session_id = ?1 AND ts < ?2 AND is_sidechain = 0 ORDER BY ts DESC, key DESC LIMIT 1";

const ADJUSTMENTS_BETWEEN: &str =
    "SELECT session_id, ts, model, input, output, cache_read, cache_write, cost_usd
     FROM adjustments WHERE ts >= ?1 AND ts < ?2 ORDER BY session_id, ts, model";

const SESSIONS_SPENDING_BETWEEN: &str = "SELECT id, project, cwd, title FROM sessions WHERE id IN (
         SELECT session_id FROM requests WHERE ts >= ?1 AND ts < ?2
         UNION SELECT session_id FROM adjustments WHERE ts >= ?1 AND ts < ?2)
     ORDER BY id";

const LIMIT_SAMPLES_BETWEEN: &str =
    "SELECT ts_ms, session_id, model, window, used_pct, resets_at_ms
     FROM limit_samples WHERE window = ?1 AND ts_ms >= ?2 AND ts_ms < ?3 ORDER BY ts_ms, id";

fn prefix_changes_sql() -> String {
    let kinds = vec!["?"; PREFIX_KINDS.len()].join(", ");
    format!(
        "SELECT ts FROM attachments
         WHERE session_id = ? AND ts >= ? AND ts < ? AND kind IN ({kinds}) ORDER BY ts"
    )
}

fn compactions_sql() -> String {
    format!(
        "SELECT c.ts, {MAIN_THREAD} FROM compactions c JOIN files f ON f.id = c.file_id
         WHERE c.session_id = ?1 AND c.ts >= ?2 AND c.ts < ?3 ORDER BY c.ts, c.line_no"
    )
}

fn history_statements() -> Vec<String> {
    vec![

        SESSIONS_SPENDING_BETWEEN.to_string(),

        compactions_sql(),

impl Store {
    pub fn requests_between(&self, since_ts: i64, until_ts: i64) -> Result<Vec<SpentRequest>> {
        let mut statement = self.conn.prepare_cached(&format!(
            "SELECT {POINT_COLUMNS}, session_id, cost_usd {REQUESTS_BETWEEN}"
        ))?;
        let rows = statement.query_map([since_ts, until_ts], |r| {
            Ok(SpentRequest {
                point: point_of(r)?,
                session_id: r.get(12)?,
                cost_usd: r.get(13)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn last_main_request_before(
        &self,
        session_id: &str,
        before_ts: i64,
    ) -> Result<Option<RequestPoint>> {
        Ok(self
            .conn
            .prepare_cached(&format!(
                "SELECT {POINT_COLUMNS} {LAST_MAIN_REQUEST_BEFORE}"
            ))?
            .query_row(params![session_id, before_ts], point_of)
            .optional()?)
    }

    pub fn adjustments_between(
        &self,
        since_ts: i64,
        until_ts: i64,
    ) -> Result<Vec<SpentAdjustment>> {
        let mut statement = self.conn.prepare_cached(ADJUSTMENTS_BETWEEN)?;
        let rows = statement.query_map([since_ts, until_ts], |r| {
            let count = |index| -> rusqlite::Result<u64> { Ok(r.get::<_, i64>(index)? as u64) };
            Ok(SpentAdjustment {
                session_id: r.get(0)?,
                ts: r.get(1)?,
                model: r.get(2)?,
                tokens: TokenCounts {
                    input: count(3)?,
                    output: count(4)?,
                    cache_read: count(5)?,
                    cache_write_5m: count(6)?,
                    ..Default::default()
                },
                cost_usd: r.get(7)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn sessions_spending_between(
        &self,
        since_ts: i64,
        until_ts: i64,
    ) -> Result<Vec<SessionInfo>> {
        let mut statement = self.conn.prepare_cached(SESSIONS_SPENDING_BETWEEN)?;
        let rows = statement.query_map([since_ts, until_ts], |r| {
            Ok(SessionInfo {
                id: r.get(0)?,
                project: r.get(1)?,
                cwd: r.get(2)?,
                title: r.get(3)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn limit_samples_between(
        &self,
        window: &str,
        since_ms: i64,
        until_ms: i64,
    ) -> Result<Vec<LimitSample>> {
        let mut statement = self.conn.prepare_cached(LIMIT_SAMPLES_BETWEEN)?;
        let rows = statement.query_map(params![window, since_ms, until_ms], |r| {
            Ok(LimitSample {
                ts_ms: r.get(0)?,
                session_id: r.get(1)?,
                model: r.get(2)?,
                window: r.get(3)?,
                used_pct: r.get(4)?,
                resets_at_ms: r.get(5)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn prefix_changes_between(
        &self,
        session_id: &str,
        since_ts: i64,
        until_ts: i64,
    ) -> Result<Vec<i64>> {
        let mut statement = self.conn.prepare_cached(&prefix_changes_sql())?;
        let mut values: Vec<Value> = vec![
            session_id.to_string().into(),
            since_ts.into(),
            until_ts.into(),
        ];
        values.extend(
            PREFIX_KINDS
                .iter()
                .map(|kind| Value::from(kind.to_string())),
        );
        let rows = statement.query_map(rusqlite::params_from_iter(values), |r| r.get(0))?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn compactions_between(
        &self,
        session_id: &str,
        since_ts: i64,
        until_ts: i64,

        let rows = statement.query_map(params![session_id, since_ts, until_ts], |r| {
            Ok(CompactionPoint {
                session_id: session_id.to_string(),
                ts: r.get(0)?,
                main: r.get(1)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

pub struct Span {
    pub start: i64,
    pub label: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Spans {
    pub spans: Vec<Span>,
    pub until: i64,
}

impl Spans {
    pub fn since(&self) -> i64 {
        self.spans.first().map_or(self.until, |span| span.start)
    }

    pub fn index_of(&self, ts: i64) -> Option<usize> {
        if ts < self.since() || ts >= self.until {
            return None;
        }
        Some(self.spans.partition_point(|span| span.start <= ts) - 1)
    }
}

pub fn spans<Tz: TimeZone>(range: Range, now_s: i64, tz: &Tz) -> Result<Spans>
where
    Tz::Offset: std::fmt::Display,
{
    let now = DateTime::from_timestamp(now_s, 0)
        .context("the clock is out of range")?
        .with_timezone(tz);
    match range {
        Range::Day => {
            let hour = now_s - i64::from(now.minute() * 60 + now.second());
            let spans = (0..24)
                .rev()
                .map(|back| {
                    let start = hour - back * HOUR_S;
                    Ok(Span {
                        start,
                        label: label(start, tz, "%H:%M")?,
                    })
                })
                .collect::<Result<_>>()?;
            Ok(Spans {
                spans,
                until: hour + HOUR_S,
            })
        }
        _ => {
            let days = range.days();
            let today = now.date_naive();
            let first = today
                .checked_sub_days(Days::new(days - 1))
                .context("the range reaches before the calendar start")?;
            let spans = (0..days)
                .map(|offset| {
                    let day = first + Days::new(offset);
                    let start = local_midnight(day, tz)?;
                    Ok(Span {
                        start,
                        label: day.format("%b %-d").to_string(),
                    })
                })
                .collect::<Result<_>>()?;
            let tomorrow = today
                .checked_add_days(Days::new(1))
                .context("today is the last supported day")?;
            Ok(Spans {
                spans,
                until: local_midnight(tomorrow, tz)?,
            })
        }
    }
}

fn rounded(value: serde_json::Value) -> serde_json::Value {
    match value {
        serde_json::Value::Number(number) if number.is_f64() => {
            json!((number.as_f64().unwrap() * 1e6).round() / 1e6)
        }
        serde_json::Value::Array(items) => items.into_iter().map(rounded).collect(),
        serde_json::Value::Object(fields) => fields
            .into_iter()
            .map(|(key, value)| (key, rounded(value)))
            .collect(),
        other => other,
    }
}

    pub sessions: &'a [SessionInfo],
    pub rebuilds: &'a [Rebuild],
    pub samples: &'a [LimitSample],
    pub compactions: &'a [CompactionPoint],
    pub fits: &'a [Fit],
    pub prices: &'a PriceTable,
}

struct Rates {
    by_family: BTreeMap<String, f64>,
    fallback: Option<f64>,
    pairs: u32,
}

impl Rates {
    fn of(fits: &[Fit]) -> Self {
        let five_hour: Vec<&Fit> = fits.iter().filter(|fit| fit.window == FIVE_HOUR).collect();
        let calibrated: Vec<&&Fit> = five_hour
            .iter()
            .filter(|fit| fit.pairs >= PAIRS_NEEDED)
            .collect();
        Self {
            by_family: calibrated
                .iter()
                .map(|fit| (fit.family.clone(), fit.pct_per_usd))
                .collect(),
            fallback: calibrated
                .iter()
                .max_by_key(|fit| fit.pairs)
                .map(|fit| fit.pct_per_usd),
            pairs: five_hour.iter().map(|fit| fit.pairs).max().unwrap_or(0),
        }
    }

    fn pct(&self, model: &str, cost_usd: Option<f64>) -> Option<f64> {
        let rate = self
            .by_family
            .get(family(model))
            .copied()
            .or(self.fallback)?;
        Some(cost_usd.unwrap_or(0.0) * rate)
    }

    fn empty(&self) -> Spend {
        Spend {
            requests: 0,
            unpriced: 0,
            cost_usd: 0.0,
            reconciled_usd: 0.0,
            tokens: 0,
            pct_5h: self.fallback.map(|_| 0.0),
        }
    }
}

struct Item {
    cost_usd: Option<f64>,
    tokens: u64,
    pct_5h: Option<f64>,
    is_request: bool,
}

impl Spend {
    fn add(&mut self, item: &Item) {
        if item.is_request {
            self.requests += 1;
            if item.cost_usd.is_none() {
                self.unpriced += 1;
            }
        } else {
            self.reconciled_usd += item.cost_usd.unwrap_or(0.0);
        }
        self.cost_usd += item.cost_usd.unwrap_or(0.0);
        self.tokens += item.tokens;
        if let (Some(total), Some(pct)) = (self.pct_5h.as_mut(), item.pct_5h) {
            *total += pct;
        }
    }
}

pub fn read<Tz: TimeZone>(
    store: &Store,
    prices: &PriceTable,
    range: Range,
    now_ms: i64,
    tz: &Tz,
) -> Result<HistoryReport>
where
    Tz::Offset: std::fmt::Display,
{
    let spans = calendar::spans(range, now_ms.div_euclid(1000), tz)?;
    let (since, until) = (spans.since(), spans.until);
    let requests = store.requests_between(since, until)?;
    let mut previous = HashMap::new();
    for session in sessions_of(&requests) {
        if let Some(point) = store.last_main_request_before(session, since)? {
            previous.insert(session, point);
        }
    }
    let mut prefix = Vec::new();
    let mut compactions = Vec::new();
    for session in sessions_of(&requests) {
        let from = previous
            .get(session)
            .map_or(since, |point| point.ts.min(since));
        prefix.extend(
            store
                .prefix_changes_between(session, from, until)?
                .into_iter()
                .map(|ts| (session.to_string(), ts)),
        );
        compactions.extend(store.compactions_between(session, from, until)?);
    }
    let rebuilds = rebuilds_in(&requests, &previous, &prefix, &compactions, prices, now_ms)
        .into_iter()
        .filter(|rebuild| rebuild.ts_ms >= since * 1000)
        .collect::<Vec<_>>();
    let samples = store.limit_samples_between(FIVE_HOUR, since * 1000, until * 1000)?;
    let in_range: Vec<CompactionPoint> = compactions
        .into_iter()
        .filter(|compaction| compaction.ts >= since)
        .collect();
    Ok(build(
        range,
        &spans,
        &Inputs {
            requests: &requests,
            adjustments: &store.adjustments_between(since, until)?,
            sessions: &store.sessions_spending_between(since, until)?,
            rebuilds: &rebuilds,
            samples: &samples,
            compactions: &in_range,
            fits: &limits::stored_fit(store)?,
            prices,
        },
        now_ms,
    ))
}

fn sessions_of(requests: &[SpentRequest]) -> BTreeSet<&str> {
    requests.iter().map(|r| r.session_id.as_str()).collect()
}

fn rebuilds_in(
    requests: &[SpentRequest],
    previous: &HashMap<&str, RequestPoint>,
    prefix: &[(String, i64)],
    compactions: &[CompactionPoint],
    prices: &PriceTable,
    now_ms: i64,
) -> Vec<Rebuild> {
    let mut by_session: BTreeMap<&str, Vec<RequestPoint>> = BTreeMap::new();
    for request in requests {
        by_session
            .entry(&request.session_id)
            .or_insert_with(|| {
                previous
                    .get(request.session_id.as_str())
                    .cloned()
                    .into_iter()
                    .collect()
            })
            .push(request.point.clone());
    }
    by_session
        .into_iter()
        .flat_map(|(session, points)| {
            let changes: Vec<i64> = prefix
                .iter()
                .filter(|(owner, _)| owner == session)
                .map(|(_, ts)| *ts)
                .collect();
            let compacted: Vec<i64> = compactions
                .iter()
                .filter(|compaction| compaction.session_id == session)
                .map(|compaction| compaction.ts)
                .collect();
            session_rebuilds(&points, &changes, &compacted, prices, now_ms)
        })
        .collect()
}

pub fn session_rebuilds(
    points: &[RequestPoint],
    prefix_changes: &[i64],
    compactions: &[i64],
    prices: &PriceTable,
    now_ms: i64,
) -> Vec<Rebuild> {
    let timeline = Timeline::build(points, &[]);
    let main = timeline.main();
    let (ttl, _) = cache_model::ttl_of(&Thread::Main, &main, false);
    cache_model::rebuilds(
        &main,
        ttl,
        &Context {
            prices,
            prefix_changes,
            compactions,
            subscription: false,
            now_ms,
        },
    )
}

struct Ledger<'a> {
    spans: &'a Spans,
    rates: &'a Rates,
    info: HashMap<&'a str, &'a SessionInfo>,
    buckets: Vec<Bucket>,
    by_bucket: Vec<BTreeMap<String, Spend>>,
    totals: Spend,
    models: BTreeMap<String, Spend>,
    projects: BTreeMap<String, (Spend, HashSet<String>)>,
    sessions: BTreeMap<String, (Spend, i64)>,
}

impl<'a> Ledger<'a> {
    fn new(spans: &'a Spans, rates: &'a Rates, sessions: &'a [SessionInfo]) -> Self {
        Self {
            spans,
            rates,
            info: sessions.iter().map(|s| (s.id.as_str(), s)).collect(),
            buckets: spans
                .spans
                .iter()
                .map(|span| empty_bucket(span, rates))
                .collect(),
            by_bucket: vec![BTreeMap::new(); spans.spans.len()],
            totals: rates.empty(),
            models: BTreeMap::new(),
            projects: BTreeMap::new(),
            sessions: BTreeMap::new(),
        }
    }

    fn add(&mut self, session: &str, ts: i64, model: &str, item: &Item) -> Option<usize> {
        let index = self.spans.index_of(ts)?;
        let model = normalize_model(model).to_string();
        let project = self.info.get(session).map_or("", |s| s.project.as_str());
        let rates = self.rates;
        self.buckets[index].spend.add(item);
        self.by_bucket[index]
            .entry(model.clone())
            .or_insert_with(|| rates.empty())
            .add(item);
        self.totals.add(item);
        self.models
            .entry(model)
            .or_insert_with(|| rates.empty())
            .add(item);
        let (spend, members) = self
            .projects
            .entry(project.to_string())
            .or_insert_with(|| (rates.empty(), HashSet::new()));
        spend.add(item);
        members.insert(session.to_string());
        let (spend, last) = self
            .sessions
            .entry(session.to_string())
            .or_insert_with(|| (rates.empty(), ts));
        spend.add(item);
        *last = (*last).max(ts);
        Some(index)
    }
}

pub fn build(range: Range, spans: &Spans, inputs: &Inputs, now_ms: i64) -> HistoryReport {
    let rates = Rates::of(inputs.fits);
    let mut ledger = Ledger::new(spans, &rates, inputs.sessions);
    let (mut read, mut prompt, mut saved_usd) = (0u64, 0u64, 0.0);
    for request in inputs.requests {
        let point = &request.point;
        let item = Item {
            cost_usd: request.cost_usd,
            tokens: all_tokens(&point.tokens),
            pct_5h: rates.pct(&point.model, request.cost_usd),
            is_request: true,
        };
        let Some(index) = ledger.add(&request.session_id, point.ts, &point.model, &item) else {
            continue;
        };
        ledger.buckets[index].prompt_tokens += point.tokens.prompt_total();
        ledger.buckets[index].cache_read_tokens += point.tokens.cache_read;
        read += point.tokens.cache_read;
        prompt += point.tokens.prompt_total();
        saved_usd +=
            cache_model::saved_usd(&point.model, &point.tokens, inputs.prices).unwrap_or(0.0);
    }
    for adjustment in inputs.adjustments {
        let item = Item {
            cost_usd: adjustment.cost_usd,
            tokens: all_tokens(&adjustment.tokens),
            pct_5h: rates.pct(&adjustment.model, adjustment.cost_usd),
            is_request: false,
        };
        ledger.add(
            &adjustment.session_id,
            adjustment.ts,
            &adjustment.model,
            &item,
        );
    }
    let Ledger {
        info,
        mut buckets,
        by_bucket,
        totals,
        models,
        projects,
        sessions,
        ..
    } = ledger;
    let order = ranked(models);
    for (bucket, spent) in buckets.iter_mut().zip(by_bucket) {
        bucket.models = order
            .iter()
            .filter_map(|model| {
                spent.get(&model.model).map(|spend| ModelSpend {
                    model: model.model.clone(),
                    spend: spend.clone(),
                })
            })
            .collect();
    }
    let (mut rebuilds, mut rebuild_usd, mut idle_rebuilds) = (0, 0.0, 0);
    for rebuild in inputs.rebuilds {
        let Some(index) = spans.index_of(rebuild.ts_ms.div_euclid(1000)) else {
            continue;
        };
        let extra = rebuild.extra_usd.unwrap_or(0.0);
        buckets[index].rebuilds += 1;
        buckets[index].rebuild_usd += extra;
        rebuilds += 1;
        rebuild_usd += extra;
        if rebuild.cause == RebuildCause::Idle {
            idle_rebuilds += 1;
        }
    }
    for sample in inputs.samples.iter().filter(|s| s.window == FIVE_HOUR) {
        if let Some(index) = spans.index_of(sample.ts_ms.div_euclid(1000)) {
            let peak = &mut buckets[index].peak_5h_pct;
            *peak = Some(peak.map_or(sample.used_pct, |p| p.max(sample.used_pct)));
        }
    }
    let mut compactions = 0;
    for compaction in inputs.compactions.iter().filter(|c| c.main) {
        if let Some(index) = spans.index_of(compaction.ts) {
            buckets[index].compactions += 1;
            compactions += 1;
        }
    }
    let peak_5h_pct = buckets
        .iter()
        .filter_map(|bucket| bucket.peak_5h_pct)
        .reduce(f64::max);
    let names = project_names(inputs.sessions);
    let projects = top(
        projects.into_iter().map(|(key, (spend, members))| {
            let (name, path) = names
                .get(&key)
                .cloned()
                .unwrap_or_else(|| (key.clone(), None));
            ProjectSpend {
                name,
                path,
                sessions: members.len() as u64,
                spend,
            }
        }),
        |project| &project.spend,
    );
    let session_count = sessions.len() as u64;
    let sessions = top(
        sessions.into_iter().map(|(id, (spend, last))| {
            let found = info.get(id.as_str());
            SessionSpend {
                title: found.and_then(|s| s.title.clone()),
                project: found
                    .and_then(|s| names.get(&s.project))
                    .map_or_else(String::new, |(name, _)| name.clone()),
                last_ms: last * 1000,
                id,
                spend,
            }
        }),
        |session| &session.spend,
    );
    HistoryReport {
        v: HISTORY_VERSION,
        range,
        bucket: range.bucket(),
        generated_at_ms: now_ms,
        since_ms: spans.since() * 1000,
        until_ms: spans.until * 1000,
        calibration: Calibration {
            calibrated: rates.fallback.is_some(),
            pairs: rates.pairs,
            needed: PAIRS_NEEDED,
        },
        totals: Totals {
            spend: totals,
            sessions: session_count,
            hit_ratio: (prompt > 0).then(|| read as f64 / prompt as f64),
            saved_usd,
            rebuilds,
            rebuild_usd,
            idle_rebuilds,
            compactions,
            peak_5h_pct,
        },
        buckets,
        models: order.into_iter().take(TOP).collect(),
        projects,
        sessions,
    }
}

fn empty_bucket(span: &Span, rates: &Rates) -> Bucket {
    Bucket {
        start_ms: span.start * 1000,
        label: span.label.clone(),
        spend: rates.empty(),
        models: Vec::new(),
        prompt_tokens: 0,
        cache_read_tokens: 0,
        rebuilds: 0,
        rebuild_usd: 0.0,
        compactions: 0,
        peak_5h_pct: None,
    }
}

fn all_tokens(tokens: &TokenCounts) -> u64 {
    tokens.prompt_total() + tokens.output
}

fn by_spend(a: &Spend, b: &Spend) -> std::cmp::Ordering {
    b.cost_usd
        .total_cmp(&a.cost_usd)
        .then_with(|| b.tokens.cmp(&a.tokens))
}

fn ranked(models: BTreeMap<String, Spend>) -> Vec<ModelSpend> {
    let mut ranked: Vec<ModelSpend> = models
        .into_iter()
        .map(|(model, spend)| ModelSpend { model, spend })
        .collect();
    ranked.sort_by(|a, b| by_spend(&a.spend, &b.spend).then_with(|| a.model.cmp(&b.model)));
    ranked
}

fn top<T>(items: impl Iterator<Item = T>, spend: impl Fn(&T) -> &Spend) -> Vec<T> {
    let mut items: Vec<T> = items.collect();
    items.sort_by(|a, b| by_spend(spend(a), spend(b)));
    items.truncate(TOP);
    items
}

fn project_names(sessions: &[SessionInfo]) -> HashMap<String, (String, Option<String>)> {
    let mut paths: BTreeMap<&str, &str> = BTreeMap::new();
    for session in sessions {
        if let Some(cwd) = session.cwd.as_deref() {
            paths.entry(&session.project).or_insert(cwd);
        }
    }
    let tail = |path: &str, parts: usize| -> String {
        let mut pieces: Vec<&str> = path.trim_end_matches('/').rsplit('/').take(parts).collect();
        pieces.reverse();
        pieces.join("/")
    };
    paths
        .iter()
        .map(|(project, path)| {
            let short = tail(path, 1);
            let shared = paths
                .iter()
                .any(|(other, p)| other != project && tail(p, 1) == short);
            let name = if shared { tail(path, 2) } else { short };
            (project.to_string(), (name, Some(path.to_string())))
        })
        .collect()
}

pub fn range_of(query: Option<&str>) -> Result<Range, &'static str> {

        Ok(Err(error)) => failure(StatusCode::INTERNAL_SERVER_ERROR, format!("{error:#}")),

use std::collections::{BTreeMap, HashMap};

use anyhow::Result;
use chrono::{DateTime, TimeZone};
use serde::{Deserialize, Serialize};

use super::project_names;
use crate::store::{SessionInfo, SpentAdjustment, SpentRequest};
use crate::transcript::TokenCounts;

pub const EXPORT_VERSION: u32 = 1;
pub const CSV_HEADER: &str = "day,project,model,requests,unpriced,input,output,cache_read,cache_write_5m,cache_write_1h,cost_usd,reconciled_usd";

#[derive(Debug, Clone, Default, PartialEq, Serialize, Deserialize)]
pub struct ExportRow {
    pub day: String,
    pub project: String,
    pub model: String,
    pub requests: u64,
    pub unpriced: u64,
    pub input: u64,
    pub output: u64,
    pub cache_read: u64,
    pub cache_write_5m: u64,
    pub cache_write_1h: u64,
    pub cost_usd: f64,
    pub reconciled_usd: f64,
}

#[derive(Serialize)]
struct Export<'a> {
    v: u32,
    rows: &'a [ExportRow],
}

pub fn rows<Tz: TimeZone>(
    requests: &[SpentRequest],
    adjustments: &[SpentAdjustment],
    sessions: &[SessionInfo],
    tz: &Tz,
) -> Vec<ExportRow> {
    let names = project_names(sessions);
    let projects: HashMap<&str, String> = sessions
        .iter()
        .map(|session| {
            let name = names
                .get(&session.project)
                .map_or_else(|| session.project.clone(), |(name, _)| name.clone());
            (session.id.as_str(), name)
        })
        .collect();
    let mut grouped = Grouped::new();
    let key = |session: &str, ts: i64, model: &str| -> Option<Key> {
        let day = DateTime::from_timestamp(ts, 0)?
            .with_timezone(tz)
            .date_naive()
            .to_string();
        let project = projects.get(session).cloned().unwrap_or_default();
        Some((day, project, model.to_string()))
    };
    for request in requests {
        let Some(key) = key(&request.session_id, request.point.ts, &request.point.model) else {
            continue;
        };
        let row = row_of(&mut grouped, key);
        row.requests += 1;
        add_tokens(row, &request.point.tokens);
        match request.cost_usd {
            Some(usd) => row.cost_usd += usd,
            None => row.unpriced += 1,
        }
    }
    for adjustment in adjustments {
        let Some(key) = key(&adjustment.session_id, adjustment.ts, &adjustment.model) else {
            continue;
        };
        let row = row_of(&mut grouped, key);
        add_tokens(row, &adjustment.tokens);
        let usd = adjustment.cost_usd.unwrap_or(0.0);
        row.cost_usd += usd;
        row.reconciled_usd += usd;
    }
    grouped.into_values().collect()
}

type Key = (String, String, String);
type Grouped = BTreeMap<Key, ExportRow>;

fn row_of(grouped: &mut Grouped, key: Key) -> &mut ExportRow {
    grouped
        .entry(key)
        .or_insert_with_key(|(day, project, model)| ExportRow {
            day: day.clone(),
            project: project.clone(),
            model: model.clone(),
            ..Default::default()
        })
}

fn add_tokens(row: &mut ExportRow, tokens: &TokenCounts) {
    row.input += tokens.input;
    row.output += tokens.output;
    row.cache_read += tokens.cache_read;
    row.cache_write_5m += tokens.cache_write_5m;
    row.cache_write_1h += tokens.cache_write_1h;
}

pub fn json(rows: &[ExportRow]) -> Result<String> {
    Ok(serde_json::to_string(&Export {
        v: EXPORT_VERSION,
        rows,
    })?)
}

pub fn csv(rows: &[ExportRow]) -> String {
    let mut out = format!("{CSV_HEADER}\n");
    for row in rows {
        let fields = [
            row.day.clone(),
            field(&row.project),
            field(&row.model),
            row.requests.to_string(),
            row.unpriced.to_string(),
            row.input.to_string(),
            row.output.to_string(),
            row.cache_read.to_string(),
            row.cache_write_5m.to_string(),
            row.cache_write_1h.to_string(),
            format!("{:.6}", row.cost_usd),
            format!("{:.6}", row.reconciled_usd),
        ];
        out.push_str(&fields.join(","));
        out.push('\n');
    }
    out
}

fn field(text: &str) -> String {
    if text.contains([',', '"', '\n', '\r']) {
        format!("\"{}\"", text.replace('"', "\"\""))
    } else {
        text.to_string()
    }
}

pub fn run(paths: &Paths, prices: &PriceTable, format: Format, days: Option<u32>) -> Result<()> {
    let (since, until) = window(days)?;
    if super::transcripts_missing(paths) {
        return Ok(());
    }
    let (store, report, reconciled) = super::import::incremental(paths, prices)?;
    for line in super::import::issue_lines(&report) {

    reconciled?;

        &store.adjustments_between(since, until)?,
        &store.sessions_spending_between(since, until)?,

        Format::Json => format!("{}\n", export::json(&rows)?),
        Format::Csv => export::csv(&rows),
    };
    std::io::stdout().lock().write_all(text.as_bytes())?;
    Ok(())

        .checked_sub_days(Days::new(u64::from(days - 1)))

    Ok((local_midnight(first_day, &Local)?, until))

import type { ThemeKey } from 'claude-code'

import type { Palette } from './palette'
import { colorOf } from './palette'

export const LOWER = [' ', '▁', '▂', '▃', '▄', '▅', '▆', '▇', '█']
export const BRAILLE_BASE = 0x2800
export const MARKER = '┊'
const LEFT_DOTS = [0x40, 0x04, 0x02, 0x01]
const RIGHT_DOTS = [0x80, 0x20, 0x10, 0x08]
const BASE64 = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'

export type Cell = { glyph: string; fg: ThemeKey | null; bg: ThemeKey | null }

export type Grid = { columns: number; rows: number; cells: Cell[][] }

export type Layout = { per: number; bars: number; cell: number; gap: number; dropped: number; offset: number }

export type Piece = { value: number; color: ThemeKey }

export type ColoredRun = { text: string; fg: ThemeKey | null; bg: ThemeKey | null }

const EMPTY: Cell = { glyph: ' ', fg: null, bg: null }

export function blank(columns: number, rows: number): Grid {
  return { columns, rows, cells: Array.from({ length: rows }, () => Array.from({ length: columns }, () => EMPTY)) }
}

export function layout(buckets: number, width: number): Layout {
  const count = Math.max(1, buckets)
  const per = Math.max(1, Math.ceil(count / width))
  const bars = Math.max(1, Math.floor(count / per))
  const cell = Math.max(1, Math.floor(width / bars))
  return { per, bars, cell, gap: cell >= 3 ? 1 : 0, dropped: count - bars * per, offset: width - bars * cell }
}

export function grouped<T>(items: readonly T[], shape: Layout): T[][] {
  const kept = items.slice(shape.dropped)
  return Array.from({ length: shape.bars }, (_, index) => kept.slice(index * shape.per, (index + 1) * shape.per))
}

function put(grid: Grid, row: number, column: number, cell: Cell): void {
  const line = grid.cells[row]
  if (line !== undefined && column >= 0 && column < grid.columns) line[column] = cell
}

function heaviest(pieces: readonly { color: ThemeKey; eighths: number }[]): ThemeKey | null {
  let best: { color: ThemeKey; eighths: number } | null = null
  for (const piece of pieces) if (piece.eighths > 0 && (best === null || piece.eighths > best.eighths)) best = piece
  return best?.color ?? null
}

export function columnCells(pieces: readonly Piece[], max: number, rows: number): Cell[] {
  const total = pieces.reduce((sum, piece) => sum + Math.max(0, piece.value), 0)
  const height = total <= 0 || max <= 0 ? 0 : Math.max(1, Math.min(rows * 8, Math.round((total / max) * rows * 8)))
  const bounds: { color: ThemeKey; from: number; to: number }[] = []
  let sum = 0
  for (const piece of pieces) {
    const from = Math.round((sum / total) * height)
    sum += Math.max(0, piece.value)
    const to = Math.round((sum / total) * height)
    if (to > from) bounds.push({ color: piece.color, from, to })
  }
  return Array.from({ length: rows }, (_, row) => {
    const bottom = row * 8
    const filled = Math.min(8, Math.max(0, height - bottom))
    if (filled === 0) return EMPTY
    const inside = bounds.map(bound => ({
      color: bound.color,
      eighths: Math.max(0, Math.min(bound.to, bottom + filled) - Math.max(bound.from, bottom)),
    }))
    if (filled < 8) return { glyph: LOWER[filled] ?? ' ', fg: heaviest(inside), bg: null }
    const [first, ...rest] = inside.filter(piece => piece.eighths > 0)
    if (first === undefined) return EMPTY
    if (rest.length === 0) return { glyph: LOWER[8] ?? '█', fg: first.color, bg: null }
    return { glyph: LOWER[first.eighths] ?? '█', fg: first.color, bg: heaviest(rest) }
  })
}

export function bars(stacks: readonly (readonly Piece[])[], shape: Layout, rows: number, max: number): Grid {
  const grid = blank(shape.offset + shape.bars * shape.cell, rows)
  stacks.forEach((pieces, index) => {
    const cells = columnCells(pieces, max, rows)
    const left = shape.offset + shape.gap + index * shape.cell
    const width = shape.cell - shape.gap
    cells.forEach((cell, fromBottom) => {
      for (let column = 0; column < width; column += 1) put(grid, rows - 1 - fromBottom, left + column, cell)
    })
  })
  return grid
}

export function sampled(values: readonly number[], points: number): number[] {
  if (values.length === 0) return Array.from({ length: points }, () => 0)
  return Array.from({ length: points }, (_, index) => values[Math.min(values.length - 1, Math.floor((index * values.length) / points))] ?? 0)
}

export function area(values: readonly number[], columns: number, rows: number, max: number, color: ThemeKey): Grid {
  const grid = blank(columns, rows)
  const dots = sampled(values, columns * 2).map(value => (max <= 0 ? 0 : Math.min(rows * 4, Math.round((value / max) * rows * 4))))
  for (let column = 0; column < columns; column += 1) {
    const left = dots[column * 2] ?? 0
    const right = dots[column * 2 + 1] ?? 0
    for (let row = 0; row < rows; row += 1) {
      const bottom = (rows - 1 - row) * 4
      let bits = 0
      for (let dot = 0; dot < 4; dot += 1) {
        if (left > bottom + dot) bits |= LEFT_DOTS[dot] ?? 0
        if (right > bottom + dot) bits |= RIGHT_DOTS[dot] ?? 0
      }
      if (bits !== 0) put(grid, row, column, { glyph: String.fromCharCode(BRAILLE_BASE + bits), fg: color, bg: null })
    }
  }
  return grid
}

export function markers(columns: number, at: readonly number[], color: ThemeKey): Grid {
  const grid = blank(columns, 1)
  for (const column of at) put(grid, 0, column, { glyph: MARKER, fg: color, bg: null })
  return grid
}

export function stacked(top: Grid, bottom: Grid): Grid {
  return { columns: Math.max(top.columns, bottom.columns), rows: top.rows + bottom.rows, cells: [...top.cells, ...bottom.cells] }
}

export function padded(grid: Grid, columns: number): Grid {
  if (grid.columns >= columns) return grid
  return { columns, rows: grid.rows, cells: grid.cells.map(row => [...row, ...Array.from({ length: columns - grid.columns }, () => EMPTY)]) }
}

export function runs(grid: Grid): ColoredRun[][] {
  return grid.cells.map(row => {
    const merged: ColoredRun[] = []
    for (const cell of row) {
      const last = merged[merged.length - 1]
      if (last !== undefined && last.fg === cell.fg && last.bg === cell.bg) last.text += cell.glyph
      else merged.push({ text: cell.glyph, fg: cell.fg, bg: cell.bg })
    }
    return merged
  })
}

export function glyphRows(grid: Grid): string[] {
  return grid.cells.map(row => row.map(cell => cell.glyph).join(''))
}

export function encode(grid: Grid, palette: Palette): string {
  const bytes = new Uint8Array(grid.columns * grid.rows * 12)
  const view = new DataView(bytes.buffer)
  let at = 0
  for (const row of grid.cells) {
    for (const cell of row) {
      view.setUint32(at, cell.glyph.charCodeAt(0), true)
      view.setUint32(at + 4, colorOf(palette, cell.fg), true)
      view.setUint32(at + 8, colorOf(palette, cell.bg), true)
      at += 12
    }
  }
  return base64(bytes)
}

export function base64(bytes: Uint8Array): string {
  let out = ''
  for (let index = 0; index < bytes.length; index += 3) {
    const a = bytes[index] ?? 0
    const b = bytes[index + 1] ?? 0
    const c = bytes[index + 2] ?? 0
    const triple = (a << 16) | (b << 8) | c
    out += BASE64[(triple >> 18) & 63] ?? ''
    out += BASE64[(triple >> 12) & 63] ?? ''
    out += index + 1 < bytes.length ? (BASE64[(triple >> 6) & 63] ?? '') : '='
    out += index + 2 < bytes.length ? (BASE64[triple & 63] ?? '') : '='
  }
  return out
}

import type { ThemeKey } from 'claude-code'

import type { Bucket, ContextReport, Daemon, HistoryRange, HistoryReport, Local, Metric, Reports, Spend } from '../types'
import type { Layout, Piece } from './chart'
import { area, bars, grouped, layout, markers, MARKER, stacked } from './chart'
import { compositionOf, reportOf } from './context'
import { FULL_BLOCK, money, modelName, percent, spread, tokens } from './format'
import type { Line } from './state'
import { LIMIT_WARNING, MIN_CONTENT, PADDING, WHY_COLUMNS, fitting, gap, notice, pair, plain, prose } from './state'

export const RANGES: readonly HistoryRange[] = ['24h', '7d', '30d', '90d']
export const METRICS: readonly Metric[] = ['cost', 'tokens', 'pct']
export const SPEND_ROWS = 6
export const HIT_ROWS = 2
export const PEAK_ROWS = 3
export const GROWTH_ROWS = 3
export const TOP_SHOWN = 5
export const HIT_FLOOR_CAP = 0.9
export const MODEL_COLORS: readonly ThemeKey[] = ['claude', 'permission', 'planMode', 'autoAccept', 'bashBorder']
export const OTHER_COLOR: ThemeKey = 'inactive'
export const INDENT = '  '

const RANGE_LABELS: Readonly<Record<HistoryRange, string>> = { '24h': '24 hours', '7d': '7 days', '30d': '30 days', '90d': '90 days' }
const METRIC_LABELS: Readonly<Record<Metric, string>> = { cost: 'Cost', tokens: 'Tokens', pct: '% of 5h' }

export type HistoryInput = {
  width: number
  range: HistoryRange
  metric: Metric
  reports: Reports
  context: ContextReport | null
  local: Local
  daemon: Daemon
  expanded: readonly string[]
}

export function rangeLabel(range: HistoryRange): string {
  return RANGE_LABELS[range]
}

export function metricLabel(metric: Metric): string {
  return METRIC_LABELS[metric]
}

export function nextRange(range: HistoryRange): HistoryRange {
  return RANGES[(RANGES.indexOf(range) + 1) % RANGES.length] ?? '7d'
}

export function metricsOf(report: HistoryReport | null): Metric[] {
  return report?.calibration.calibrated === true ? [...METRICS] : METRICS.filter(metric => metric !== 'pct')
}

export function shownMetric(metric: Metric, report: HistoryReport | null): Metric {
  return metricsOf(report).includes(metric) ? metric : 'cost'
}

export function nextMetric(metric: Metric, report: HistoryReport | null): Metric {
  const allowed = metricsOf(report)
  return allowed[(allowed.indexOf(shownMetric(metric, report)) + 1) % allowed.length] ?? 'cost'
}

export function valueOf(spend: Spend, metric: Metric): number {
  if (metric === 'tokens') return spend.tokens
  if (metric === 'pct') return spend.pct_5h ?? 0
  return spend.cost_usd
}

export function amount(value: number, metric: Metric): string {
  if (metric === 'tokens') return tokens(value)
  if (metric === 'pct') return `~${percent(value)}`
  return money(value)
}

export function historyScreen(input: HistoryInput): Line[] {
  const width = Math.max(MIN_CONTENT, input.width - 2 * PADDING)
  const report = input.reports[input.range] ?? null
  const metric = shownMetric(input.metric, report)
  const busy = report !== null && (report.totals.requests > 0 || report.totals.reconciled_usd > 0)
  const sections = [
    notice(input, width),
    headline(input, report, metric, width),
    ...(report !== null && busy
      ? [spendChart(report, metric, width), cacheChart(input, report, width), peakChart(report, width), top('projects', report, metric, width), top('sessions', report, metric, width)]
      : []),
    growth(input, width),
  ].filter(section => section.length > 0)
  return sections.flatMap((section, index) => (index === 0 ? section : [gap(index), ...section]))
}

function headline(input: HistoryInput, report: HistoryReport | null, metric: Metric, width: number): Line[] {
  const title = `Last ${rangeLabel(input.range)}`
  if (report === null) {
    if (input.daemon.status !== 'ok') return []
    return [plain('hist-head', title, { bold: true }), prose('hist-loading', `Loading the last ${rangeLabel(input.range)}… ✻`, { dim: true })]
  }
  const { totals } = report
  if (totals.requests === 0 && totals.reconciled_usd === 0) {
    return [plain('hist-head', title, { bold: true }), prose('hist-empty', `No requests in the last ${rangeLabel(input.range)} yet ✻`, { dim: true })]
  }
  const value = amount(valueOf(totals, metric), metric)
  const why = metric === 'pct' ? 'hist-pct' : undefined
  const head = pair('hist-head', title, value, why === undefined ? width : width - WHY_COLUMNS, { color: 'claude', bold: true }, { bold: true })
  const lines: Line[] = [why === undefined ? head : { ...head, why }]
  const sessions = `${totals.sessions} ${totals.sessions === 1 ? 'session' : 'sessions'}`
  const requests = `${totals.requests} ${totals.requests === 1 ? 'request' : 'requests'}`
  lines.push(plain('hist-sub', `${sessions} · ${requests}`, { dim: true }))
  if (totals.unpriced > 0) {
    const noun = totals.unpriced === 1 ? 'request on an unknown model is' : 'requests on unknown models are'
    lines.push(prose('hist-unpriced', fitting(width, `${totals.unpriced} ${noun} not priced`, `${totals.unpriced} unpriced`), { dim: true }))
  }
  if (why !== undefined && input.expanded.includes(why)) {
    const { pairs } = report.calibration
    lines.push(
      prose('explain-hist-pct', `Estimated from how far each dollar moved your 5h limit, learned from ${pairs} limit readings. 100% is one full 5h window.`, { dim: true }),
    )
  }
  return lines
}

function per(report: HistoryReport, shape: Layout): string {
  const unit = report.bucket === 'hour' ? 'hour' : 'day'
  return shape.per === 1 ? `by ${unit}` : `per ${shape.per} ${unit}s`
}

function axis(key: string, report: HistoryReport, shape: Layout, groups: Bucket[][], width: number): Line {
  const first = groups[0]?.[0]?.label ?? ''
  const last = report.bucket === 'hour' ? 'now' : 'today'
  return pair(key, `${' '.repeat(shape.offset + shape.gap)}${first}`, last, width, { dim: true }, { dim: true })
}

function spendChart(report: HistoryReport, metric: Metric, width: number): Line[] {
  const shape = layout(report.buckets.length, width)
  const groups = grouped(report.buckets, shape)
  const named = report.models.map(model => model.model)
  const stacks = groups.map(group => {
    const pieces: Piece[] = named.map((model, index) => ({
      value: group.reduce((sum, bucket) => sum + bucket.models.filter(spent => spent.model === model).reduce((s, spent) => s + valueOf(spent, metric), 0), 0),
      color: MODEL_COLORS[index] ?? OTHER_COLOR,
    }))
    const all = group.reduce((sum, bucket) => sum + valueOf(bucket, metric), 0)
    const other = all - pieces.reduce((sum, piece) => sum + piece.value, 0)
    return other > 1e-9 ? [...pieces, { value: other, color: OTHER_COLOR }] : pieces
  })
  const totals = stacks.map(pieces => pieces.reduce((sum, piece) => sum + piece.value, 0))
  const max = Math.max(0, ...totals)
  const lines: Line[] = [
    pair('hist-spend', `${metricLabel(metric)} ${per(report, shape)}`, `peak ${amount(max, metric)}`, width, { dim: true }, { bold: true }),
    { key: 'hist-spend-chart', segments: [], chart: bars(stacks, shape, SPEND_ROWS, max) },
    axis('hist-spend-axis', report, shape, groups, width),
  ]
  const shown = report.models.map((model, index) => ({ name: modelName(model.model), value: valueOf(model, metric), color: MODEL_COLORS[index] ?? OTHER_COLOR }))
  const rest = valueOf(report.totals, metric) - shown.reduce((sum, model) => sum + model.value, 0)
  if (rest > 1e-9) shown.push({ name: 'Other', value: rest, color: OTHER_COLOR })
  shown.forEach((model, index) => lines.push(swatch(`hist-model-${index}`, model.name, amount(model.value, metric), model.color, width)))
  return lines
}

function swatch(key: string, name: string, value: string, color: ThemeKey, width: number): Line {
  const text = spread(`${INDENT}${FULL_BLOCK} ${name}`, value, width)
  const start = INDENT.length + FULL_BLOCK.length
  return {
    key,
    segments: [
      { text: INDENT },
      { text: FULL_BLOCK, color },
      { text: text.slice(start, text.length - value.length), dim: true },
      { text: value },
    ],
  }
}

export function hitFloor(ratios: readonly number[]): number {
  if (ratios.length === 0) return 0
  return Math.min(HIT_FLOOR_CAP, Math.floor(Math.min(...ratios) * 10) / 10)
}

function cacheChart(input: HistoryInput, report: HistoryReport, width: number): Line[] {
  const { totals } = report
  if (totals.hit_ratio === null) return []
  const shape = layout(report.buckets.length, width)
  const groups = grouped(report.buckets, shape)
  const ratios = groups.map(group => {
    const prompt = group.reduce((sum, bucket) => sum + bucket.prompt_tokens, 0)
    return prompt > 0 ? group.reduce((sum, bucket) => sum + bucket.cache_read_tokens, 0) / prompt : null
  })
  const floor = hitFloor(ratios.filter((ratio): ratio is number => ratio !== null))
  const stacks = ratios.map((ratio): Piece[] => (ratio === null ? [] : [{ value: Math.max(0, ratio - floor), color: 'success' }]))
  const head = pair('hist-hit', 'Cache hit ratio', percent(totals.hit_ratio * 100), width - WHY_COLUMNS, {}, { bold: true })
  const lines: Line[] = [{ ...head, why: 'hist-hit' }]
  if (input.expanded.includes('hist-hit')) {
    const scale = floor > 0 ? ` The bars start at ${percent(floor * 100)}, so small changes show.` : ''
    lines.push(prose('explain-hist-hit', `The share of prompt tokens read from the cache instead of sent again.${scale}`, { dim: true }))
  }
  lines.push({ key: 'hist-hit-chart', segments: [], chart: bars(stacks, shape, HIT_ROWS, 1 - floor) })
  if (totals.saved_usd >= 0.01) lines.push(pair('hist-saved', `${INDENT}Saved by cache hits`, money(totals.saved_usd), width, { color: 'success' }, { dim: true }))
  if (totals.rebuilds > 0) {
    lines.push(pair('hist-rebuilds', `${INDENT}Rebuilds`, `${totals.rebuilds} · ~${money(totals.rebuild_usd)}`, width, {}, { dim: true }))
  }
  return lines
}

function peakChart(report: HistoryReport, width: number): Line[] {
  const peak = report.totals.peak_5h_pct
  if (peak === null) return []
  const shape = layout(report.buckets.length, width)
  const groups = grouped(report.buckets, shape)
  const stacks = groups.map((group): Piece[] => {
    const peaks = group.map(bucket => bucket.peak_5h_pct).filter((value): value is number => value !== null)
    if (peaks.length === 0) return []
    const highest = Math.max(...peaks)
    return [{ value: highest, color: highest >= LIMIT_WARNING ? 'warning' : 'permission' }]
  })
  return [
    pair('hist-peak', '5h limit, highest', percent(peak), width, peak >= LIMIT_WARNING ? { color: 'warning' } : {}, { bold: true }),
    { key: 'hist-peak-chart', segments: [], chart: bars(stacks, shape, PEAK_ROWS, 100) },
  ]
}

function top(kind: 'projects' | 'sessions', report: HistoryReport, metric: Metric, width: number): Line[] {
  const rows =
    kind === 'projects'
      ? report.projects.map(project => ({ name: `${project.name} · ${project.sessions} ${project.sessions === 1 ? 'session' : 'sessions'}`, spend: project }))
      : report.sessions.map(session => ({ name: `${session.title ?? `Untitled ${session.id.slice(0, 8)}`} · ${session.project}`, spend: session }))
  if (rows.length === 0) return []
  return [
    plain(`hist-${kind}`, kind === 'projects' ? 'Top projects' : 'Top sessions', { bold: true }),
    ...rows.slice(0, TOP_SHOWN).map((row, index) => pair(`hist-${kind}-${index}`, `${INDENT}${row.name}`, amount(valueOf(row.spend, metric), metric), width, {}, { dim: true })),
  ]
}

function growth(input: HistoryInput, width: number): Line[] {
  const report = reportOf({ report: input.context, local: input.local })
  const points = report?.history?.points ?? []
  if (points.length < 2) return []
  const values = points.map(point => point.prompt_tokens)
  const window = compositionOf({ report: input.context, local: input.local })?.max_tokens ?? input.local.measure?.contextWindow ?? Math.max(...values)
  const last = values[values.length - 1] ?? 0
  const compacted = points.flatMap((point, index) => (point.compacted ? [Math.min(width - 1, Math.floor((index * width) / points.length))] : []))
  const curve = area(values, width, GROWTH_ROWS, window, 'claude')
  const lines: Line[] = [
    pair('hist-growth', 'Context this session', `${tokens(last)} / ${tokens(window)}`, width, {}, { bold: true }),
    { key: 'hist-growth-chart', segments: [], chart: compacted.length > 0 ? stacked(markers(width, compacted, 'warning'), curve) : curve },
  ]
  if (compacted.length > 0) {
    const noun = compacted.length === 1 ? 'compaction' : 'compactions'
    lines.push({ key: 'hist-growth-note', segments: [{ text: INDENT }, { text: MARKER, color: 'warning' }, { text: ` ${compacted.length} ${noun}`, dim: true }] })
  }
  return lines
}
