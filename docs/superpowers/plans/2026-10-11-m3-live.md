# claude-plus Milestone 3 (Mod Skeleton and Live View) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Claude Code mod `plus` opens a `claude-plus` pane and a status entry, forwards every usage event to the daemon, and shows the Live view: model and effort, context, a counting-down cache with its heartbeat, next-turn estimates, session totals and plan limits with pace, all computed by the daemon.

**Architecture:** The daemon gains four pure units: a per-session `timeline` (transcript requests joined with live `turn.step` events), the `cache_model` (TTL, expiry, hit ratio, rebuilds), the `forecast` (warm, cold, alternative model) and `limits` (samples from `session.measure`, reset detection, a fitted percent per dollar, pace).
`GET /snapshot` adds them under a new `live` field and stays at v1 because fields are only added.
The mod in `mod/` keeps every `$` call and atom in `hooks/register.tsx` and puts formatting, the daemon client and the screen model in pure files, so the views are plain functions of state that `claude plugin test` checks line by line at 40, 60 and 100 columns.

**Tech Stack:** Rust (edition 2024, MSRV 1.88), no new crates; Claude Code 2.1.296 function hooks (TypeScript, JSX with `h`), `claude plugin validate` and `claude plugin test`, TypeScript 6.0.3 through `npx` for type-checking only.
Node v26.11.1 and npx are installed at `/opt/homebrew/bin`; there is no global `tsc`, and `npx --offline -p typescript@6.0.3 tsc` runs from the npx cache.

**Spec:** `docs/superpowers/specs/2026-10-10-claude-plus-design.md` (sections 3 "The pane" and "Look and feel", 5 "Cache state", "Next-turn forecast (estimate)" and "Subscription percent (learned estimate)", 7 "Error handling and safety", 8 "Testing", 9 milestone 3: "Mod skeleton and Live view: pane, status entry, `/plus`, forwarding, cache model, forecast, limits sampling").

Every line of Rust and TypeScript below was run on a clone of that commit before the plan was written: `cargo test` (232 lib, 32 cli and 18 daemon tests), clippy, `cargo +1.88 check`, `claude plugin validate mod`, `claude plugin test mod` (53 tests, five runs in a row) and `tsc` all passed.

## Decisions

The spec is silent on these points, so this plan decides them.

1. The plugin is named `plus`, because Claude Code reserves names that start with `claude-`.
   The pane id is `plus`, its title `claude-plus`, the command `/plus` and the state namespace `plus`.
2. The mod lives in `mod/` with one hooks module, `hooks/register.tsx`.
   Every atom and every function that receives `$` is declared at the top level of that file, because the validator follows `$` only into top-level functions of the same file and requires atoms to be declared where they are read and updated.
   Formatting (`format.ts`), the daemon client (`client.ts`) and the screen model (`state.ts`) are pure, and the views receive their elements from `$.ui.resolve(e)` as a `ui` object.
3. Type-checking uses a vendored copy of the engine's declarations (Claude Code 2.1.296, sha256 `05a420dd003dbf9f0b2d8ac54fc411b182c1b372f47f87faaa7b55f88b3451a6`) at `mod-dev/types/claude-code/index.d.ts`, with `mod-dev/tsconfig.json` outside the plugin so that nothing for development ships in the mod.
   The copy the engine writes into `mod/.claude-plugin/types/` when it loads the mod is gitignored.
4. The daemon is started with `<binaryPath> daemon --ensure` through `$.process.run` (10 s timeout) at `session.start` and on `/plus`, once per module load, and again on the next `/plus` after a failure.
   `binaryPath` is a userConfig option defaulting to `claude-plus`.
   Exit code 127 or an `ENOENT` error means the binary is missing; any other failure shows the first line of stderr.
5. Every daemon call goes through `$.http.fetch` with `socketPath` to `http://claude-plus`, raced against `$.clock.sleep(500)` with an `AbortController`, because `$.http.fetch` has no timeout option.
   The socket is `$CLAUDE_PLUS_HOME/daemon.sock`, else `$HOME/.claude-plus/daemon.sock`.
6. Forwarded events go to an in-memory outbox that keeps the newest 256, is flushed right away and retried on every tick until the daemon accepts it.
   Event data: `session.start` `{cwd, surface, interactive}`, `session.measure` `{model, context, rateLimits, cost_usd, changed}`, `turn.step` `{turnId, index, agentId, model, effort, stopReason, usage}` (only when usage is present), `turn.complete` `{turnId, agentId, reason, usage}`, `session.compact` `{trigger, agentId, skipped, tokensBefore, tokensAfter}`, `session.end` `{reason}` under the ending session's id.
7. The snapshot is polled every 3 s and on the first tick after a turn completes.
   The session id is read again on every poll and hook, because `/clear` starts a new session without `session.start`; a new id clears the local state, and a snapshot of another session is ignored.
8. One self-rescheduling `$.clock.after` timer drives everything: 1 s normally, 50 ms while a number eases, 500 ms in the cache's last minute (1 s always with animations off).
   Every hook starts it if it is not running, because `session.start` does not fire again after a hot reload.
9. The status entry reads `$4.18 · cache 52:14 · 5h 54%` (parts omitted when unknown, `cache cold` once expired) and `$.ui.status` is called only when the text changes.
10. The pane opens unasked at `session.start` only in interactive sessions, and not when the last `/plus` ran on a main-screen (not fullscreen) terminal, so that it never takes over the main screen inline without being asked.
    That last presentation is kept in `$.store` under `fullscreen`.
11. Live bars are `Text` runs of eighth blocks colored with theme keys; `Raster` waits for M5, because it takes raw RGB colors and would not follow the theme.
12. The snapshot adds one field, `live` `{model, effort, cache, forecast, limits}`, and stays at v1.
13. The timeline joins transcript requests with live `turn.step` events, which share no id, by fingerprint (thread, normalized model, input, cache read, cache write) within 5 minutes.
    An unmatched step joins only if it is newer than the thread's latest transcript request.
    Live steps count `cache_creation_input_tokens` as 5-minute writes, because the mod API does not split them; the TTL is only ever observed from transcript rows.
14. The TTL comes from the latest transcript cache write (`1h` when it wrote 1-hour tokens, `5m` otherwise, shown without `~`).
    Without one it is assumed (shown as `~1h` or `~5m`): 1 hour for the main thread when the session reports rate limits (a subscription), 5 minutes otherwise and always for subagents.
    Only main-thread requests move the countdown and count as rebuilds; hit ratio and savings count every thread.
15. A rebuild is a main-thread request whose previous prefix was at least 2,048 tokens, that read less than a tenth of it and wrote at least half of it, unless a compaction happened in between.
    Its cause is `idle` (gap at least the TTL), `model_switch`, `prefix_changed` (a skill listing, instructions, nested memory, MCP instructions, deferred tools or agent listing attachment in between) or `unknown`.
    Its extra cost is writing `min(write, prefix)` minus reading it; `saved_usd` is the cost with every cache read billed as input minus the real cost.
16. The forecast uses the main thread's last 10 requests: `P` is the latest cache read plus write, `N` the median of input plus cache write, `O` the median of output.
    Alternatives: Opus to Sonnet 5.5, Fable and Mythos to Opus 5.5, Sonnet to Haiku 5.5, Haiku to Sonnet 5.5.
    Its percent of the 5h window uses the fitted percent per dollar and is omitted until calibrated.
17. Limit samples live in a new `limit_samples` table (schema v9), one row per window and measure, skipped when nothing moved since the previous row of that window.
    A window instance ends at a drop of more than 0.5 points, a `resetsAt` that moved by more than 60 s, or a passed reset.
18. The fit pairs consecutive samples of one instance whose percent rose, with API-priced spend in between, over 14 days, ignoring the last 2 minutes (transcripts lag) and intervals where no family has 80% of the spend.
    It is a median of ratios with 10% trimmed at each end, per window and family, shown once 20 pairs exist, stored as JSON in `meta.limits_fit` and refreshed after an ingest at most once a minute.
19. The pace extrapolates the last 30 minutes (from the instance's first sample when younger, nothing under 5 minutes) to the reset, and names the time the window fills when that comes first.
20. Window kinds are shown as `5h` (`five_hour`), `7d` (`seven_day`) and `Spend` (`spend_limit`); other kinds are shown as sent.
    Only `five_hour` was seen in the mod API's examples, so the other two names are a guess the manual check verifies.
21. The missing-binary notice does not name a `brew` command, because the tap owner is not known until M7.
22. Alerts, the opt-in chime and the daily recap wait for M6, and `session.usage` forwarding for M4 (Context view).
23. `animations=false` (userConfig, default true) stops the heartbeat and the easing; the countdown still ticks every second.
24. The heartbeat cycles every 4 s through dim, normal, bold, normal in the `claude` color, alternates bold and dim every 500 ms in `warning` in the last minute, holds still while Claude works, and becomes a dim `·` when the cache is cold.
25. CI gains a `mod` job on Ubuntu that installs Claude Code 2.1.296 with the official install script, sets up Node 22, and runs validate, test and tsc.
    The install command was not run while writing this plan.
26. A `?` button sits at the right of each row that has a derivation (cache, rebuilds, next turn, plan limits) and toggles a dim paragraph under its section.

## Review Focus

1. A hot reload or a `/plus` in a session whose `session.start` ran under the old module must still start the ticker, the daemon and the status entry (Task 10 test `/plus after a hot reload starts the ticker without a session start`).
2. `/clear` keeps the process under a new session id with no `session.start`: the pane must drop the old session's numbers and poll the new one (Task 10 test `a new session after /clear drops the previous snapshot`, Task 9 test `ignores a snapshot that belongs to another session`).
3. A daemon that stops answering, or is down when events happen, must cost the hooks at most 500 ms, show a notice, and deliver the queued events once it is back (Task 8 test `a daemon error keeps its message and a silent daemon times out`, Task 10 tests `a silent daemon is reported once the 500 ms timeout passes` and `events queued while the daemon is down are delivered once it answers`).
4. A subagent's requests must not restart or extend the main conversation's cache countdown (Task 2 test `subagent_requests_do_not_move_the_main_countdown`, Task 1 test `threads_keep_subagents_apart_from_the_main_conversation`).
5. A 5h window that reset while the user was away must read 0% with no stale pace, and a reset must never be paired into the calibration (Task 5 tests `windows_report_the_latest_reading_with_its_calibration` and `mixed_spend_unsettled_pairs_and_resets_make_no_pairs`).

- `cache.state` is `warm`, `cold` or `none` (no main-thread request touched the cache yet); `ttl` is `5m` or `1h`; `ttl_source` is `observed` or `assumed`.
- `last_rebuild.cause` is `idle`, `model_switch`, `prefix_changed` or `unknown`; dollar fields are `null` when the model is not priced.
- `forecast` is `null` before the first main-thread request; `*_pct_5h` are `null` until the 5h window is calibrated; `alternative` is `null` for models without one.
- `limits` lists `five_hour`, `seven_day`, `spend_limit` first, then any other kind; `pace` is `null` without 5 minutes of history or after a reset; `calibration.pct_per_usd` is `null` below `needed` pairs.

```rust
use serde_json::Value;

use crate::pricing::normalize_model;
use crate::store::{RequestPoint, StoredEvent};
use crate::transcript::TokenCounts;

pub const STEP_KIND: &str = "turn.step";
pub const MATCH_WINDOW_MS: i64 = 300_000;

#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Thread {
    Main,
    Agent(String),
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Source {
    Transcript,
    Live,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Observed {
    pub ts_ms: i64,
    pub model: String,
    pub thread: Thread,
    pub tokens: TokenCounts,
    pub effort: Option<String>,
    pub source: Source,
}

impl Observed {
    pub fn touches_cache(&self) -> bool {
        self.tokens.cache_read > 0 || self.tokens.cache_write() > 0
    }

    pub fn prefix(&self) -> u64 {
        self.tokens.cache_read + self.tokens.cache_write()
    }

    fn fingerprint(&self) -> (Thread, &str, u64, u64, u64) {
        (
            self.thread.clone(),
            normalize_model(&self.model),
            self.tokens.input,
            self.tokens.cache_read,
            self.tokens.cache_write(),
        )
    }
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct Timeline {
    pub requests: Vec<Observed>,
}

impl Timeline {
    pub fn build(requests: &[RequestPoint], steps: &[StoredEvent]) -> Self {
        let mut observed: Vec<Observed> = requests.iter().map(from_transcript).collect();
        let mut matched = vec![false; observed.len()];
        let mut live = Vec::new();
        for step in steps.iter().filter_map(from_step) {
            let twin = observed.iter().enumerate().position(|(index, request)| {
                !matched[index]
                    && request.fingerprint() == step.fingerprint()
                    && (request.ts_ms - step.ts_ms).abs() <= MATCH_WINDOW_MS
            });
            match twin {
                Some(index) => matched[index] = true,
                None => live.push(step),
            }
        }
        live.retain(|step| {
            observed
                .iter()
                .filter(|request| request.thread == step.thread)
                .all(|request| request.ts_ms <= step.ts_ms)
        });
        observed.extend(live);
        observed.sort_by_key(|request| request.ts_ms);
        Self { requests: observed }
    }

    pub fn main(&self) -> Vec<&Observed> {
        self.requests
            .iter()
            .filter(|request| request.thread == Thread::Main)
            .collect()
    }

    pub fn latest_main(&self) -> Option<&Observed> {
        self.requests
            .iter()
            .rev()
            .find(|request| request.thread == Thread::Main)
    }

    pub fn steps_from_ms(requests: &[RequestPoint]) -> i64 {
        requests
            .last()
            .map_or(0, |latest| latest.ts * 1000 - MATCH_WINDOW_MS)
    }
}

fn from_transcript(point: &RequestPoint) -> Observed {
    Observed {
        ts_ms: point.ts * 1000,
        model: point.model.clone(),
        thread: match (&point.agent_id, point.is_sidechain) {
            (Some(agent), _) => Thread::Agent(agent.clone()),
            (None, true) => Thread::Agent(String::new()),
            (None, false) => Thread::Main,
        },
        tokens: point.tokens,
        effort: point.effort.clone(),
        source: Source::Transcript,
    }
}

fn from_step(event: &StoredEvent) -> Option<Observed> {
    let data: Value = serde_json::from_str(&event.json).ok()?;
    let usage = data.get("usage")?;
    let count = |field: &str| usage.get(field).and_then(Value::as_u64).unwrap_or(0);
    let tokens = TokenCounts {
        input: count("input_tokens"),
        output: count("output_tokens"),
        cache_read: count("cache_read_input_tokens"),
        cache_write_5m: count("cache_creation_input_tokens"),
        ..Default::default()
    };
    if tokens.is_empty() {
        return None;
    }
    let model = usage
        .get("model")
        .or_else(|| data.get("model"))
        .and_then(Value::as_str)?
        .to_string();
    Some(Observed {
        ts_ms: event.ts_ms,
        model,
        thread: match data.get("agentId").and_then(Value::as_str) {
            Some(agent) => Thread::Agent(agent.to_string()),
            None => Thread::Main,
        },
        tokens,
        effort: data.get("effort").and_then(|effort| match effort {
            Value::String(text) => Some(text.clone()),
            Value::Number(number) => Some(number.to_string()),
            _ => None,
        }),
        source: Source::Live,
    })
}
```

```rust
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Cache {
    pub state: CacheState,
    pub ttl: Ttl,
    pub ttl_source: TtlSource,
    pub last_touch_ms: Option<i64>,
    pub expires_at_ms: Option<i64>,
    pub hit_ratio: Option<f64>,
    pub saved_usd: f64,
    pub rebuilds: u64,
    pub rebuild_usd: f64,
    pub last_rebuild: Option<Rebuild>,
}

pub struct Context<'a> {
    pub prices: &'a PriceTable,
    pub prefix_changes: &'a [i64],
    pub compactions: &'a [i64],
    pub subscription: bool,
    pub now_ms: i64,
}

pub fn ttl_of(thread: &Thread, requests: &[&Observed], subscription: bool) -> (Ttl, TtlSource) {
    let observed = requests
        .iter()
        .rev()
        .find(|request| request.source == Source::Transcript && request.tokens.cache_write() > 0);
    match observed {
        Some(request) if request.tokens.cache_write_1h > 0 => (Ttl::OneHour, TtlSource::Observed),
        Some(_) => (Ttl::FiveMinutes, TtlSource::Observed),
        None if *thread == Thread::Main && subscription => (Ttl::OneHour, TtlSource::Assumed),
        None => (Ttl::FiveMinutes, TtlSource::Assumed),
    }
}

pub fn model(timeline: &Timeline, context: &Context) -> Cache {
    let main = timeline.main();
    let (ttl, ttl_source) = ttl_of(&Thread::Main, &main, context.subscription);
    let last_touch_ms = main
        .iter()
        .rev()
        .find(|request| request.touches_cache())
        .map(|request| request.ts_ms);
    let expires_at_ms = last_touch_ms.map(|touched| touched + ttl.millis());
    let state = match expires_at_ms {
        None => CacheState::None,
        Some(expires) if context.now_ms < expires => CacheState::Warm,
        Some(_) => CacheState::Cold,
    };
    let rebuilds: Vec<Rebuild> = main
        .windows(2)
        .filter_map(|pair| rebuild(pair[0], pair[1], ttl, context))
        .collect();
    Cache {
        state,
        ttl,
        ttl_source,
        last_touch_ms,
        expires_at_ms,
        hit_ratio: hit_ratio(&timeline.requests),
        saved_usd: timeline
            .requests
            .iter()
            .filter_map(|request| saved(request, context.prices))
            .sum(),
        rebuilds: rebuilds.len() as u64,
        rebuild_usd: rebuilds.iter().filter_map(|r| r.extra_usd).sum(),
        last_rebuild: rebuilds.last().cloned(),
    }
}

fn hit_ratio(requests: &[Observed]) -> Option<f64> {
    let (read, total) = requests
        .iter()
        .fold((0u64, 0u64), |(read, total), request| {
            (
                read + request.tokens.cache_read,
                total + request.tokens.prompt_total(),
            )
        });
    (total > 0).then(|| read as f64 / total as f64)
}

fn saved(request: &Observed, prices: &PriceTable) -> Option<f64> {
    let uncached = TokenCounts {
        input: request.tokens.input + request.tokens.cache_read,
        cache_read: 0,
        ..request.tokens
    };
    Some(prices.cost(&request.model, &uncached)? - prices.cost(&request.model, &request.tokens)?)
}

fn rebuild(
    previous: &Observed,
    request: &Observed,
    ttl: Ttl,
    context: &Context,
) -> Option<Rebuild> {
    let prefix = previous.prefix();
    let is_rebuild = prefix >= MIN_REBUILD_PREFIX
        && request.tokens.cache_read * 10 < prefix
        && request.tokens.cache_write() * 2 >= prefix;
    let between = |times: &[i64]| {
        times.iter().any(|ts| {
            let at = ts * 1000;
            previous.ts_ms < at && at <= request.ts_ms
        })
    };
    if !is_rebuild || between(context.compactions) {
        return None;
    }
    let cause = if request.ts_ms - previous.ts_ms >= ttl.millis() {
        RebuildCause::Idle
    } else if normalize_model(&previous.model) != normalize_model(&request.model) {
        RebuildCause::ModelSwitch
    } else if between(context.prefix_changes) {
        RebuildCause::PrefixChanged
    } else {
        RebuildCause::Unknown
    };
    let tokens = request.tokens.cache_write().min(prefix);
    let read = TokenCounts {
        cache_read: tokens,
        ..Default::default()
    };
    let extra_usd = context
        .prices
        .cost(&request.model, &ttl.written(tokens))
        .zip(context.prices.cost(&request.model, &read))
        .map(|(written, read)| written - read);
    Some(Rebuild {
        ts_ms: request.ts_ms,
        cause,
        tokens,
        extra_usd,
    })
}
```

```rust
    ("fable", "claude-opus-5-5"),
    ("mythos", "claude-opus-5-5"),
    ("sonnet", "claude-haiku-5-5"),

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Forecast {

    pub new_tokens: u64,

pub struct Alternative {
    pub model: String,
    pub first_usd: f64,
    pub next_usd: f64,
}

pub fn family(model: &str) -> &'static str {
    let model = normalize_model(model);
    FAMILIES
        .iter()
        .find(|family| model.split('-').any(|part| part == **family))
        .copied()
        .unwrap_or("other")
}

pub fn alternative_for(model: &str) -> Option<&'static str> {
    let family = family(model);
    ALTERNATIVES
        .iter()
        .find(|(from, _)| *from == family)
        .map(|(_, to)| *to)
}

pub fn next_turn(
    main: &[&Observed],
    prices: &PriceTable,
    ttl: Ttl,
    pct_per_usd_5h: Option<f64>,
) -> Option<Forecast> {
    let latest = main.last()?;
    let recent = &main[main.len().saturating_sub(RECENT)..];
    let prefix_tokens = latest.prefix();
    let new_tokens = median(
        recent
            .iter()
            .map(|r| r.tokens.input + r.tokens.cache_write()),
    );
    let output_tokens = median(recent.iter().map(|r| r.tokens.output));
    let warm = TokenCounts {
        cache_read: prefix_tokens,
        output: output_tokens,
        ..ttl.written(new_tokens)
    };
    let cold = TokenCounts {
        output: output_tokens,
        ..ttl.written(prefix_tokens + new_tokens)
    };
    let warm_usd = prices.cost(&latest.model, &warm);
    let cold_usd = prices.cost(&latest.model, &cold);
    let percent = |usd: Option<f64>| usd.zip(pct_per_usd_5h).map(|(usd, rate)| usd * rate);
    let alternative = alternative_for(&latest.model).and_then(|model| {
        Some(Alternative {
            model: model.to_string(),
            first_usd: prices.cost(model, &cold)?,
            next_usd: prices.cost(model, &warm)?,
        })
    });
    Some(Forecast {
        model: latest.model.clone(),
        samples: recent.len() as u32,
        prefix_tokens,
        new_tokens,
        output_tokens,
        warm_usd,
        cold_usd,
        warm_pct_5h: percent(warm_usd),
        cold_pct_5h: percent(cold_usd),
        alternative,
    })
}

fn median(values: impl Iterator<Item = u64>) -> u64 {
    let mut values: Vec<u64> = values.collect();
    values.sort_unstable();
    match values.len() {
        0 => 0,
        n if n % 2 == 1 => values[n / 2],
        n => (values[n / 2 - 1] + values[n / 2]) / 2,
    }
}
```

```rust
    pub fn repeats(&self, other: &LimitSample) -> bool {
        self.window == other.window
            && self.used_pct == other.used_pct
            && match (self.resets_at_ms, other.resets_at_ms) {
                (Some(a), Some(b)) => (a - b).abs() <= RESETS_AT_TOLERANCE_MS,
                (None, None) => true,
                _ => false,
            }
    }
}

impl Writer<'_> {
    pub fn limit_sample(&mut self, sample: &LimitSample) -> Result<bool> {
        let previous = self
            .tx
            .prepare_cached(
                "SELECT ts_ms, session_id, model, window, used_pct, resets_at_ms FROM limit_samples
                 WHERE window = ?1 AND ts_ms <= ?2 ORDER BY ts_ms DESC, id DESC LIMIT 1",
            )?
            .query_row(params![sample.window, sample.ts_ms], read_sample)
            .optional()?;
        if previous.is_some_and(|previous| previous.repeats(sample)) {
            return Ok(false);
        }
        self.tx
            .prepare_cached(
                "INSERT INTO limit_samples (ts_ms, session_id, model, window, used_pct, resets_at_ms)
                 VALUES (?1, ?2, ?3, ?4, ?5, ?6)",
            )?
            .execute(params![
                sample.ts_ms,
                sample.session_id,
                sample.model,
                sample.window,
                sample.used_pct,
                sample.resets_at_ms
            ])?;
        Ok(true)
    }

    pub fn set_meta(&mut self, key: &str, value: &str) -> Result<()> {
        self.tx
            .prepare_cached("INSERT OR REPLACE INTO meta (key, value) VALUES (?1, ?2)")?
            .execute([key, value])?;
        Ok(())
    }
}

impl Store {
    pub fn limit_samples_since(&self, since_ms: i64) -> Result<Vec<LimitSample>> {
        let mut statement = self.conn.prepare_cached(
            "SELECT ts_ms, session_id, model, window, used_pct, resets_at_ms FROM limit_samples
             WHERE ts_ms >= ?1 ORDER BY window, ts_ms, id",
        )?;
        let rows = statement.query_map([since_ms], read_sample)?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn spend_since(&self, since_ms: i64) -> Result<Vec<SpendPoint>> {
        let mut statement = self.conn.prepare_cached(
            "SELECT ts, model, cost_usd FROM requests
             WHERE ts * 1000 >= ?1 AND cost_usd IS NOT NULL ORDER BY ts",
        )?;
        let rows = statement.query_map([since_ms], |r| {
            Ok(SpendPoint {
                ts_ms: r.get::<_, i64>(0)? * 1000,
                model: r.get(1)?,
                cost_usd: r.get(2)?,
            })
        })?;
        Ok(rows.collect::<rusqlite::Result<_>>()?)
    }

    pub fn meta(&self, key: &str) -> Result<Option<String>> {
        Ok(self
            .conn
            .prepare_cached("SELECT value FROM meta WHERE key = ?1")?
            .query_row([key], |r| r.get(0))
            .optional()?)
    }
}

        model: r.get(2)?,
        window: r.get(3)?,
        used_pct: r.get(4)?,
        resets_at_ms: r.get(5)?,
    })
}
```

```rust
use std::collections::BTreeMap;

use anyhow::Result;
use chrono::DateTime;
use serde::{Deserialize, Serialize};
use serde_json::Value;

use crate::forecast::family;
use crate::store::{LimitSample, RESETS_AT_TOLERANCE_MS, SpendPoint, Store};

pub const FIT_KEY: &str = "limits_fit";
pub const FIT_DAYS: i64 = 14;
pub const SETTLE_MS: i64 = 120_000;

pub const DOMINANT_SHARE: f64 = 0.8;
pub const PACE_SPAN_MS: i64 = 30 * 60_000;
pub const MIN_PACE_SPAN_MS: i64 = 5 * 60_000;
pub const RESET_DROP_PCT: f64 = 0.5;
const DAY_MS: i64 = 86_400_000;
const HOUR_MS: f64 = 3_600_000.0;
const WINDOW_ORDER: &[&str] = &["five_hour", "seven_day", "spend_limit"];

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Fit {
    pub window: String,
    pub family: String,
    pub pairs: u32,
    pub pct_per_usd: f64,

}

pub struct Calibration {
    pub family: String,
    pub pairs: u32,
    pub needed: u32,
    pub pct_per_usd: Option<f64>,
}

    pub used_pct: f64,
    pub resets_at_ms: Option<i64>,
    pub sampled_at_ms: i64,
    pub reset_since_sample: bool,
    pub pace: Option<Pace>,
    pub calibration: Calibration,

pub fn samples_from_measure(session_id: &str, ts_ms: i64, data: &Value) -> Vec<LimitSample> {
    let model = data.get("model").and_then(Value::as_str).map(String::from);
    data.get("rateLimits")
        .and_then(Value::as_array)
        .into_iter()
        .flatten()
        .filter_map(|limit| {
            Some(LimitSample {
                ts_ms,
                session_id: session_id.to_string(),
                model: model.clone(),
                window: limit.get("kind")?.as_str()?.to_string(),
                used_pct: limit.get("percentUsed")?.as_f64()?,
                resets_at_ms: limit
                    .get("resetsAt")
                    .and_then(Value::as_str)
                    .and_then(|at| DateTime::parse_from_rfc3339(at).ok())
                    .map(|at| at.timestamp_millis()),
            })
        })
        .collect()
}

pub fn instances(samples: &[LimitSample]) -> Vec<&[LimitSample]> {
    let mut instances = Vec::new();
    let mut start = 0;
    for index in 1..samples.len() {
        let (previous, sample) = (&samples[index - 1], &samples[index]);
        let moved_reset = match (previous.resets_at_ms, sample.resets_at_ms) {
            (Some(a), Some(b)) => (a - b).abs() > RESETS_AT_TOLERANCE_MS,
            (a, b) => a.is_some() != b.is_some(),
        };
        let dropped = sample.used_pct + RESET_DROP_PCT < previous.used_pct;
        if sample.window != previous.window || moved_reset || dropped {
            instances.push(&samples[start..index]);
            start = index;
        }
    }
    if start < samples.len() {
        instances.push(&samples[start..]);
    }
    instances
}

pub fn fit(samples: &[LimitSample], spend: &[SpendPoint], settled_before_ms: i64) -> Vec<Fit> {
    let mut ratios: BTreeMap<(String, String), Vec<f64>> = BTreeMap::new();
    for instance in instances(samples) {
        for pair in instance.windows(2) {
            let (from, to) = (&pair[0], &pair[1]);
            let gained = to.used_pct - from.used_pct;
            if to.ts_ms > settled_before_ms || gained <= 0.0 {
                continue;
            }
            let Some((family, usd)) = dominant_spend(spend, from.ts_ms, to.ts_ms) else {
                continue;
            };
            ratios
                .entry((to.window.clone(), family.to_string()))
                .or_default()
                .push(gained / usd);
        }
    }
    ratios
        .into_iter()
        .map(|((window, family), ratios)| Fit {
            window,
            family,
            pairs: ratios.len() as u32,
            pct_per_usd: trimmed_median(ratios),
        })
        .collect()
}

fn dominant_spend(
    spend: &[SpendPoint],
    after_ms: i64,
    until_ms: i64,
) -> Option<(&'static str, f64)> {
    let start = spend.partition_point(|point| point.ts_ms <= after_ms);
    let end = spend.partition_point(|point| point.ts_ms <= until_ms);
    let mut by_family: BTreeMap<&'static str, f64> = BTreeMap::new();
    for point in &spend[start..end] {
        *by_family.entry(family(&point.model)).or_default() += point.cost_usd;
    }
    let total: f64 = by_family.values().sum();
    let (family, top) = by_family.into_iter().max_by(|a, b| a.1.total_cmp(&b.1))?;
    (total > 0.0 && top / total >= DOMINANT_SHARE).then_some((family, total))
}

fn trimmed_median(mut ratios: Vec<f64>) -> f64 {
    ratios.sort_by(f64::total_cmp);
    let trim = ratios.len() / 10;
    let kept = &ratios[trim..ratios.len() - trim];
    let middle = kept.len() / 2;
    if kept.len() % 2 == 1 {
        kept[middle]
    } else {
        (kept[middle - 1] + kept[middle]) / 2.0
    }
}

pub fn pace(instance: &[LimitSample], now_ms: i64) -> Option<Pace> {
    let latest = instance.last()?;
    let start = now_ms - PACE_SPAN_MS;
    let anchor = instance
        .iter()
        .rev()
        .find(|sample| sample.ts_ms <= start)
        .unwrap_or(&instance[0]);
    let elapsed = now_ms - anchor.ts_ms.max(start);
    if elapsed < MIN_PACE_SPAN_MS {
        return None;
    }
    let per_ms = (latest.used_pct - anchor.used_pct) / elapsed as f64;
    let projected_pct = latest
        .resets_at_ms
        .map(|resets| latest.used_pct + per_ms * (resets - now_ms).max(0) as f64);
    let full_at_ms = match projected_pct {
        Some(projected) if projected >= 100.0 && per_ms > 0.0 => {
            Some(now_ms + ((100.0 - latest.used_pct).max(0.0) / per_ms).round() as i64)
        }
        _ => None,
    };
    Some(Pace {
        pct_per_hour: per_ms * HOUR_MS,
        projected_pct,
        full_at_ms,
    })
}

pub fn windows(
    samples: &[LimitSample],
    fits: &[Fit],
    model: Option<&str>,
    now_ms: i64,
) -> Vec<LimitWindow> {
    let family = model.map_or("other", family);
    let mut latest: BTreeMap<&str, &[LimitSample]> = BTreeMap::new();
    for instance in instances(samples) {
        latest.insert(&instance[0].window, instance);
    }
    let mut windows: Vec<LimitWindow> = latest
        .into_values()
        .map(|instance| {
            let sample = instance.last().expect("instances are never empty");
            let reset = sample.resets_at_ms.is_some_and(|resets| resets <= now_ms);
            let fit = fits
                .iter()
                .find(|fit| fit.window == sample.window && fit.family == family);
            let pairs = fit.map_or(0, |fit| fit.pairs);
            LimitWindow {
                window: sample.window.clone(),
                used_pct: if reset { 0.0 } else { sample.used_pct },
                resets_at_ms: sample.resets_at_ms.filter(|_| !reset),
                sampled_at_ms: sample.ts_ms,
                reset_since_sample: reset,
                pace: if reset { None } else { pace(instance, now_ms) },
                calibration: Calibration {
                    family: family.to_string(),
                    pairs,
                    needed: PAIRS_NEEDED,
                    pct_per_usd: fit
                        .filter(|fit| fit.pairs >= PAIRS_NEEDED)
                        .map(|fit| fit.pct_per_usd),
                },
            }
        })
        .collect();
    windows.sort_by_key(|window| {
        (
            WINDOW_ORDER
                .iter()
                .position(|known| *known == window.window)
                .unwrap_or(WINDOW_ORDER.len()),
            window.window.clone(),
        )
    });
    windows
}

pub fn refresh_fit(store: &mut Store, now_ms: i64) -> Result<Vec<Fit>> {
    let since = now_ms - FIT_DAYS * DAY_MS;
    let samples = store.limit_samples_since(since)?;
    let spend = store.spend_since(since)?;
    let fits = fit(&samples, &spend, now_ms - SETTLE_MS);
    let mut writer = store.writer()?;
    writer.set_meta(FIT_KEY, &serde_json::to_string(&fits)?)?;
    writer.commit()?;
    Ok(fits)
}

pub fn stored_fit(store: &Store) -> Result<Vec<Fit>> {
    Ok(match store.meta(FIT_KEY)? {
        Some(json) => serde_json::from_str(&json).unwrap_or_default(),
        None => Vec::new(),
    })
}

pub fn recent_samples(store: &Store, now_ms: i64) -> Result<Vec<LimitSample>> {
    store.limit_samples_since(now_ms - 8 * DAY_MS)
}
```

```ts
const MINUTE_MS = 60_000
const HOUR_MS = 3_600_000
const DAY_MS = 86_400_000
const EIGHTHS = ['', '▏', '▎', '▍', '▌', '▋', '▊', '▉']
const FAMILIES = ['opus', 'sonnet', 'haiku', 'fable', 'mythos']
const WINDOWS: Record<string, string> = { five_hour: '5h', seven_day: '7d', spend_limit: 'Spend' }

export const FULL_BLOCK = '█'
export const TRACK = '░'
export const ELLIPSIS = '…'

export function money(usd: number): string {
  if (usd === 0) return '$0.00'
  if (usd < 0.01) return '<$0.01'
  if (usd < 1000) return `$${usd.toFixed(2)}`
  return `$${grouped(Math.round(usd))}`
}

export function tokens(count: number): string {
  if (count < 1000) return String(Math.round(count))
  if (count < 1_000_000) return scaled(count / 1000, 'k')
  return scaled(count / 1_000_000, 'M')
}

export function percent(value: number): string {
  if (value > 0 && value < 1) return '<1%'
  return `${Math.round(value)}%`
}

export function finePercent(value: number): string {
  if (value > 0 && value < 0.1) return '<0.1%'
  return value < 10 ? `${value.toFixed(1)}%` : `${Math.round(value)}%`
}

export function countdown(ms: number): string {
  const seconds = Math.max(0, Math.ceil(ms / 1000))
  const hours = Math.floor(seconds / 3600)
  const minutes = Math.floor((seconds % 3600) / 60)
  const rest = String(seconds % 60).padStart(2, '0')
  return hours > 0 ? `${hours}:${String(minutes).padStart(2, '0')}:${rest}` : `${minutes}:${rest}`
}

export function duration(ms: number): string {
  if (ms < MINUTE_MS) return '<1m'
  if (ms < HOUR_MS) return `${Math.floor(ms / MINUTE_MS)}m`
  if (ms < DAY_MS) {
    const minutes = Math.floor((ms % HOUR_MS) / MINUTE_MS)
    return minutes === 0 ? `${Math.floor(ms / HOUR_MS)}h` : `${Math.floor(ms / HOUR_MS)}h ${minutes}m`
  }
  const hours = Math.floor((ms % DAY_MS) / HOUR_MS)
  return hours === 0 ? `${Math.floor(ms / DAY_MS)}d` : `${Math.floor(ms / DAY_MS)}d ${hours}h`
}

export function modelName(id: string): string {
  const parts = id.replace(/\[.*\]$/, '').replace(/-\d{8}$/, '').split('-')
  const at = parts.findIndex(part => FAMILIES.includes(part))
  if (at < 0) return id
  const family = parts[at] ?? ''
  const version = parts.slice(at + 1).filter(part => /^\d+$/.test(part))
  const name = family.charAt(0).toUpperCase() + family.slice(1)
  return version.length > 0 ? `${name} ${version.join('.')}` : name
}

export function windowName(kind: string): string {
  return WINDOWS[kind] ?? kind
}

export function fit(text: string, width: number): string {
  if (text.length <= width) return text
  return width <= 1 ? ELLIPSIS.slice(0, width) : `${text.slice(0, width - 1)}${ELLIPSIS}`
}

export function spread(left: string, right: string, width: number): string {
  const room = width - right.length - 1
  const shown = fit(left, Math.max(0, room))
  return `${shown}${' '.repeat(Math.max(1, width - shown.length - right.length))}${right}`
}

export type BarCells = { filled: string; track: string }

export function bar(fraction: number, width: number): BarCells {
  const clamped = Math.min(1, Math.max(0, Number.isFinite(fraction) ? fraction : 0))
  const eighths = Math.round(clamped * width * 8)
  const full = Math.floor(eighths / 8)
  const partial = EIGHTHS[eighths % 8] ?? ''
  const filled = FULL_BLOCK.repeat(full) + partial
  return { filled, track: TRACK.repeat(width - filled.length) }
}

function scaled(value: number, unit: string): string {
  const rounded = value < 100 ? Math.round(value * 10) / 10 : Math.round(value)
  if (rounded >= 1000 && unit === 'k') return scaled(value / 1000, 'M')
  return `${String(rounded)}${unit}`
}

function grouped(value: number): string {
  return String(value).replace(/\B(?=(\d{3})+(?!\d))/g, ',')
}
```

```ts
import type { HttpInit, HttpResponse, JsonValue, SessionMeasureInput } from 'claude-code'

import type { Measure, Snapshot } from '../types'

export const TIMEOUT_MS = 500
export const OUTBOX_LIMIT = 256
export const HOST = 'http://claude-plus'

export type Io = {
  fetch: (url: string, init: HttpInit) => Promise<HttpResponse>
  sleep: (ms: number, options: { signal: AbortSignal }) => Promise<void>
}

export type Reply = { ok: true; text: string } | { ok: false; reason: string; status: number | null }

export type PlusEvent = { session: string; kind: string; ts_ms: number; data: { [key: string]: JsonValue } }

export function socketPath(home: string | undefined, plusHome: string | undefined): string | null {
  const base = plusHome !== undefined && plusHome !== '' ? plusHome : home !== undefined && home !== '' ? `${home}/.claude-plus` : null
  return base === null ? null : `${base.replace(/\/+$/, '')}/daemon.sock`
}

export async function request(io: Io, socket: string, path: string, init: HttpInit = {}): Promise<Reply> {
  const stop = new AbortController()
  const late = io.sleep(TIMEOUT_MS, { signal: stop.signal }).then(
    (): Reply => ({ ok: false, reason: `no answer within ${TIMEOUT_MS} ms`, status: null }),
    (): Reply => ({ ok: false, reason: 'cancelled', status: null }),
  )
  const answered = io.fetch(`${HOST}${path}`, { ...init, socketPath: socket }).then(
    (response): Reply =>
      response.ok
        ? { ok: true, text: response.text }
        : { ok: false, reason: `${response.status}: ${errorOf(response.text)}`, status: response.status },
    (error: unknown): Reply => ({ ok: false, reason: error instanceof Error ? error.message : String(error), status: null }),
  )
  const reply = await Promise.race([answered, late])
  stop.abort()
  return reply
}

export function snapshotPath(session: string): string {
  return `/snapshot?session=${encodeURIComponent(session)}`
}

export function parseSnapshot(text: string): Snapshot | null {
  const value = safeJson(text)
  if (!isObject(value) || value.v !== 1 || typeof value.session !== 'string') return null
  const live = value.live
  if (!isObject(value.totals) || !isObject(live) || !isObject(live.cache) || !Array.isArray(live.limits)) return null
  return value as unknown as Snapshot
}

export function measureOf(e: SessionMeasureInput, atMs: number): Measure {
  return {
    atMs,
    contextTokens: e.context.tokens ?? null,
    contextWindow: e.context.window,
    contextPercent: e.context.percent ?? null,
    rateLimits: e.rateLimits.map(limit => ({
      kind: limit.kind,
      percentUsed: limit.percentUsed,
      resetsAtMs: limit.resetsAt === undefined ? null : Date.parse(limit.resetsAt),
    })),
    costUsd: e.cost?.usd ?? null,
  }
}

export class Outbox {
  private queued: PlusEvent[] = []

  add(event: PlusEvent): void {
    this.queued.push(event)
    if (this.queued.length > OUTBOX_LIMIT) this.queued.splice(0, this.queued.length - OUTBOX_LIMIT)
  }

  take(): PlusEvent[] {
    const taken = this.queued
    this.queued = []
    return taken
  }

  putBack(events: PlusEvent[]): void {
    this.queued = [...events, ...this.queued].slice(-OUTBOX_LIMIT)
  }

  get size(): number {
    return this.queued.length
  }
}

export function eventsBody(events: PlusEvent[]): string {
  return JSON.stringify({ events })
}

function errorOf(text: string): string {
  const value: unknown = safeJson(text)
  return isObject(value) && typeof value.error === 'string' ? value.error : text.slice(0, 120)
}

function safeJson(text: string): unknown {
  try {
    return JSON.parse(text)
  } catch {
    return undefined
  }
}

function isObject(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
}
```

```ts
  return snapshot !== null && (local.session === null || snapshot.session === local.session) ? snapshot : null
}

export function cacheClock(snapshot: Snapshot | null, local: Local, nowMs: number): CacheClock {
  const cache = snapshot?.live.cache
  const subscribed = (local.measure?.rateLimits.length ?? 0) > 0
  const ttlMs =
    cache !== undefined ? (cache.ttl === '1h' ? HOUR_MS : FIVE_MINUTES_MS) : subscribed ? HOUR_MS : FIVE_MINUTES_MS
  const step = local.step
  const touched = step !== null && (step.cacheRead > 0 || step.cacheWrite > 0) ? step.atMs + ttlMs : null
  const candidates = [cache?.expires_at_ms ?? null, touched].filter((at): at is number => at !== null)
  const expiresAtMs = candidates.length > 0 ? Math.max(...candidates) : null
  const remainingMs = expiresAtMs === null ? 0 : Math.max(0, expiresAtMs - nowMs)
  return {
    state: expiresAtMs === null ? 'none' : remainingMs > 0 ? 'warm' : 'cold',
    ttlMs,
    assumed: cache === undefined || cache.ttl_source === 'assumed',
    expiresAtMs,
    remainingMs,
  }
}

export function heartbeat(clock: CacheClock, nowMs: number, animations: boolean, working: boolean): Segment {
  if (clock.state !== 'warm') return { text: '·', dim: true }
  const urgent = clock.remainingMs <= LAST_MINUTE_MS
  const color: ThemeKey = urgent ? 'warning' : 'claude'
  if (!animations || working) return { text: '✻', color }
  if (urgent) {
    return Math.floor(nowMs / QUICK_BREATH_MS) % 2 === 0
      ? { text: '✻', color, bold: true }
      : { text: '✻', color, dim: true }
  }
  const phase = Math.floor(nowMs / BREATH_MS) % 4
  if (phase === 0) return { text: '✻', color, dim: true }
  if (phase === 2) return { text: '✻', color, bold: true }
  return { text: '✻', color }
}

export function eased(motion: Motion, nowMs: number): number {
  const progress = (nowMs - motion.startMs) / EASE_MS
  if (progress >= 1) return motion.to
  if (progress <= 0) return motion.from
  return motion.from + (motion.to - motion.from) * (1 - (1 - progress) ** 3)
}

export function shown(motions: Readonly<Record<string, Motion>>, key: string, target: number, nowMs: number): number {
  const motion = motions[key]
  return motion !== undefined && motion.to === target ? eased(motion, nowMs) : target
}

export function isMoving(motions: Readonly<Record<string, Motion>>, nowMs: number): boolean {
  return Object.values(motions).some(motion => nowMs - motion.startMs < EASE_MS)
}

export function settled(motions: Readonly<Record<string, Motion>>, nowMs: number): Record<string, Motion> {
  return Object.fromEntries(Object.entries(motions).filter(([, motion]) => nowMs - motion.startMs < EASE_MS))
}

export function easables(snapshot: Snapshot | null, local: Local): Record<string, number> {
  const values: Record<string, number> = {}
  const cost = snapshot?.totals.cost_usd ?? local.measure?.costUsd ?? null
  if (cost !== null) values.cost = cost
  const context = local.measure?.contextPercent ?? null
  if (context !== null) values.context = context
  const hit = snapshot?.live.cache.hit_ratio ?? null
  if (hit !== null) values.hit = hit * 100
  for (const limit of limitsOf(snapshot, local)) values[`limit:${limit.window}`] = limit.used_pct
  return values
}

export function retarget(
  motions: Readonly<Record<string, Motion>>,
  before: Record<string, number>,
  after: Record<string, number>,
  nowMs: number,
  animations: boolean,
): Record<string, Motion> {
  if (!animations) return {}
  const next: Record<string, Motion> = {}
  for (const [key, to] of Object.entries(after)) {
    const from = before[key]
    const running = motions[key]
    if (from === undefined || from === to) {
      if (running !== undefined && running.to === to && nowMs - running.startMs < EASE_MS) next[key] = running
      continue
    }
    next[key] = { from: shown(motions, key, from, nowMs), to, startMs: nowMs }
  }
  return next
}

export function tickPeriod(input: Pick<ScreenInput, 'animations' | 'motions' | 'nowMs' | 'snapshot' | 'local'>): number {
  if (!input.animations) return TICK_MS
  if (isMoving(input.motions, input.nowMs)) return FRAME_MS
  const clock = cacheClock(current(input), input.local, input.nowMs)
  return clock.state === 'warm' && clock.remainingMs <= LAST_MINUTE_MS ? QUICK_BREATH_MS : TICK_MS
}

export function statusText(input: Pick<ScreenInput, 'snapshot' | 'local' | 'nowMs'>): string | undefined {
  const snapshot = current(input)
  const parts: string[] = []
  const cost = snapshot?.totals.cost_usd ?? input.local.measure?.costUsd ?? null
  if (cost !== null) parts.push(money(cost))
  const clock = cacheClock(snapshot, input.local, input.nowMs)
  if (clock.state === 'warm') parts.push(`cache ${countdown(clock.remainingMs)}`)
  if (clock.state === 'cold') parts.push('cache cold')
  const five = limitsOf(snapshot, input.local).find(limit => limit.window === 'five_hour')
  if (five !== undefined) parts.push(`5h ${percent(five.used_pct)}`)
  return parts.length > 0 ? parts.join(' · ') : undefined
}

export function limitsOf(snapshot: Snapshot | null, local: Local): LimitWindow[] {
  if (snapshot !== null && snapshot.live.limits.length > 0) return snapshot.live.limits
  return (local.measure?.rateLimits ?? []).map(limit => ({
    window: limit.kind,
    used_pct: limit.percentUsed,
    resets_at_ms: limit.resetsAtMs,
    sampled_at_ms: local.measure?.atMs ?? 0,
    reset_since_sample: false,
    pace: null,
    calibration: { family: 'other', pairs: 0, needed: 20, pct_per_usd: null },
  }))
}

export function screen(input: ScreenInput): Line[] {
  const width = Math.max(MIN_CONTENT, input.width - 2 * PADDING)
  const snapshot = current(input)
  const sections = [
    notice(input),
    headline(input, snapshot, width),
    context(input, width),
    cache(input, snapshot, width),
    forecast(input, snapshot, width),
    session(input, snapshot, width),
    limits(input, snapshot, width),
  ].filter(section => section.length > 0)
  return sections.flatMap((section, index) => (index === 0 ? section : [gap(index), ...section]))
}

function gap(index: number): Line {
  return { key: `gap-${index}`, segments: [{ text: ' ' }] }
}

function plain(key: string, text: string, style: Style = {}): Line {
  return { key, segments: [{ text, ...style }] }
}

function prose(key: string, text: string, style: Style = {}, indent = 0): Line {
  const line: Line = { key, segments: [{ text, ...style }], wrap: true }
  if (indent > 0) line.indent = indent
  return line
}

type Style = Omit<Segment, 'text'>

function pair(key: string, left: string, right: string, width: number, rightStyle: Style = {}, leftStyle: Style = {}): Line {
  const text = spread(left, right, width)
  return {
    key,
    segments: [
      { text: text.slice(0, text.length - right.length), ...leftStyle },
      { text: right, ...rightStyle },
    ],
  }
}

function heading(key: string, title: string, width: number, why?: string): Line {
  const line: Line = { key, segments: [{ text: title.padEnd(why === undefined ? width : width - WHY_COLUMNS), bold: true }] }
  if (why !== undefined) line.why = why
  return line
}

function meter(key: string, label: string, fraction: number, value: string, width: number, color: ThemeKey): Line {
  const labelled = label.length > 0 ? `${label} ` : ''
  const cells = bar(fraction, width - labelled.length - value.length - 1)
  return {
    key,
    segments: [
      { text: labelled },
      { text: cells.filled, color },
      { text: cells.track, dim: true },
      { text: ` ${value}` },
    ],
  }
}

function notice(input: ScreenInput): Line[] {
  const { status, detail } = input.daemon
  if (status === 'ok') return []
  if (status === 'starting') return [prose('daemon', 'Starting the claude-plus daemon…', { dim: true })]
  if (status === 'rebuilding') return [prose('daemon', 'Rebuilding the claude-plus index… numbers return in a moment', { dim: true })]
  if (status === 'missing') {
    return [prose('daemon', 'claude-plus is not installed yet. Install it, or set its path in the plugin options', { color: 'warning' })]
  }
  if (status === 'unreachable') {
    return [prose('daemon', 'The daemon is not answering · run claude-plus daemon --ensure', { color: 'warning' })]
  }
  return [prose('daemon', `The daemon could not start: ${detail ?? 'no reason given'}`, { color: 'error' })]
}

function headline(input: ScreenInput, snapshot: Snapshot | null, width: number): Line[] {
  const id = snapshot?.live.model ?? input.local.model
  const effort = snapshot?.live.effort ?? null
  const name = id === null ? 'Claude' : modelName(id)
  const left = effort === null ? name : `${name} · ${effort}`
  const cost = snapshot?.totals.cost_usd ?? input.local.measure?.costUsd ?? null
  const lines: Line[] = []
  if (cost !== null) {
    const value = money(shown(input.motions, 'cost', cost, input.nowMs))
    lines.push(pair('headline', left, value, width, { color: 'claude', bold: true }))
  } else {
    lines.push(plain('headline', left))
  }
  const unpriced = snapshot?.totals.unpriced_requests ?? 0
  if (unpriced > 0) {
    const noun = unpriced === 1 ? 'request on an unknown model is' : 'requests on unknown models are'
    lines.push(prose('unpriced', `${unpriced} ${noun} not priced`, { dim: true }))
  }
  return lines
}

function context(input: ScreenInput, width: number): Line[] {
  const measure = input.local.measure
  if (measure === null || measure.contextPercent === null) {
    return [plain('context', 'Context', { bold: true }), prose('context-empty', 'Context appears after your first prompt', { dim: true })]
  }
  const used = shown(input.motions, 'context', measure.contextPercent, input.nowMs)
  const amount =
    measure.contextTokens === null ? tokens(measure.contextWindow) : `${tokens(measure.contextTokens)} / ${tokens(measure.contextWindow)}`
  const color: ThemeKey = used >= CONTEXT_ERROR ? 'error' : used >= CONTEXT_WARNING ? 'warning' : 'text'
  return [
    pair('context', 'Context', amount, width, {}, { bold: true }),
    meter('context-bar', '', used / 100, percent(used).padStart(4), width, color),
  ]
}

function cache(input: ScreenInput, snapshot: Snapshot | null, width: number): Line[] {
  const clock = cacheClock(snapshot, input.local, input.nowMs)
  const glyph = heartbeat(clock, input.nowMs, input.animations, input.local.working)
  const ttl = `${clock.assumed ? '~' : ''}${clock.ttlMs === HOUR_MS ? '1h' : '5m'}`
  const forecast = snapshot?.live.forecast ?? null
  const lines: Line[] = []
  if (clock.state === 'none') {
    lines.push(heading('cache', 'Cache', width))
    lines.push(prose('cache-note', 'Cache starts with your first prompt ✻', { dim: true }))
    return lines
  }
  const state = clock.state === 'warm' ? 'warm' : 'cold'
  const right = clock.state === 'warm' ? `${countdown(clock.remainingMs)} left` : 'expired'
  const title = 'Cache '
  const left = `${title}${glyph.text} ${state} · ${ttl}`
  const padded = spread(left, right, width - WHY_COLUMNS)
  const urgent = clock.state === 'warm' && clock.remainingMs <= LAST_MINUTE_MS
  lines.push({
    key: 'cache',
    why: 'cache',
    segments: [
      { text: title, bold: true },
      glyph,
      { text: padded.slice(title.length + glyph.text.length, padded.length - right.length) },
      { text: right, ...(clock.state === 'warm' ? { color: urgent ? 'warning' : 'success' } : { dim: true }) },
    ],
  })
  const cells = bar(clock.remainingMs / clock.ttlMs, width)
  lines.push({
    key: 'cache-bar',
    segments: [
      { text: cells.filled, color: urgent ? 'warning' : 'success' },
      { text: cells.track, dim: true },
    ],
  })
  const live = snapshot?.live.cache
  if (clock.state === 'cold' && forecast?.cold_usd != null) {
    lines.push(prose('cache-note', `Cache went cold while you were away, rewarming will cost ~${money(forecast.cold_usd)}`))
  } else if (live !== undefined && live.saved_usd >= 0.01) {
    lines.push(prose('cache-note', `Cache hits saved you ${money(live.saved_usd)} this session`, { color: 'success' }))
  }
  if (live !== undefined && live.hit_ratio !== null) {
    const hit = shown(input.motions, 'hit', live.hit_ratio * 100, input.nowMs)
    lines.push(pair('cache-hits', '  Hit ratio', percent(hit), width, {}, { dim: true }))
  }
  if (live !== undefined && live.rebuilds > 0) {
    const value = `${live.rebuilds} · ~${money(live.rebuild_usd)}`
    lines.push({ ...pair('cache-rebuilds', '  Rebuilds', value, width - WHY_COLUMNS, {}, { dim: true }), why: 'rebuilds' })
  }
  if (input.expanded.includes('cache')) lines.push(...cacheWhy(clock))
  if (input.expanded.includes('rebuilds') && live?.last_rebuild != null) {
    lines.push(prose('explain-rebuilds', rebuildWhy(live.last_rebuild.cause, input.nowMs - live.last_rebuild.ts_ms), { dim: true }))
  }
  return lines
}

function cacheWhy(clock: CacheClock): Line[] {
  const ttl = clock.ttlMs === HOUR_MS ? '1 hour' : '5 minutes'
  const source = clock.assumed
    ? `No cache write has been read from the transcript yet, so the ${ttl} lifetime is assumed from your plan.`
    : `The last cache write in the transcript asked for a ${ttl} lifetime.`
  return [prose('explain-cache', `${source} Every request that reads or writes the cache starts the countdown again.`, { dim: true })]
}

function rebuildWhy(cause: string, agoMs: number): string {
  const reasons: Record<string, string> = {
    idle: 'the cache expired during an idle gap',
    model_switch: 'the model changed, and each model keeps its own cache',
    prefix_changed: 'the injected context changed (tools, skills or memory)',
    unknown: 'no cause could be told from the transcript',
  }
  return `The last rebuild, ${duration(agoMs)} ago, wrote the prompt again because ${reasons[cause] ?? reasons.unknown}.`
}

function forecast(input: ScreenInput, snapshot: Snapshot | null, width: number): Line[] {
  const next = snapshot?.live.forecast ?? null
  if (next === null || (next.warm_usd === null && next.cold_usd === null)) return []
  const clock = cacheClock(snapshot, input.local, input.nowMs)
  const cost = (usd: number | null, pct: number | null) =>
    usd === null ? 'price unknown' : pct === null ? `~${money(usd)}` : `~${money(usd)} · ${finePercent(pct)} of 5h`
  const warmFirst = clock.state === 'warm'
  const lines: Line[] = [
    heading('next', 'Next turn', width, 'forecast'),
    pair('next-warm', '  if warm', cost(next.warm_usd, next.warm_pct_5h), width, warmFirst ? {} : { dim: true }, { dim: true }),
    pair('next-cold', '  if cold', cost(next.cold_usd, next.cold_pct_5h), width, warmFirst ? { dim: true } : {}, { dim: true }),
  ]
  if (next.alternative !== null) {
    const value = `~${money(next.alternative.first_usd)}, then ~${money(next.alternative.next_usd)}`
    lines.push(pair('next-alternative', `  on ${modelName(next.alternative.model)}`, value, width, { dim: true }, { dim: true }))
  }
  if (input.expanded.includes('forecast')) {
    lines.push(
      prose(
        'explain-forecast',
        `Your ${tokens(next.prefix_tokens)} token prompt is read from the cache when warm and written again when cold. ` +
          `${tokens(next.new_tokens)} new and ${tokens(next.output_tokens)} output tokens are the medians of your last ${next.samples} requests.`,
        { dim: true },
      ),
    )
  }
  return lines
}

function session(input: ScreenInput, snapshot: Snapshot | null, width: number): Line[] {
  const lines: Line[] = [heading('session', 'Session', width)]
  if (snapshot !== null) {
    const t = snapshot.totals.tokens
    const prompt = t.input + t.cache_read + t.cache_write_5m + t.cache_write_1h
    lines.push(pair('session-tokens', '  Tokens in / out', `${tokens(prompt)} / ${tokens(t.output)}`, width, {}, { dim: true }))
    lines.push(pair('session-turns', '  Turns · subagents', `${input.local.turns} · ${snapshot.totals.subagents}`, width, {}, { dim: true }))
    if (snapshot.totals.reconciled_usd >= 0.01) {
      lines.push(pair('session-reconciled', '  Reconciled', money(snapshot.totals.reconciled_usd), width, { dim: true }, { dim: true }))
    }
    return lines
  }
  const step = input.local.step
  lines.push(pair('session-turns', '  Turns', String(input.local.turns), width, {}, { dim: true }))
  if (step !== null) {
    const prompt = step.input + step.cacheRead + step.cacheWrite
    lines.push(pair('session-step', '  Last request', `${tokens(prompt)} in · ${tokens(step.output)} out`, width, {}, { dim: true }))
  }
  return lines
}

function limits(input: ScreenInput, snapshot: Snapshot | null, width: number): Line[] {
  const windows = limitsOf(snapshot, input.local)
  if (windows.length === 0) return []
  const lines: Line[] = [heading('limits', 'Plan limits', width, 'limits')]
  for (const limit of windows) {
    const used = shown(input.motions, `limit:${limit.window}`, limit.used_pct, input.nowMs)
    const color: ThemeKey = used >= LIMIT_WARNING ? 'warning' : 'text'
    lines.push(meter(`limit-${limit.window}`, `  ${windowName(limit.window).padEnd(5)}`, used / 100, percent(used).padStart(4), width, color))
    const detail = limitDetail(limit, input.nowMs)
    if (detail !== null) lines.push(detail)
  }
  const five = windows.find(limit => limit.window === 'five_hour')
  if (snapshot !== null && five !== undefined && five.calibration.pct_per_usd === null) {
    lines.push(prose('limits-learning', 'Learning how your plan counts tokens… a few more turns ✻', { dim: true }))
  }
  if (input.expanded.includes('limits')) {
    const learned = five?.calibration
    const how =
      learned?.pct_per_usd != null
        ? `From ${learned.pairs} readings, 1% of your 5h window is about ${money(1 / learned.pct_per_usd)} of API-priced usage on ${familyName(learned.family)}.`
        : `Each turn pairs the percent Claude Code reports with what it would cost on the API; ${learned?.pairs ?? 0} of ${learned?.needed ?? 20} readings so far.`
    lines.push(prose('explain-limits', `${how} The pace projects the last 30 minutes to the reset.`, { dim: true }))
  }
  return lines
}

function familyName(family: string): string {
  return family.charAt(0).toUpperCase() + family.slice(1)
}

function limitDetail(limit: LimitWindow, nowMs: number): Line | null {
  const key = `limit-${limit.window}-detail`
  const parts: string[] = []
  if (limit.resets_at_ms !== null) parts.push(`resets in ${duration(Math.max(0, limit.resets_at_ms - nowMs))}`)
  const pace = limit.pace
  if (pace?.full_at_ms != null) {
    parts.push(`full in ${duration(Math.max(0, pace.full_at_ms - nowMs))} at this pace`)
    return prose(key, parts.join(' · '), { color: 'warning' }, DETAIL_INDENT)
  }
  if (pace?.projected_pct != null) parts.push(`on pace for ${percent(pace.projected_pct)}`)
  return parts.length > 0 ? prose(key, parts.join(' · '), { dim: true }, DETAIL_INDENT) : null
}
```

```tsx
import type { EngineInterface, JsonValue, PluginOptions, Register, Timer } from 'claude-code'

import type { Daemon, Local, Motion, PlusView, Snapshot } from '../types'
import type { Io, PlusEvent } from './client'
import { Outbox, eventsBody, measureOf, parseSnapshot, request, snapshotPath, socketPath } from './client'
import {
  EMPTY_LOCAL,
  easables,
  ensureError,
  ensureOutcome,
  retarget,
  screen,
  settled,
  statusText,
  stepOf,
  tickPeriod,
  toggled,
} from './state'
import { Live } from './views/live'

export const PANE_TITLE = 'claude-plus'
export const POLL_MS = 3000
export const ENSURE_TIMEOUT_MS = 10_000
export const FULLSCREEN_KEY = 'fullscreen'
export const SERVICE_UNAVAILABLE = 503

const view = atom({ plugin: 'plus', key: 'view' } as const, 'live' as PlusView)
const snapshot = atom({ plugin: 'plus', key: 'snapshot' } as const, null as Snapshot | null)
const local = atom({ plugin: 'plus', key: 'local' } as const, EMPTY_LOCAL as Local)
const daemon = atom({ plugin: 'plus', key: 'daemon' } as const, { status: 'starting', detail: null } as Daemon)
const now = atom({ plugin: 'plus', key: 'now' } as const, 0)
const expanded = atom({ plugin: 'plus', key: 'expanded' } as const, [] as string[])
const motions = atom({ plugin: 'plus', key: 'motions' } as const, {} as Record<string, Motion>)

type Runtime = {
  binary: string
  animations: boolean
  outbox: Outbox
  timer: Timer | null
  socket: string | null | undefined
  ensuring: Promise<void> | null
  flushing: boolean
  polledAtMs: number
  shownStatus: string | undefined
}

function fresh(options: PluginOptions): Runtime {
  return {
    binary: typeof options.binaryPath === 'string' && options.binaryPath !== '' ? options.binaryPath : 'claude-plus',
    animations: options.animations !== false,
    outbox: new Outbox(),
    timer: null,
    socket: undefined,
    ensuring: null,
    flushing: false,
    polledAtMs: -Infinity,
    shownStatus: undefined,
  }
}

let runtime = fresh({})

function io($: EngineInterface): Io {
  return {
    fetch: (url, init) => $.http.fetch(url, init),
    sleep: (ms, sleepOptions) => $.clock.sleep(ms, sleepOptions),
  }
}

async function socketOf($: EngineInterface): Promise<string | null> {
  if (runtime.socket === undefined) runtime.socket = socketPath(await $.env.get('HOME'), await $.env.get('CLAUDE_PLUS_HOME'))
  return runtime.socket
}

function ensureTimers($: EngineInterface): void {
  if (runtime.timer !== null) return
  runtime.timer = $.clock.after(0, () => void tick($))
}

async function schedule($: EngineInterface): Promise<void> {
  const period = tickPeriod({
    animations: runtime.animations,
    motions: await read($, motions),
    nowMs: await read($, now),
    snapshot: await read($, snapshot),
    local: await read($, local),
  })
  runtime.timer = $.clock.after(period, () => void tick($))
}

async function tick($: EngineInterface): Promise<void> {
  try {
    const at = await $.clock.now()
    await update($, now, () => at)
    if (runtime.outbox.size > 0) await flush($)
    if (at - runtime.polledAtMs >= POLL_MS) await poll($)
    await settle($)
    await showStatus($)
  } finally {
    await schedule($)
  }
}

async function settle($: EngineInterface): Promise<void> {
  const at = await read($, now)
  const running = await read($, motions)
  const kept = settled(running, at)
  if (Object.keys(kept).length !== Object.keys(running).length) await update($, motions, () => kept)
}

async function showStatus($: EngineInterface): Promise<void> {
  const text = statusText({ snapshot: await read($, snapshot), local: await read($, local), nowMs: await read($, now) })
  if (text === runtime.shownStatus) return
  runtime.shownStatus = text
  $.ui.status(text)
}

async function animate($: EngineInterface, change: () => Promise<void>): Promise<void> {
  const before = easables(await read($, snapshot), await read($, local))
  await change()
  const after = easables(await read($, snapshot), await read($, local))
  const at = await $.clock.now()
  await update($, motions, running => retarget(running, before, after, at, runtime.animations))
  await update($, now, () => at)
  await showStatus($)
}

async function follow($: EngineInterface): Promise<string> {
  const id = await $.session.id()
  const known = await read($, local)
  if (known.session !== id) {
    await update($, local, () => ({ ...EMPTY_LOCAL, session: id }))
    await update($, snapshot, () => null)
    await update($, motions, () => ({}))
  }
  return id
}

async function poll($: EngineInterface): Promise<void> {
  runtime.polledAtMs = await $.clock.now()
  const id = await follow($)
  const path = await socketOf($)
  if (path === null) return
  const reply = await request(io($), path, snapshotPath(id))
  const status = (await read($, daemon)).status
  if (!reply.ok) {
    if (reply.status === SERVICE_UNAVAILABLE) await update($, daemon, (): Daemon => ({ status: 'rebuilding', detail: null }))
    else if (status === 'ok' || status === 'rebuilding') await update($, daemon, (): Daemon => ({ status: 'unreachable', detail: reply.reason }))
    return
  }
  const parsed = parseSnapshot(reply.text)
  if (parsed === null || parsed.session !== id) return
  if (status !== 'ok') await update($, daemon, (): Daemon => ({ status: 'ok', detail: null }))
  await animate($, async () => {
    await update($, snapshot, () => parsed)
  })
}

async function flush($: EngineInterface): Promise<void> {
  const path = await socketOf($)
  if (runtime.flushing || path === null || runtime.outbox.size === 0) return
  runtime.flushing = true
  const events = runtime.outbox.take()
  try {
    const reply = await request(io($), path, '/events', { method: 'POST', headers: { 'content-type': 'application/json' }, body: eventsBody(events) })
    if (!reply.ok) runtime.outbox.putBack(events)
  } finally {
    runtime.flushing = false
  }
}

async function forward($: EngineInterface, kind: string, data: { [key: string]: JsonValue }, session?: string): Promise<void> {
  const event: PlusEvent = { session: session ?? (await follow($)), kind, ts_ms: await $.clock.now(), data }
  runtime.outbox.add(event)
  await flush($)
}

function ensureDaemon($: EngineInterface): Promise<void> {
  runtime.ensuring ??= (async () => {
    const outcome = await $.process.run([runtime.binary, 'daemon', '--ensure'], { timeoutMs: ENSURE_TIMEOUT_MS }).then(
      result => ensureOutcome(result.exitCode, result.stderr),
      ensureError,
    )
    await update($, daemon, () => outcome)
    if (outcome.status === 'ok') {
      await flush($)
      await poll($)
    } else {
      runtime.ensuring = null
    }
  })()
  return runtime.ensuring
}

async function open($: EngineInterface): Promise<string> {
  const opened = await $.ui.open({ id: PANE_ID, title: PANE_TITLE })
  return opened.isPlaced ? '✻ claude-plus is open beside the conversation' : `✻ claude-plus will show once there is room: ${opened.reason}`
}

    const model = await $.session.model()
    await update($, local, known => ({ ...known, session: id, model }))

    void forward($, 'session.start', { cwd: e.cwd, surface: e.surface, interactive: e.isInteractive })
    if (e.isInteractive && (await $.store.get(FULLSCREEN_KEY)) !== false) void open($)
    return next(e)
  })

    void ensureDaemon($)
    await $.store.set(FULLSCREEN_KEY, e.presentation.isFullscreen)
    return { text: await open($) }
  })

  on('turn.start', async ($, e, next) => {
    ensureTimers($)
    await follow($)
    await update($, local, known => ({ ...known, working: true }))

  })

  on('session.compact', async ($, e, next) => {
    const result = await next(e)
    void forward($, 'session.compact', {
      trigger: e.trigger,
      agentId: e.agentId ?? null,
      skipped: result.skip ?? null,
      tokensBefore: result.skip === undefined ? (result.tokensBefore ?? null) : null,
      tokensAfter: result.skip === undefined ? (result.tokensAfter ?? null) : null,
    })
    return result
  })

  on('session.end', async ($, e, next) => {
    void forward($, 'session.end', { reason: e.reason }, e.sessionId)
    return next(e)
  })

  on('ui.render', { component: 'Pane', requestId: PANE_ID }, async ($, e) => {
    const nowMs = await read($, now)
    const current = await read($, view)
    const lines = screen({
      width: e.props.bodyColumns,
      nowMs,
      animations: runtime.animations,
      snapshot: await read($, snapshot),
      local: await read($, local),
      daemon: await read($, daemon),
      expanded: await read($, expanded),
      motions: await read($, motions),
    })
    return (
      <Live
        ui={$.ui.resolve(e)}
        width={e.props.bodyColumns}
        lines={lines}
        tabs={[{ key: 'tab-live', hotkey: '1', label: 'Live', isActive: current === 'live', onPress: () => void update($, view, () => 'live') }]}
        onWhy={key => void update($, expanded, list => toggled(list, key))}
      />
    )
  })
}
```
